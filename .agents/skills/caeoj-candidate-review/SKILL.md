# 考生视角题面审阅

目标是判断考生能否依靠公开材料确定任务、实现接口并理解评价要求。按[审阅流程](references/workflow.md)组织独立 subagent；不让作者自审冒充独立考生，也不把已有审阅结论提供给审阅者。可独立调用，或由出题／DATA 设计流程复用同一份最终版本审阅。

先明确目标题目清单和模式，记录所选模式及公开样例范围：

| 模式 | 材料与缺失处理 |
|---|---|
| `statements`，题面模式，默认 | 必需本题 instruction.md、DATA.md、通用 CONTRACT.md；允许无样例。已明确公开的样例可纳入，缺少时标记样例未经检查，不据此否定题面完成 |
| `exam-materials`，考试材料模式 | 必需三文件及真实交付考生的公开样例输入和其依赖；公开输出仅在声明提供时必需。缺失则继续可完成的题面审阅，但考试材料结论为资料不足，不自动降级为题面模式或生成样例 |

解释性材料只有三文件。纳入样例不增加解题文档依赖，只允许检查确认公开的数据资产；文件名或位于 samples／examples 并不足以证明其公开。公开身份不明时记录范围缺口，不能读取隐藏 cases、私有参考、生成器、求解实现、维护规范或其他题目来补足题意。不得从校验器行为或外部资料倒推文档未声明的要求。

协调 Agent 负责定位、公开材料清单与报告汇总；独立考生使用不继承作者讨论的新上下文（支持时 `fork_turns="none"`），只接收真实任务、通用审阅方法和允许材料。协调方可以读取本技能及流程，考生不据此获得额外物理定义或作者预设答案。整章／整库可按规模分组，但逐题记录实际覆盖，不用少量抽查代表全库。无法启动独立审阅时如实记录未完成，保留可执行部分。

检查物理目标与建模责任、条件与初态、字段和数组身份、单位、连续重建、点值／平均／积分、评分和资源是否可确定，并寻找障碍、误导、无关或不应公开的信息。按风险尝试具体反例或两种合理实现，不能只查关键词或格式。可解析公开样例的 JSON／HDF5／网格，检查文件引用、轴、单位与输出约定；默认不编写完整求解器、不运行收费模型、不重新标定参考。

默认只写审阅报告到 `runs/candidate-review/<本次目录>/`，不修改题目、数据、工具或配置；在出题任务中由调用方负责修复并请求受影响文件复核。报告包含模式、逐题覆盖、文件版本／SHA256、具体位置、影响、反例和建议，区分明确缺陷、待核实问题及可选精炼。题面结论与样例检查状态分别给出；“本轮未发现未决问题”仅限记录的证据，不证明无缺陷、参考准确、工具兑现或预算可达。修订／材料变化后核对版本再复核，不设固定轮数或必须发现的问题数量。

本技能不承担 general problem 定位或章节划分的独立设计审阅；即使题意清楚可实现，也不据此判定题目设计合理。不读取哲学、规划或设计审阅报告来补题意，不与设计审阅共用审阅者上下文。

本技能不自动调用其他技能。隐藏输入全量审计和文档／实现双向一致性由维护方另行处理；样例检查不等于实际数据审计。
