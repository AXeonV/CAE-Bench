# 评测配置与框架适配

以题目 instruction.md、DATA.md、CONTRACT.md 为要求来源；先定位当前评分实现、执行器、配置解析、组装／发布入口和相关测试，再生成配置。文件名、必需字段、默认值及后端要求不是永久约定，不能凭记忆照抄旧配置。按 [配置工作流](references/workflow.md) 执行；当前仓库的实现路线见 [后端定位线索](references/current-backend.md)，使用时仍须核对源码。

当前题库统一显式提供 `grading.json`，`judge-config.json` 只定义执行设置；缺评分策略即停止，不从执行配置派生容差或静默使用默认评分。单点 CLI／SDK 的 `atol/rtol` 便捷比较仍可用，但不是题库的另一配置来源。

可运行评测必须有明确评分与执行设置，但不要求每题手写 judge-config.json 或 Harbor 覆盖文件。判断哪些配置由题目声明、共享模板继承或组装生成，记录最终生效值与来源。题面／DATA 仍是完整考生契约，配置和内部报告不能增加隐藏判据、资源限制或阅读依赖。

先提取评分公式、阈值／偏置、按时间／空间／分量的聚合、逐例和总分、资源、程序接口及失败分类，再映射实际字段名、实例数量及目标框架。区分 outputs 逻辑字段名、quantity 与 HDF5 array key；不根据 quantity 猜固定字段名，也不在字段未绑定时伪造可运行 grading.json。模型／数值容差由题意确定，参考精度和预算校准证据另记，不能为适配 judge 放宽要求。

框架可表达且执行满足目标时只改必要配置；缺能力时先按[职责设计](../../../qbank/design/CORE-AND-EXTENSIONS.md)定位：通用评分／扩展接口归 `src/caeoj/`，物理契约能力归 `qbank/extensions/caeoj_ext/`，题目专用公开运行规则按需归本题 `extension/`，装配与后端适配归 `src/caeoj_tools/` 或现有 `src/utils/` 维护入口，参考制作归本题 `author/`。扩展不按章节命名；普通新增题目不扩充发布器的领域文件清单。按授权实施最小适配，再验证目标判据与旧行为。未知配置键可能被忽略，不能只因 JSON/TOML 可解析就说已生效。不机械把 Harbor 当成未来唯一后端，也不把稳定物理判据写死在某个框架文件名中。

评测要求缺失、与题面冲突或 DATA 无法绑定时反馈相应环节：目标／评分／资源回到 caeoj-author-question，字段和观测映射回到 caeoj-design-data，实际数据不一致交给 caeoj-data-review。这里是向当前协调方反馈问题，不递归启动完整出题流程或扩大任务范围；纯配置变更不默认重跑设计或考生审阅。常规字段映射和已定预算的配置选择自主推进；会改变用户考查目标的决定先给出具体方案，不在配置里暗加默认规则。

按任务阶段交付：数据未就绪时可完成已有信息支持的配置与静态／临时 fixture 验证，精确记录缺少的绑定、实例数或参考等依赖；不能以假正式样例绕过组装器。暂定阈值／资源不等于已校准。既无数据又无法生成实际文件时，交付明确映射及未决项，不能宣称可运行评测；用户要求正式发布时仍需完成真实数据、独立参考和发布验证。

验证要覆盖配置实际加载与执行：必要时用临时输入／参考／候选输出测试判分边界、非法输出、运行失败及基础设施错误，检查公开策略与实际 verifier 一致，资源和总 verifier 预算不冲突。发布可见范围只含必要工具与公开材料，不泄露隐藏数据、参考、凭据或 qbank/maintenance。框架适配变化时重查旧任务，验证范围与变更风险相称。

完整出题中的考生文档审阅可沿用 author-question／design-data 的三文件复核；评测配置另检查其与题面的等价性和真实执行结果，不能用文档审阅代替执行验证。重大框架／评分适配时使用独立 subagent 审阅需求到配置的映射及测试证据，再修订复核；没有执行环境或独立工具时如实报告，不冒称端到端通过。

交付实际配置／必要适配、需求到生效项的映射、所核对的框架版本或提交、验证与未决状态，并按用户偏好提交本次修改。不自动运行模型评测、生成正式案例、推送／合并或发布；这些行为按本次用户任务范围处理。配置、SDK、退出语义或装配入口变化后，同步本技能、后端参考、相关技能与 README 操作指南。已有生成包需重新校验，不能沿用过期包的通过结论；历史成绩标明所用题目及评分版本，不自动改写为当前题目的成绩。

用户要求实际运行模型 benchmark 时，由 [caeoj-run-benchmark](../caeoj-run-benchmark/SKILL.md) 协调运行、监控和结果汇总；本技能完成配置及框架适配后返回该流程，不自行追加模型尝试。
