# 实际数据审计

先读取目标题目的 instruction.md、DATA.md 和 `docs/CONTRACT.md`，再枚举全部实际输入及公开输出。三文件是对照依据，维护实现只能帮助定位问题，不能补足公开定义。本技能不替代独立设计或考生审阅。

## 盘点

题目有 data-manifest.json 时按[数据池操作](../../../qbank/maintenance/DATA-SYNC.md)核对选择、case 描述摘要及输入／参考完整性，使用现有 `data verify`；缺本地装配不等于 HF 无数据，需要获取时按指南操作，不覆盖差异或刷新绑定掩盖问题。作者证据在 `author/data-evidence/`。

```sh
python .agents/skills/caeoj-data-review/scripts/inventory.py --task qbank/<chapter>/<section>/<task> --output runs/data-review/<task>/inventory.json
```

脚本只发现 `cases/*/problem.json`、`samples/*/input/problem.json`，盘点 JSON、HDF5 元数据和网格头；examples 或其他布局须另行枚举。它不执行题目代码、不审数值参考，成功退出只表示盘点完成。按需使用当前 `caeoj info`、`validate-input`、`validate-output` 检查已装配支持和结构。

必须覆盖全部实际输入，汇总字段、条件及表示的出现／缺失变体；大数组先读元数据，按需检查切片，记录未检查部分。缺数据时审可得材料并报告资料不足，临时 fixture 不算实际数据审计。

## 对照

建立“JSON 路径／HDF5 key → 文档位置 → 约定 → 输入证据”的覆盖关系，检查：

- **文件与身份**：入口和路径基准，条件→字段→数组引用链；对象名、array key、location、Physical Group、tag 与行号的区别。
- **字段与条件**：全部必需／可选及嵌套键、类型、单位、值域、出现规则、缺省、role/operator 和常量／场表示；缺失不能擅自解释为零。
- **数组与采样**：dtype、完整 shape、轴和分量、位置／IDs 对应、时间覆盖、重建与外推；区分节点／单元、初态／初猜、输出时刻／内部步长。
- **物理含义**：材料与边界声明、坐标、法向、通量符号、基准、点值／平均／积分及观测存在与唯一性的公开定义；不以算法习惯替换题意。
- **范围与输出**：实际输入是否在题面支持范围，输出 key、复制轴、必需／可选量是否完整；数据越界单列，不扩大题意迁就数据。

解析文档中的 JSON 示例并核对字段引用；片段须标明。读取示例在临时目录或副本执行，基础读写不隐式插值，显式采样须有 sampling 声明。核查全部实际表示分支，不能用一个样例或运行无异常代表完整通过。

工具或接口变更时，从最终 DATA 独立选择有区分力的合法／非法变体，检查文档允许却拒绝、文档禁止却接受两种方向；预期不能只来自同源生成器。低影响措辞变更无需机械加测试。

## 报告与反馈

默认只写 `runs/data-review/<task>/report.md`。记录文件版本、输入数、变体和示例覆盖、缺失／未验证项；问题给出严重度、数据路径、文档位置、证据、影响及最小建议，区分文档问题、数据问题和资料不足。结论为“通过”“需修订”或“资料不足，未完成”；有影响读取的未定义分支或冲突时不能通过。

结构、契约、数值／物理和资源验证分别陈述；文件摘要一致或参考存在不证明数值准确。隐藏输入证据留维护报告，公开材料不增加标答、算法或隐藏测试提示，校验器不补物理或纠正答案。

冲突时记录双方依据，不默认数据正确。用户授权修复后按问题归属联合 [caeoj-design-data](../caeoj-design-data/SKILL.md) 或出题环节处理，重跑受影响检查。配置、打包及 benchmark 仅在本次任务包含时执行，相关操作引用对应技能与维护指南。
