# DATA 设计与验证细节

入口、任务边界及独立审阅要求见 [SKILL](../SKILL.md)。本页在设计字段或修改工具时使用；[CONTRACT](../../../../docs/CONTRACT.md)拥有通用格式，[实现职责](../../../../qbank/design/CORE-AND-EXTENSIONS.md)和[运行说明](../../../../qbank/maintenance/RUNTIME.md)拥有实现及装配机制。

## 从物理要求到数据

先区分固定事实、考生建模自由、算例变化量和观测。对可能产生不同问题的两种解释给出具体差异，再反馈题面，不用默认值填补物理欠定。

| 设计面 | 本题必须明确的内容 |
|---|---|
| 对象与条件 | 维度／降维含义、区域、材料／状态、稳态／瞬态／统计目标、初态、边界、源和基准 |
| 文件与身份 | 精确 JSON 路径、必需／可选键、类型、值域、缺省、文件路径基准；条件→fields→array 引用及 IDs 对应 |
| 条件变体 | role／variable／operator、全部嵌套 data 键、常量／场表示、quantity 标签、出现和组合规则 |
| 连续解释 | dtype、逻辑 shape、轴与分量、空间／时间重建及外推、位置覆盖、单位与符号 |
| 观测与输出 | 点值／导数／界面迹／平均／积分、作用对象与方向、采样窗口、必需／可选输出及复制轴 |

按风险检查观测存在与唯一性：允许的间断、折点或几何是否使请求量无定义；必要数据保证写明，并区分声明可检约束与数值／物理保证。不要求形式证明，不为具体反例添加无关限制。

区分初态与迭代初猜、输出时刻与内部步长、节点值与实体平均、压力与力的基准。特殊坐标／分量应有真实物理含义，不能用假空间点表达整体量。只写本题适用分支；公共规则准确引用，领域定义在 DATA 内完整。

结构易误读时给可解析 JSON 片段，标明片段及非固定数值，不强制给同构算子重复例子。资源与评分由 instruction 完整公开，维护配置不能补考生要求。

## 实现缺口的处理

- 表示、语义与工具均足够：完成 DATA，无需拓展协议。
- 通用表示可用，物理语义缺支持：在 DATA 定义语义，按能力补共享物理扩展；本题专用公开规则归本题 extension。
- 通用实体、引用或采样表达不足：联合修改 CONTRACT、Schema、读写及实际下游。
- 任务欠定或矛盾：反馈出题，不用实现隐藏修补。

变更记录需求、拥有层、影响及验证；仅支持当前接口，替换机制时同步清理调用方。领域检查只验证可判定声明，不补物理、转换单位或纠正答案。核心不依赖具体题库／物理模块；公开入口、provider 和文件白名单按运行说明核对，不复制装配机制到本技能。

SDK 基础读取不隐式插值；`sample_field` 使用显式 sampling。位置不同的条件引用须定义覆盖与重建，数组等长不能证明对应。缺参、畸形引用应返回约定诊断，避免内部异常或宽泛捕获掩盖错误。

## 按风险验证

文档变更检查字段覆盖、三文件边界、可解析片段、符号和分支一致性。工具变更按实际影响选择：

- 合法输入／输出 roundtrip；缺参、多参、错单位、引用／位置、时间覆盖及组合边界。
- 独立预期的材料响应、插值、几何积分／法向等；非连续 tag、不同排列、条件双侧与方向。
- 从最终 DATA 独立选合法／非法变体，对照工具接受与拒绝；可以借已有 fixture 作载体，不能只由被测 helper 或同源生成器决定预期。
- 受影响当前题目的回归；有性能影响时检查大网格、数组装载及启动开销。
- 装配变更后在公开包根目录普通安装，移出源码目录运行 CLI 与 SDK；不能依赖 editable checkout 或 PYTHONPATH。检查包资源、实际导入、题目绑定及多题交替读取，缺扩展须明确失败；作者工具和隐藏数据不得入包。

公开闭包验证方式见[公开接口](../../../../qbank/design/PUBLIC-INTERFACE.md)与运行说明。可复用 `qbank/maintenance/authoring/verify_install.py`，以 `--domain` 选择实际领域 fixture。开发环境安装成功不代替公开包独立安装。

临时 fixture 放忽略目录，不覆盖非空目录或冒充正式案例。实际数据审计交对应技能；数据缺失不妨碍契约交付，报告未验证部分。交付前按 SKILL 完成独立考生审阅，复核修订及受影响题目；契约、实现、数值参考和资源证据分别陈述。
