# 从题面到 DATA.md

## 1. 提取需求并识别题面问题

先读题面与 CONTRACT，区分任务事实、考生自由、算例变化量和要求输出的观测，再检查已有 DATA 及工具。维护实现和来源不是题意的替代品。

| 需求 | 需要确定 |
|---|---|
| 分析对象 | 物理维度及降维含义、区域、材料／状态、稳态／瞬态／统计目标 |
| 物理信息 | 初态、边界、源、库存和基准；哪些材料响应已给定，哪些模型允许考生选择 |
| 连续数据 | 点／实体、坐标、分量、单位、空间重建、时间及外推、唯一迹 |
| 观测 | 位置／区域、时间／统计窗口、通量方向、载荷作用对象、平均与积分 |
| 组合 | 合法与禁止组合、出现规则、可检查的声明约束及需数据保证的物理条件 |

尝试用两种合理解释读取同一题面。若会得到不同问题或观测，记录具体影响并反馈题面；别用“算法自由”补足缺失的物理条件。模型选择自由不允许改写给定材料响应，来源配置也不能变成隐藏模型约束。

观测的存在与唯一性也需检查：允许的初态、空间重建、载荷和几何可能产生折点、间断或奇异性，不能只确认输出有单位和shape。按风险尝试一个具体合法场景，核查请求的点值、导数或界面迹是否有唯一含义；需要正则性保证时明示为数据接收条件，并与可由校验器判定的声明约束分开。不强制对每题做形式证明，也不把具体领域反例复制为所有题的限制。

题面缺失时不只输出一份字段表假装已完成：在出题任务中回到 author-section，按既有规划补题面；独立 DATA 任务中先提出缺失信息与可审查方案，完成不依赖它的部分。对改变用户目标的选择请求澄清；不默认把每个接口设计决定都变成审批。

## 2. 设计本题可独立读取的契约

将需求映射到清单、场和条件，复用 Gmsh MSH 4.1 ASCII 网格、HDF5 `.h5` 数组及 JSON 声明；位置按含义选择 mesh、points、entities 或 aggregate，参数和条件使用已有常量、类型化引用、time_axis、sampling 等结构。不能仅因为新领域而重造格式。字段名称和枚举是物理对象的表达，不能隐藏数值算法或求解控制参数。

DATA 至少覆盖下列内容，按本题需要组织，不要求照抄固定标题：

- **入口与引用**：清单、文件、路径基准；条件到 fields 再到 array 的引用链；对象名、数组 key、Physical Group、实体 tag 与数组行号的区别。
- **分析与参数**：准确 JSON 路径、全部必需／可选键、类型、单位、值域、出现条件、缺省的真实含义；分析模型／版本标识不可只靠 task 推断。
- **物理解释**：本题固定的材料响应、状态关系、条件及观测含义就地写清；不替考生固定题面保留自由的闭合。无需为 CAE 题附解法、弱式推导或推荐离散。
- **条件结构**：全部 role／variable／operator 和 data 键集合、标量／场／选项表示、物理符号、区域、时间及组合规则。各字段 quantity 的允许值或明确不限制的标签规则须写清，不能只靠单位猜用途。
- **数组与连续解释**：dtype、完整 shape、分量、位置与 IDs、时间轴；空间／时间重建和外推；节点转实体平均的顺序；初态与请求时刻不同于内部时间步。
- **观测**：必需与可选输出、点值／加权平均／积分、导数及界面迹、二维厚度、压力和力的基准、输出 key 与复制的轴。不能用假点表达区域整体量。

嵌套／表示差异易误读时提供代表性 JSON 片段；结构表已能逐键还原时，无需为仅名称不同的算子重复示例。已有格式片段必须可解析并标注为片段，不冒充可运行样例。例子的数值、字段名和区间不是固定值时明确说明。仅保留本题适用分支；层流不混入湍流平均，二维不让考生阅读三维题来找补充，稳态不混列瞬态初态或多帧变化要求。

考生文件只依赖本题 instruction、DATA、CONTRACT。资源与评分完整留在 instruction，含实际指标、聚合、阈值和固定偏置，不让考生再找 GRADING 或维护记录。维护资料位于 qbank/maintenance，不作为并列契约，也不随公开工具包打包。

## 3. 判断是否需要拓展基础设施

区分以下情况，避免以“拓展协议”取代实际 DATA 交付：

| 缺口 | 处理 |
|---|---|
| 已有结构、物理语义和工具足够 | 写好本题 DATA；无需改通用协议或加一层领域文档 |
| 已有结构可表达，但新增物理语义需要支持 | DATA 定义语义，在 qbank/extensions/caeoj_ext 按物理能力补领域检查、辅助接口及受控运行描述；仅不可复用的公开规则放本题 extension/ |
| 缺少实体／引用／采样等通用表示 | 修改 CONTRACT、Schema、通用读写及必要下游，同时更新本题 DATA |
| 问题本身欠定或矛盾 | 反馈题面；不能靠增加任意默认值、隐藏投影或缩小题目绕过 |

变更前记录拥有层、受影响读者和兼容决定。相同 JSON 会产生不同物理解读时，即使字段名未变也属于语义变化；按现有版本策略说明迁移，不盲目递增，也不暗改旧数据。CFD 的四键启用只是实例，不是新题的固定模板。

按实际影响同步：核心 Schema 管通用结构，领域 Schema 与检查由共享扩展拥有；通用检查管引用、shape、dtype、IDs 和时间；领域检查管可判定的单位、参数及组合；SDK 精确读取与显式采样；评分配置匹配题面。核心不得导入具体物理模块、按章号分派或读题库目录。发布与后端共用维护层装配，不为新增扩展修改中央领域文件名清单，不需要改变的层不制造无意义代码。

考生公共入口维持 `caeoj.sdk` 和 `python -m caeoj validate-input / validate-output / grade`；`info --input` 与 `--version` 用于检查安装和契约支持。扩展选择、依赖闭包、资源与旧导入兼容由装配完成，DATA 不让考生选择扩展、调用注册函数或阅读源码。领域辅助公开门面与内部文件布局分开，旧领域 SDK 名称由受控装配适配，不能在核心重新硬编码转发。

基础读写不隐式插值；`sample_field` 只按显式 sampling 声明进行时间采样。条件引用默认使用同一 location；允许不同采样位置时，DATA 必须定义覆盖与重建关系，并由已装配的检查接口验证。不能以数组长度相同替代区域对应。

共享参数读取和物理辅助复用领域扩展，仍被 DATA 使用的 SDK／模块转发保留相同签名与语义，不在核心或多个子领域复制实现。临时 CFD 契约示例的维护入口为 `qbank/maintenance/cfd_examples.py`，不是核心模块或考生工具；使用前核对本题是否适用。

开发时安装核心及独立开发 provider：`python -m pip install -e '.[maint]'`、`python -m pip install -e qbank/extensions`；公开包在自身根目录只需 `python -m pip install .`。前者不能当作后者验证证据。可信运行描述由已安装 `caeoj_bundle` 提供，输入不能选择任意导入路径。维护装配实现在 `caeoj_tools.assembly`，调用前核对实际接口；不要根据本文凭空填写未支持的字段。

通用错误先处理，再访问领域字段；缺参数或畸形引用应返回诊断，不能 KeyError，也不以宽泛捕获掩盖缺陷。对照当前 CONTRACT 核对诊断类别、路径和 CLI 退出码，修复不一致时同步回归和读者说明；整数元数据不能误接受 bool 或 2.0。昂贵几何和连接关系按需加载，保护旧大网格任务的内存及启动行为。校验器不补物理、不转换单位、不修复答案，不宣称已证明物理适定或数值准确。

## 4. 按变更风险验证

纯文档设计首先核对字段覆盖、可解析片段、三文件依赖、分支与符号一致性，不为低影响文字调整机械加测试。新增或改变工具时，按需要验证：

- 最小合法输入及输出 roundtrip，覆盖关键配置，不机械枚举所有物理属性的笛卡尔积。
- 缺／多参数、错单位、错引用／位置、时间覆盖不足、非法组合及范围边界。
- 独立手算的材料响应、插值、简单几何积分／法向、相质量或统计量；不让被测 helper 自己生成预期值再自证。
- 非连续 tag、不同排列、边界方向及节点／单元、平均／积分的区别。
- 代表性旧合法输入、非法诊断和相关回归；有性能影响时检查相应开销。
- 公开包从自身根目录普通安装，移出源码目录后用 CLI 与 SDK 读取同一输入，核对实际导入及包资源路径；不能由本机 editable checkout／PYTHONPATH 掩盖依赖遗漏。验证缺扩展明确失败，核心可独立安装；多题装配一次安装后可交替读取，无注册覆盖。检查包中没有维护工具、author、隐藏数据或 qbank/maintenance。

用现有项目环境，不覆盖非空目录。临时解析 fixture 不写成正式案例，不证明一般求解器、数值精度或物理模型有效。已有真实数据时交由 audit-data 完整盘点，注意 inventory 的发现范围，不能用零输入报告代替实际检查。

另从最终 DATA 独立挑选容易与实现分歧的合法／非法变体，验证工具接受与拒绝的边界。优先检查有实际风险的表示分支、条件双侧与方向、相交约束及观测支持集合，不机械展开全部组合。已有 fixture 可作载体，但预期及变体选择不能只来自同一生成器、模型清单或 helper；否则文档和代码的共同遗漏可能让测试全部通过。

## 5. 独立审阅、反馈与交付

调用 [caeoj-review-statements](../../caeoj-review-statements/SKILL.md) 组织考生审阅，模式、材料边界、报告与版本复核按该技能执行；默认题面模式允许缺少样例。可与总出题流程复用同一最终版本审阅，不因技能切换重复检查未变内容。

维护方另查工具、配置与契约的双向一致性，按上节选择独立变体；考生审阅不能证明实现正确。模板按能力组合适用段落并同步修订，共享实现变化时重查所有受影响题目的 DATA 和证据。

交付 DATA、必要的 instruction 修订、工具和验证证据；维护记录保存需求映射、兼容决定、审阅意见处理及剩余限制。分别报告契约审阅、基础设施、实际数据审计、数值／物理证据和发布状态；没有数据不妨碍契约交付，也不构成真实数据审计通过。
