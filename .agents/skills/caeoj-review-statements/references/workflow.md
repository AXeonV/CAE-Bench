# 审阅流程与证据

## 确定任务与材料

目标可以是单题、节、章或整个 qbank。协调方先枚举目标题目的实际路径及必需三文件；不要因为缺失某文件而将该题从清单删除。记下基线提交、工作树状态和未提交内容，但文件SHA256才是本次实际审阅版本，提交号不能覆盖未提交修改。

明确 `statements` 或 `exam-materials`，默认前者。出题方声明数据留后时使用前者；用户明确要求按真实考试材料检查则使用后者，缺样例不是自动转换模式的理由。

确认公开资产可依据三文件的样例声明、实际公开包清单或用户明确给出的公开材料范围。协调方只把确认的资产及公开身份依据交给考生；不将含隐藏数据的整个题目目录开放给审阅者。路径名称不能替代公开性证据，也不通过读取私有参考来判断它能否公开。用户给定范围不清时可先完成三文件审阅，样例部分保留资料不足。

考试材料中的公开样例至少应有可读取输入及其声明依赖。若题目承诺公开输出，则同样检查；没有承诺时不要求出题方公开隐藏答案。JSON格式片段、空目录、链接文字或占位文件不算实际样例。不固定样例数量，但检查本次范围内全部已确认公开样例；无法完整检查时准确列出覆盖与缺口。

记录允许文件的路径、角色、SHA256及缺失项。样例清单包括输入依赖和已承诺的公开输出；目录内新增、删除文件或符号链接指向白名单外时，不自动扩大权限。可以按原相对结构将确认材料复制到 runs 内只含公开文件的快照，保持相对引用可用；不复制实现、作者工具、隐藏参考或旧报告。快照只能减少误读风险，不能冒称已构成文件系统访问隔离。

## 组织独立考生

用新上下文启动 subagent，避免继承作者的推导、旧缺陷清单或期望结论。给准确文件白名单，不给猜测的答案或预设修复方向。题目较多时分组，每题都要有覆盖记录；不要求一题一agent，也不让审阅者从维护目录选择题意。

可使用以下简短任务，并附模式、允许材料、缺失项及报告目的地：

> 你是要实现这些题目求解器的考生。仅阅读列出的公开三文件，以及本次明确允许的公开样例资产；不能借实现、隐藏输入／答案、维护规范或其他题目补题意。判断能否确定任务、接口、观测与评价。寻找具体歧义、遗漏、障碍、误导及无关或不应公开的信息，并按风险尝试反例。报告文件位置、影响和最小建议，区分明确缺陷、待核实问题与可选精炼，不要求发现固定数量。不修改材料；不要为完成审阅编写完整求解器或生成数据。记录实际读过文件的版本和覆盖，不声称执行未做的验证。

协调方可以告知通用报告格式与模式规则，不能向考生解释材料中遗漏的领域语义。无可用独立agent时，报告独立审阅未完成；作者自己的检查只能标为自审。

## 从实现者角度检查

沿着“确定任务 → 读取输入 → 建立物理／数学问题 → 计算观测 → 写结果 → 理解评分与资源”的实际顺序阅读，按题目风险重点检查：

- 固定事实、算例变化量、建模自由与方法要求是否明确，是否含隐藏模型或算法要求。
- 条件、初态、单位、基准、符号、实体身份、数组轴及表示分支能否唯一读取；是否有未声明缺省、矛盾组合或外部定义依赖。
- 连续重建、时间历史与输出时刻、点值／导数／界面迹、平均／积分是否有明确且可定义的含义。
- 评分、资源和程序接口是否足以指导提交；是否泄露不应公开的信息或保留与本题无关的模板段落。

反例应给出具体触发条件及结果差异，不必发展成数值案例。只因某类问题可能困难、非线性或欠正则，不能直接判为缺陷；先核对公开适用范围及数据保证是否已排除该场景。不要求形式证明或罗列全部物理组合，不用审阅者自己的算法偏好替换题意。外部知识不能替文档增加要求，无法确认的科学判断列为待核实。

纳入样例时，用中性的文件解析工具检查引用、身份、数组元数据及必要值，严格对照三文件；不通过源码、生成器或校验器报错反推隐藏规则。发现文件与文档冲突时记录双方依据，不默认样例正确，也不修改文档迁就样例。报告未读取的大数组部分；结构与说明一致不等于参考数值正确。若公开输出存在，可检查其格式、采样及量纲一致性，不能仅凭输出能被读取就宣称答案已验证。

样例输入可以是文档一致性的具体证据，但不是扩大问题族的唯一依据；没有样例仍可检查公开契约。考试材料模式材料不齐时继续三文件部分，保留本模式未完成状态，不能伪造样例或借隐藏数据补齐。

## 报告与复核

在本次独立目录保存报告及版本清单。无需强制新建机器Schema或固定表格，但至少明确：

1. 范围与模式：计划题目、实际审阅题目／文件／样例、未读和缺失材料、独立审阅是否执行。
2. 版本：基线提交（如有）、实际文件SHA256；缺失文件显式记录，新增文件不自动纳入。
3. 发现：严重程度、文件与行号／数据路径、触发场景或反例、影响、最小建议；分别标记明确缺陷、待核实问题、可选精炼。
4. 分开结论：题面是需修订、资料不足或本轮未发现未决问题；样例是未提供／未纳入、部分检查、资料不足或已检查。考试材料模式缺必需样例时，整体不能写完整通过，即使题面没有发现问题。
5. 限制：未检查的内容，不将公开样例一致性或反例检查扩大为隐藏数据、实现、参考精度、运行预算或整个物理领域的验证。

汇总时保留具体问题与分歧，不用多数票抹去反例。调用方负责是否修复；纯审阅任务不直接修改试题。修改后只对受影响内容请求复核，先核对其余文件确实未变；新增／删除样例也属于材料变化。旧散列不覆盖新版本。未决问题保留影响，不把首轮意见列表或测试数写成最终通过，也不以固定轮数代替判断。
