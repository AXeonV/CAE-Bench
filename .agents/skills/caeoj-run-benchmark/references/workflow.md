# 运行准备、冻结与结果核查

运行决策和完成条件见 [SKILL](../SKILL.md)，Harbor 及监控命令按需查[后端操作](harbor.md)。本页用于保存运行证据和处理续作。

## 就绪与装配

用唯一 slug 定位题目，查同请求的活动进程／job。明确新生成、续跑或冻结提交重判，核对已确认模型、推理设置、尝试数、并发和预算；重判不自动调用 Agent。

有 data-manifest.json 时按[数据操作](../../../../qbank/maintenance/DATA-SYNC.md)获取并严格核验；装配是准备步骤，数据制作及选样改变另按用户范围处理。核对全部所选输入／参考、公开样例、字段和策略绑定。已有数据审计及独立审阅可按 SHA256 与覆盖复用；疑点交对应技能处理。

用户按池 case ID 指定本次测试／样例时，先用数据工具生成临时选择（`select --revision <HF提交> --output <选择文件>`），再采用该选择完成装配和冻结，记录本次选择与既有默认清单的区别；新增入池条目不自动加入运行。缺少所需 case 时，建设工作交 [caeoj-source-cases](../../caeoj-source-cases/SKILL.md)，不以缺数据为由自动调用模型或改变范围。

确认 Docker、主机架构、空间、凭据配置和 Harbor，按[评测维护说明](../../../../qbank/maintenance/EVALUATION.md)核对实际隔离与限额。环境安装、开发回归和 Oracle 仅在准备或诊断需要时运行；Oracle 不证明一般参考精度。

通过 `publish_dist.py`、`prepare_harbor.py` 生成公开包与任务，操作见 [README](../../../../README.md#运行)，实现见[运行说明](../../../../qbank/maintenance/RUNTIME.md)。内容和绑定匹配时可复用产物；过期则重建。工具装配不制作数值样例，缺正式数据须报告。

## 冻结记录

运行前保存 `runs/benchmarks/<run-id>/plan.json` 或等价记录：

- 目标题目、源码提交及未提交状态；题面、数据、参考、每个case评分配置及资源内容哈希。
- 池 case ID、描述摘要、角色、回执实际 HF 提交；公开 ZIP 与 Harbor 任务绑定。
- 执行主机、工具版本、Agent／model／推理参数、尝试与并发、各层预算和重试上限。
- job 名称、任务／jobs／日志目录、预期 trial 数、准备及尚未验证状态。

不记录凭据值或带认证 URL。启动前再核对冻结内容，运行中不修改；需要改变条件时建立独立运行并保留前后证据。

## 监控与执行

按后端操作启动或确认 Viewer，jobs 目录与实际运行完全一致；页面验证后立即提供可点击 URL。后台任务记录 PID／工具会话、命令、日志和目录，使用可恢复会话，不把提交命令当作成功启动。

启动后核对实际解析的题目、模型、资源、尝试数及 job 路径。持续检查 trial 与 verifier 进展和错误，避免密集轮询；中断后先读进程和持久产物，再确认 resume 的范围，避免重复求解。

## 汇总

核对 job 与全部 trial 的终态、逐例覆盖、评分绑定和报告，区分未运行、考生失败、基础设施故障。送分样例按 public_cases／public_sample 单列其公开身份，仍按题目约定参与计分，不作为独立未见 case 解释。每次尝试单列，分母完整；补跑保留原因及原记录，不静默追加收费求解或挑最好成绩。

保存 `report.md` 及必要机器摘要，链接计划、原始结果和日志，报告逐例／逐次及汇总成绩、时间费用和缺口。费用无记录则注明未知；参考一致性不等于连续问题精度或预算已校准。

监控默认保留，交付地址、运行状态和精确停止方法；仅按用户要求或清理本次失败测试停止自己的服务。更新结果文档时只写本次有证据的成绩与错误分析，不改写其他条件下的成绩。外部上传、发布与推送依本次任务授权。
