# 算例建设

读取指定题目的 instruction.md、DATA.md、CONTRACT、已有作者材料和 HF 清单；按[算例制作与溯源](../../../qbank/maintenance/CASE-SOURCING.md)工作。沿用用户指定的工况、来源、求解器和计算资源；没有指定来源时自主选择适合公开题目范围的依据，直接制作，不默认停在候选方案。

1. 确定本批 case 的目标、覆盖及来源依据，区分工况出处、参考生产者与独立验证依据。来源不能增加题面未定义的假设；定义不足反馈出题／DATA，判题能力缺口交 [caeoj-configure-judge](../caeoj-configure-judge/SKILL.md)，不暗改题意迁就来源。
2. 获取可定位的原始数据，或实际执行所选求解器。用户要求某求解器计算时，完成配置、运行和结果取得；只写配置／脚本不算完成。保存可复现配方及来源、输入、转换和输出的版本／摘要关联。
3. 制作自包含输入、真实覆盖范围内的参考与逐例 grading.json。文献只有稀疏观测时使用对应评价，不补造“文献全场”；完整提交示例单独验证。通用／领域评价代码留代码仓库，不随 case 上传执行代码。
4. 检查数值依据与实际消费链；调用 [caeoj-data-review](../caeoj-data-review/SKILL.md)审计本批全部实际输入及公开输出，并处理发现。使用数值程序、参考求解器及契约／判分工具验证，不调用 LLM 作答，不启动 Agent benchmark。记录同源验证与独立比对的区别，结构通过或自判分通过不代替参考可信度。
5. 复用 [caeoj-manage-data](../caeoj-manage-data/SKILL.md)制池、上传及固定提交后的获取核验，不另写同步工具。默认只入池，保留既有测试／样例选择；staged selection 仅用于本批验证，不复制覆盖正式清单。首次入池的身份定位及临时选样按操作指南处理。

制作证据与可维护脚本保存在本题 author/，大文件和临时计算留忽略目录；入池后清理前先确认远端载荷完整，保留复现所需证据。无法获得来源、执行计算或完成验证时报告已完成范围和阻碍，不把配方、缺参考或未收敛结果报告为已验证 case。

交付 HF 提交、case ID／描述摘要、来源与制作记录、数值与契约验证结果及局限，以及之后按 ID 选样的命令。区分参考验证、入池、正式选样和模型评测；本技能默认止于已验证入池。
