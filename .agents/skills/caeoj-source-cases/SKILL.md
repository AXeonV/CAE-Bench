# 算例建设

读取指定题目的 instruction.md、DATA.md、CONTRACT、已有作者材料和 HF 清单；按[算例制作与溯源](../../../qbank/maintenance/CASE-SOURCING.md)工作。沿用用户指定的工况、来源、求解器和计算资源。要求明确、来源与适用性可核实时直接执行；关键要求缺失、来源与题目不相容或需要改变既定工况时，说明具体缺口并澄清，不自行补定关键条件。

1. 对照已有池确定新增能力覆盖及工况来源，检查几何、边界、驱动和物理状态的有效差异。不以相似解析家族的参数、坐标或命名变化凑数；确需参数系列时说明新增考查价值，未取得足够不同的可信工况就如实交付缺口。来源不能增加题面未定义的假设；定义不足反馈出题／DATA，判题能力缺口交 [caeoj-configure-judge](../caeoj-configure-judge/SKILL.md)，不暗改题意迁就来源。
2. 优先取得可追溯的公开参考数据。文献明确给出解析解时，可在核对适用条件后按原公式求值；需要数值计算时，实际运行有明确出处且适用的现成求解器。临时自编求解器不能作为参考生产者；引用底层数值库不能替代求解器出处。记录实际生产者，不以少量公开观测吻合为自行生成的其他结果提供来源。保存原始数据／公式／求解器的定位、版本和输入到输出的可复现关联；只写配置／脚本不算完成计算。
3. 制作自包含输入、可信来源实际支持的参考及逐例 grading.json。按题目能力和参考覆盖选择全场、观测点或二者结合，不预设全场优先，也不自行用少量观测替代题目承诺的整体要求。文献只有稀疏观测时不补造“文献全场”；完整提交示例单独验证。通用／领域评价代码留代码仓库，不随 case 上传执行代码。
4. 检查参考出处、生产过程、数值依据与实际消费链；共享配置或转换修复后复核受影响的成功例与失败例，资源和并行证据按制作流程保存；调用 [caeoj-data-review](../caeoj-data-review/SKILL.md)审计本批全部实际输入及公开输出，并处理发现。使用有出处的参考、求解器及契约／判分工具验证，不调用 LLM 作答，不启动 Agent benchmark。记录同源验证与独立比对的区别；守恒、低残差、网格加密和自判分通过不能替代参考出处与适用性。
5. 复用 [caeoj-manage-data](../caeoj-manage-data/SKILL.md)制池、上传及固定提交后的获取核验，不另写同步工具。默认只入池，保留既有测试／样例选择；staged selection 仅用于本批验证，不复制覆盖正式清单。首次入池的身份定位及临时选样按操作指南处理。

制作证据与可维护脚本保存在本题 author/，大文件和临时计算留忽略目录；入池后清理前先确认远端载荷完整，保留复现所需证据。无法获得来源、执行计算或完成验证时报告已完成范围和阻碍，不把配方、缺参考或未收敛结果报告为已验证 case。

交付 HF 提交、case ID／描述摘要、来源与制作记录、数值与契约验证结果及局限，以及之后按 ID 选样的命令。区分参考验证、入池、正式选样和模型评测；本技能默认止于已验证入池。
