# 历史 RC7 fast-v1

论文对齐版本见 [RC7 论文冻结快照](rc7-paper.md)。本页记录原 74 题发布物。

RC7 是基于 RC6 冻结选题构建的快速版候选发行版，保留 74 题及其全部正式评分 case，共 550 个正式 case。题目内容、case 选择和评分配置沿用 RC6；fast-v1 只缩小题目范围，不修改单题评分。

RC7 的总分按 74 题等权计算，不能与完整 82 题的 RC6 总分直接比较。RC7 排除的 8 题见发行包内 `FAST-PROFILE.json`。论文使用完整的 82 题冻结快照。这个历史子集没有新增模型调用或容器执行。

## 下载与校验

公开下载资产：[`caeoj-qbank-20261029-rc7-public-fast-v1.zip`](https://github.com/AXeonV/CAE-Bench-OJ/releases/download/caeoj-qbank-20261029-rc7/caeoj-qbank-20261029-rc7-public-fast-v1.zip)。它仅包含 74 个考生材料包、发行说明、fast profile 和对应许可材料，不包含隐藏测试、参考答案或私有判题包。

下载后验证发行资产 SHA-256，并按包内说明校验各文件。完整维护者题库包不作为公开发行资产。

## 验证边界

RC7 的公开材料及固定选题完整性检查通过。环境验证继承 RC6 记录；本次没有重新构建全部环境，也没有重新评估参考数值资格、异机资源兼容性或模型表现。因此 RC7 仍是预发布候选版，不表示所有题目的参考精度和跨环境运行均已完成验收。
