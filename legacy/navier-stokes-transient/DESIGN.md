# 瞬态题设计与解析标答

本文件只用于出题，不发布给 Agent。瞬态题不使用 Ghia 稳态表作早期时刻标答。当前 32 点均有连续解析参考，参考实现与 numerical baseline 独立。

## 启动、停止和任意离散初始剖面的通道流

令 s∈[0,H] 为跨壁坐标、e 为周期流向单位向量，ν=μ/ρ，体加速度为 ae。连续初始剖面 q₀(s) 是输入相邻网格层之间的分片线性函数；它沿周期方向不变。壁面在 t>0 固定为 U₀e、U₁e。

稳态剖面 `q∞(s)=U₀+(U₁−U₀)s/H+a s(H−s)/(2ν)`。

`u(s,t)=e[q∞(s)+Σₙ₌₁∞ bₙ sin(nπs/H) exp(−ν(nπ/H)²t)]`，`p=0`。

`bₙ=(2/H)∫₀ᴴ[q₀(s)−q∞(s)]sin(nπs/H)ds`。

分片线性初值的积分在每个区间精确计算：若 q₀(s)=ms+c，κ=nπ/H，则原函数为 `−q₀(s)cos(κs)/κ+m sin(κs)/κ²`。稳态剖面的系数为：

`b∞,n = 2[U₀−(−1)ⁿU₁]/(nπ) + 2aH²[1−(−1)ⁿ]/[ν(nπ)³]`。

取初值系数减去上述系数。对于静止初值、上壁突然运动的纯库埃特启动，`bₙ=2U₁(−1)ⁿ/(nπ)`；纯泊肃叶启动取 U₀=U₁=0。停止剪切、多个模式、带符号局部初值均使用同一积分定义，不把生成配方当作连续初值。

实现保留 1,024 项；t₁ 保证 νt₁/H²≥0.001。系数尾界 `|bₙ|≤2B`，B 可取 `sup|q₀|+sup|q∞|`，遗漏误差用 `2B∫₁₀₂₄∞exp(−ν(π/H)²t₁ z²)dz` 上界，写入每例 analytic.json。t=0 直接复制初始节点值，不用截断级数逼近不相容的壁面起始值。

## 具有非零对流的二维周期解析流

正方形边长 L，κ=2πm/L，m∈{1,2}；常数平移速度 (cₓ,cᵧ)、幅值 A、相位 (φₓ,φᵧ)。定义：

`X=κ(x−x₀−cₓt)+φₓ`，`Y=κ(y−y₀−cᵧt)+φᵧ`，`a(t)=A exp(−2νκ²t)`。

`u=cₓ+a(t)sin(X)cos(Y)`。

`v=cᵧ−a(t)cos(X)sin(Y)`。

`p=ρa(t)²[cos(2X)+cos(2Y)]/4`。

这是带 Galilean 平移的衰减 Taylor–Green 周期流。直接代入可得 `∇·u=0`，速度的非线性自对流由压力梯度平衡，常数平移导致实际空间相位随时间移动。体加速度为零，压力面积平均值为零。公式由本项目直接代入验证；初值属于题目定义的低阶三角多项式空间，节点样本唯一确定它。

没有平移时，速度虽可通过分量扩散得到，但压力仍不为零；加入平移后，忽略对流连速度演化也会出错。测试分别变化平移方向、双向平移、波数、相位、幅值、ρ/μ、空间尺度、稀疏 tag 和二进制网格，不仅改变输出时间的量纲。

初始压力不是给定独立自由度；t=0 压力由不可压缩方程及零均值规范决定。不得复制初始速度后把所有时刻压力写零。

## 同一特征值的叠加涡旋

令 `f(X)=(sin X,cos X)`、`f(Y)=(sin Y,cos Y)`，C 是任意实 2×2 矩阵，X、Y 与上一节相同：

`ψ=exp(−2νκ²t) f(X)ᵀ C f(Y)/κ`，`w=(ψ_y,−ψ_x)`，`u=c+w`。

`p=ρ[exp(−4νκ²t)Σ Cᵢⱼ²/2−(|w|²+2κ²ψ²)/2]`。

每个基函数均满足 `−Δψ=2κ²ψ`。由二维恒等式，`(w·∇)w=∇[(|w|²+2κ²ψ²)/2]`；速度扩散与指数衰减抵消，常数 c 的对流与相位平移抵消，因此上述压力给出完整 NS 解。面积平均 `|w|²` 为 `exp(−4νκ²t)ΣCᵢⱼ²/2`，`2κ²ψ²` 具有同一平均值，所加常数正好保证 p 零均值。

C 只有左上项 A 非零时是上一节单涡旋。新增矩阵行列式均非零，具有两个独立方向组合，无法仅通过改变单涡旋幅值与相位得到。节点数据仍落在原有初始场范围内，输入无需新增字段。

## 斜向周期剪切波

取整数波向量 `(wₓ,wᵧ)`，`k=2π(wₓ,wᵧ)/L`，`d=(kᵧ,−kₓ)/|k|`。定义：

`u=c+A d sin[k·(x−x₀−ct)+φ] exp(−ν|k|²t)`，`p=0`。

因为 d·k=0，散度与剪切自身对流为零；c·k 不为零时存在平移对流，扩散因子为 `exp(−ν|k|²t)`。测试改变波向量方向和符号，包括 (1,2)、(2,−1)、(0,2)、(1,−1)，所有初始波数均在绝对值≤2 的范围内。该类与叠加涡旋使用相同的双周期数据接口。

## 判分、资源与独立 baseline

18 个通道点、14 个二维周期点，25～4,225 节点、32～8,192 三角形。新增通道将非零、振荡、局部脉冲初值与运动壁和体力同时组合，不仅测试从静止启动。输出时间有 6～8 个，包含早期快速变化和较晚衰减阶段，间隔不等距。每点速度绝对容差 0.02 m/s、压力绝对容差 0.02 Pa，rtol=0，全部要求值通过才得 1 分。

baseline 使用输入网格和数据：通道以有限差分离散、Crank–Nicolson 时间积分及起始 Rannacher 步求解；二维周期问题采用去混叠 Fourier 谱离散、Leray 投影及 RK4，并从数值对流计算压力。baseline 不导入解析公式、参数配方或标答。

输出时刻与内部步长分离。baseline 内部选择步长满足自身扩散和对流稳定性，题目没有强制 CFL 数、每步固定迭代数或固定时间步。单点限制 5 秒、1,024 MiB，网格上限和输出时刻经 baseline 检查；具体结果记录于 runs。

当前没有瞬态方腔点：Ghia 1982 提供的是稳态中线，不能成为瞬态真值。后续若引入启动方腔，需要另行获取独立且经过网格、时间收敛验证的瞬态基准，不用 baseline 反过来充当标答。
