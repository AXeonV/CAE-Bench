# Case 判题链路测试

本题测试完整物理场提交与 case 级判题，不考查 PDE 求解。读取输入的二维节点速度场，原样回传全部节点、全部时刻及 x、y 两个分量。节点 tag、时间和分量的对应关系必须保留，不能将 tag 当作行号。

启动方式：`python solve.py --input problem.json --output result.h5`。数据定义见 [DATA.md](DATA.md)，通用文件规则见 [CONTRACT.md](../../../../docs/CONTRACT.md)。考生无需输出测点值、中线速度或额外评价结果。

每例墙钟上限 10 秒，含启动、读入和写出。环境为 Linux AMD64、无 GPU；不设本题专用 CPU／内存配额。合法输入最多 1,000 个节点、100 个输出时刻。

评分首先完整检查输出契约，包括未被数值检查选中的分量。每例从下列检查中选一个或多个，全部选中检查通过得 1 分，否则得 0 分：

- **整场检查**：在全部输出节点和时刻，比较回传值与输入值。
- **测点检查**：在三角形内、共边或外边界上的点，用提交的节点值作三角形一阶重心插值（P1 重建），比较同样重建的输入场。每项可选择 x、y 或按 x、y 顺序组成的两个分量，并选择输入已列出的一个或多个精确时刻。无时间插值。共边两侧重建具有相同边上节点值，因此共边取值一致。

以上每个被比较的标量都须满足 `|结果−参考| ≤ 1e-10 m/s`，不使用相对容差，不跨点、时间或分量平均。测点检查采用所选三角形的重心坐标；边界舍入容许 64 倍 float64 机器精度，夹到 [0,1] 后归一化。合法评价点都位于包含三角形内。

评分器选择检查范围并完成提取；无论选中哪些检查，正确目标始终是完整回传输入场，考生不必读取机器判题配置推断输出要求。未被选中的值仍必须满足完整输出格式，但没有额外数值判据。公开样例仅提供随机输出格式示例；输入／参考／配置错误属于评测基础设施错误，不算考生失分。

## 公开格式样例

`samples/01/`、`samples/02/` 仅展示输入与输出结构。其 `output/result.h5` 为随机生成的格式示例，只保证数组结构、dtype、IDs和时间轴符合输入要求，不保证数值答案正确，也不作为本地数值判分依据。正式case使用独立的隐藏参考判分。
