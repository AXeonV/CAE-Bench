# 二维瞬态热传导

给定矩形域、常数导热系数 k、常数体积热容 C、初始温度和四条边的条件，求指定时刻所有网格节点的温度 T：

`C ∂T/∂t = k(Txx + Tyy)`，t > 0，无热源。

初始温度由网格节点值给出，在每个三角形内按线性函数解释。边界条件随时间不变，n 为向外单位法向：

| `operator` | 边界方程 |
|---|---|
| `dirichlet` | T=0 |
| `normal_derivative` | ∂T/∂n=0 |
| `normal_flux` | −k∂T/∂n=0 |
| `robin` | αT+β∂T/∂n=0 |

Dirichlet 边界的初始节点温度为零。其他条件要求在 t>0 满足，不要求初始场在边界上的法向导数相容。初始温度可以为负。

## 输入范围

输入遵守[通用数据协议](../../../../docs/CONTRACT.md)，字段含义见 [DATA.md](DATA.md)。

| 项目 | 范围 |
|---|---|
| 矩形 | x0,y0∈[−5,5] m；Lx,Ly∈[0.5,3] m，长短边比≤3 |
| 材料 | 0.05≤k≤20 W/(m·K)；0.5≤C≤20 J/(m³·K) |
| 网格 | Gmsh MSH 4.1 ASCII，一阶三角形和边界线段；9～8,000 节点，8～16,000 三角形 |
| 初始温度 | float64 节点值，绝对值≤10 K |
| Robin | 0.1≤α≤10 W/(m²·K)，0.05≤β≤20 W/(m·K) |
| 输出时刻 | float64，6～12 个，含 t=0，严格递增，末时刻≤4,000 s |
| 首个正输出时刻 | `(k/C)t₁ / max(Lx,Ly)² ≥ 0.003` |

网格和边界分组保证一致，无孤立或退化单元。输入给出的时间轴只规定输出时刻；程序自行选择内部固定或自适应时间步、迭代和收敛策略，满足精度与资源要求。

## 输出与判分

接口：`python solve.py --input problem.json --output result.h5`。

输出包含原样复制的 `node_ids`、`times`，以及 float64 `temperature`，shape `[输出时刻数,节点数,1]`，单位 K。t=0 的温度为输入给定的初始节点温度。

对每个请求输出物理量、每个标量分量和每个请求时刻，分别沿空间位置计算加权归一化均方根误差：

`e = sqrt(sum_i(w_i*(a_i-r_i)^2)/sum_i(w_i)) / max(sqrt(sum_i(w_i*r_i^2)/sum_i(w_i)), scale_floor)`。

`a_i` 为提交值，`r_i` 为参考值；采用下述已声明的评分变换或参考尺度偏置时，按对应定义代入。不同物理量、分量或时刻分别计算空间 NRMSE，不拼接原始数值。本例的 `total NRMSE` 定义为全部这些 `e` 的等权均方根 `E=sqrt(sum(e_j^2)/M)`，其中 `M` 为 NRMSE 组数，全部请求时刻均参与，包括初始帧；全部观测位置均参与，包括边界及零值。

每例连续得分：`E <= 0.05` 得 1 分；`0.05 < E < 0.10` 得 `(0.10-E)/0.05` 分；`E >= 0.10` 得 0 分。题目 reward 为全部正式 case 得分的算术平均值，不按字段数量或空间点数量给 case 加权。

空间位置采用等点权重 `w_i=1`；这是对请求观测位置的误差评价，不推断网格体积或积分权重。单个整体观测也使用该规则。

除 DATA 明确声明的评分变换外，候选和参考均按规定表示直接比较，不平移、去均值、拟合比例或对齐场。

`scale_floor` 是与本输出同单位的正数下限，防止零参考或很小的参考导致除零或尺度失控。本题明确采用：

| quantity | scale_floor | 单位 |
|---|---|---|
| `temperature` | 0.02 | `K` |

IDs、时间轴、shape、dtype 和有限值要求仍须严格满足；整数及布尔输出精确比较。程序失败、超时、超资源、缺失或非法输出得 0 分；输入、参考或评价基础设施错误不算考生失分。守恒、低残差和正常退出不替代目标观测准确性。

每例墙钟限时 **5 秒**，内存 **1,024 MB**（按 1 MB=2²⁰ 字节计）。
