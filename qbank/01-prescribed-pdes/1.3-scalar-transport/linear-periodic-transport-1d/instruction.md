# 一维周期线性输运

本文与 [DATA.md](DATA.md) 及[通用协议](../../../../docs/CONTRACT.md)共同定义要求。

在区间 [0,1] m 上求无量纲标量 u：

\[\partial_t u+b\partial_x u=0.\]

b 是输入给定的恒定速度，单位 m/s。左右端周期连接，无扩散和源项。输入网格将区间划为 1024 个等长线单元，每个初始值定义该单元内部的常数；单元交界的单点值不影响要求的积分平均。初态允许间断，采用线性输运方程的周期弱解。

求解程序应处理任意满足公开范围的初态、速度及请求时刻：b∈{0.1,0.2,0.4,0.7,1,2,4,7} m/s；初始值有限且绝对值不超过 1000；时刻含 0、严格递增，0≤t≤2 s，1～201 个时刻。输出每个原单元上 u 的长度平均值，初始时刻输出给定的初值。请求时刻不规定内部时间步，观测网格不限制内部离散；解析和数值方法均可使用。

接口为 `python solve.py --input problem.json --output result.h5`。Python 入口可以调用其他语言实现。所有输入引用相对 problem.json 所在目录解析。必须按实际字段引用、IDs 和时间轴读取并输出，不能通过 ID 数值推断空间次序。结果 HDF5 仅包含 DATA 指定的输出及其固定轴。

对全部时刻和全部单元分别比较，要求 `|结果−参考| ≤ 1e−6 + 1e−6×|参考|`。任一点超限或结果结构非法，本例为 0 分；全部通过为 1 分。多例成绩为通过例数除以本次明确选择的例数。没有固定默认测试集合。

每例墙钟上限 120 秒、2 CPU、2048 MB 内存，结果文件上限 16777216 字节。超时、非零退出或缺少结果，本例为 0 分。
