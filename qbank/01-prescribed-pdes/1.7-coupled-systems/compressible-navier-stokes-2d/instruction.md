# 二维可压缩 Navier–Stokes

本文与 [DATA.md](DATA.md) 共同定义求解要求。DATA.md 中的字段、位置、数组关联和采样规则也是题目的一部分。

## 数学问题

定义域为 [0,1]×[0,1] m²。

求密度 ρ、速度 v 和热力学压力 p：

\[\partial_t\rho+\nabla\cdot(\rho v)=0,\]
\[\partial_t(\rho v)+\nabla\cdot(\rho v\otimes v+pI)=\nabla\cdot Q,\]
\[\partial_tE+\nabla\cdot((E+p)v)=\sum_j\partial_j\!\left(\sum_i v_i Q_{ij}\right),\]
\[E=\frac{p}{\gamma-1}+\frac12\rho|v|^2,\qquad
Q_{ij}=\rho\left[\eta+\left(\zeta+\frac{\eta}{3}\right)\delta_{ij}\right]\partial_jv_i.\]

Q 为黏性动量通量张量，(∇·Q)_i=∑_j∂_jQ_ij；I 为本题空间维数的单位矩阵。i、j 遍历本题空间维数，δ_ij 为 Kronecker 符号。E 为单位体积总能量，γ 为比热比，η、ζ 为固定运动学黏性系数（m²/s）。这是密度加权、按方向定义的 黏性模型；不添加未给出的交叉导数或热传导项。

初始 ρ、v、p 在各单元内分别为给定常数，由它们构造初始守恒量。记平均_K(f)=|K|⁻¹∫_K f，矢量按分量平均；|K| 为原输入单元 K 的长度、面积或体积。以下“平均”均指平均_K。输出采用守恒量的单元平均后反算的状态：ρ_out=平均(ρ)，v_out=平均(ρv)/ρ_out，p_out=(γ−1)[平均(E)−|平均(ρv)|²/(2ρ_out)]。这些定义在 t=0 与输入相同；在非均匀场中 v_out 和 p_out 无须等于 v、p 的体积平均值。

## 初始与边界条件

两个方向均周期：ρ、v、p 及所需导数周期相等。

## 输入范围

输入遵守[通用数据协议](../../../../docs/CONTRACT.md)，采用 Gmsh 网格、JSON 元数据和 HDF5 场。采样值的连续含义见 [DATA.md](DATA.md)。

等长矩形单元；0≤t≤1 s；所有初始值有限，ρ、p 严格正。支持的原输入网格与参数组合为：512×512 对应 (η,ζ)=(10⁻⁸,10⁻⁸)，128×128 对应 (η,ζ)=(0.01,0.01) 或 (0.1,0.1)。这些网格规定初值和输出积分单元，不限制程序内部求解网格。

| 参数 | 定义与支持值 |
|---|---|
| `gamma` | γ=5/3；单位 `1` |
| `shear_viscosity` | η：密度加权定向模型的运动学剪切系数；单位 `m2/s` |
| `bulk_viscosity` | ζ：密度加权定向模型的运动学体系数；单位 `m2/s` |

初值、参数和请求时刻以输入为准；ID 只表示实体身份，不表示空间次序。

程序自行选择语言、库、空间离散、内部固定/自适应时间步及收敛策略；不得改变方程、域、条件、单位或输出时刻。

请求时刻数为 1～9（包括 t=0），具体时刻从输入时间轴读取。

## 输出与提交

接口：`python solve.py --input problem.json --output result.h5`。Python 入口可以调用其他语言实现，题面不要求核心计算使用 Python。

输入中的包内文件路径相对 `problem.json` 所在目录解析。读取 JSON 声明的文件和数组引用；按每个输出的 `location` 与 `time_axis` 排列空间行和时间行，将结果写入其 `array` 指定的 HDF5 键。IDs 和时间轴原样复制，结果保存到 `--output` 指定路径。

输出 `density[T,N,1]`（kg/m3）、`velocity[T,N,2]`（m/s）、`pressure[T,N,1]`（Pa），并原样附带输入的 IDs 和 `times`；N 为要求输出的位置数量，T 为请求时刻数。字段均为 float64，具体 quantity、location、value_kind、分量顺序和时间轴见 [DATA.md](DATA.md)。

公开格式样例位于 `samples/01/` 与 `samples/02/`。

## 判分与运行资源

对每个请求输出物理量、每个标量分量和每个请求时刻，分别沿空间位置计算加权归一化均方根误差：

`e = sqrt(sum_i(w_i*(a_i-r_i)^2)/sum_i(w_i)) / max(sqrt(sum_i(w_i*r_i^2)/sum_i(w_i)), scale_floor)`。

`a_i` 为提交值，`r_i` 为参考值；采用下述已声明的评分变换或参考尺度偏置时，按对应定义代入。不同物理量、分量或时刻分别计算空间 NRMSE，不拼接原始数值。本例的 `total NRMSE` 定义为全部这些 `e` 的等权均方根 `E=sqrt(sum(e_j^2)/M)`，其中 `M` 为 NRMSE 组数，全部请求时刻均参与，包括初始帧；全部观测位置均参与，包括边界及零值。

每例连续得分：`E <= 0.05` 得 1 分；`0.05 < E < 0.10` 得 `(0.10-E)/0.05` 分；`E >= 0.10` 得 0 分。题目 reward 为全部正式 case 得分的算术平均值，不按字段数量或空间点数量给 case 加权。

空间位置采用等点权重 `w_i=1`；这是对请求观测位置的误差评价，不推断网格体积或积分权重。单个整体观测也使用该规则。

除 DATA 明确声明的评分变换外，候选和参考均按规定表示直接比较，不平移、去均值、拟合比例或对齐场。

`scale_floor` 是与本输出同单位的正数下限，防止零参考或很小的参考导致除零或尺度失控。本题明确采用：

| 输出字段 | scale_floor | 单位 |
|---|---|---|
| `density` | 0.1 | `该输出声明的单位` |
| `velocity` | 0.1 | `该输出声明的单位` |
| `pressure` | 0.1 | `该输出声明的单位` |

IDs、时间轴、shape、dtype 和有限值要求仍须严格满足；整数及布尔输出精确比较。程序失败、超时、超资源、缺失或非法输出得 0 分；输入、参考或评价基础设施错误不算考生失分。守恒、低残差和正常退出不替代目标观测准确性。

每例求解程序墙钟上限 600 秒，环境 CPU 8 vCPU、内存上限 24 GiB；结果文件大小上限 268435456 字节。超时、非零退出、缺少结果或结果结构非法均为本例 0 分。
