# 2.1.8 3D 非牛顿流体不可压缩流动瞬态分析

生产可复用求解器，完成输入所描述的3维空间单相层流分析。

密度为正常数，流体为无记忆的广义牛顿流体。须支持带剪切率上下限的幂律、Cross、Carreau 和 Carreau–Yasuda 四种材料响应，具体种类与参数由输入给定；不支持屈服应力、黏弹性或触变。

从输入给出的物理初态出发，计算全部指定时刻的流动。初始速度是物理状态，不是任意迭代初猜；不将时间平均代替瞬时输出。

几何、材料参数、边界及体加速度由每个算例提供。三维流量与载荷为实际空间积分量。输出请求的速度、压力及其他适用观测。

接口定义见[本题 DATA.md](DATA.md)，通用存储规则见[CONTRACT.md](../../../../docs/CONTRACT.md)。这三份文件构成本题完整要求。

## 任务

实现一个可复用求解器，读取算例给出的流体域、材料、机械条件及观测要求，计算相应流动。几何、材料参数、条件分布与观测位置均可能变化。一次提交冻结后用于该题的全部算例。

允许自行选择语言、软件、内部网格、离散、线性／非线性求解和收敛策略。可以使用解析或降阶方法，只要覆盖下述范围并达到相同精度。不得改变输入所定义的物理对象、材料响应、边界、初值、压力基准或观测时刻。提交接口不限制核心计算必须用 Python。

## 物理范围

单相连续介质、层流、固定流体域，无反应、相变或待求的温度场。温度由输入给定并保持均匀恒定；不计算热量传递或温升。体加速度可随位置及时间变化，未给出时为零。

本题求完整三维流动；流量与载荷使用实际空间积分。

域按单元公共边／面连通，可以有内孔和多个障碍物。边界可以静止或给定切向壁面运动；壁面运动不改变域的几何。支持条件及其组合见[本题 DATA.md](DATA.md)。不存在隐含的重力、参考系旋转、壁面粗糙度或入口扰动。

从给定物理初态演化至请求时刻，输入时间轴不是内部时间步长。算例保证初态和边界相容，且所需物理解可确定。

## 输入支持范围

- 网格为 Gmsh MSH 4.1 ASCII、一阶单元。流体单元为四面体／六面体／棱柱／金字塔，边界为三角形或平面四边形。允许混合单元，域边界以给定网格的分片直线／平面为准。
- 每例至多 50,000 个流体单元、100,000 个节点、101 个不同的输出时刻；全部输出数组合计至多 5,000,000 个 float64 标量分量。
- 一个流体域、一个空间均匀的材料；材料参数取值范围与严格正值／非负值约束见数据说明。输入和所求状态均在材料有效范围内，几何及条件满足层流分析的适用性。
- 正式算例采用非退化网格，并须经独立基准程序验证：在相同运行资源内达到本题精度。不会仅凭参数合法就将极端时间跨度、尺度比或病态网格纳入测试；考生无须覆盖所有有限正数参数的任意病态组合。
- 不要求支持屈服、黏弹性、触变、多相、湍流、轴对称、网格运动或流固耦合。

## 评价

对每个请求输出物理量、每个标量分量和每个请求时刻，分别沿空间位置计算加权归一化均方根误差：

`e = sqrt(sum_i(w_i*(a_i-r_i)^2)/sum_i(w_i)) / max(sqrt(sum_i(w_i*r_i^2)/sum_i(w_i)), scale_floor)`。

`a_i` 为提交值，`r_i` 为参考值；采用下述已声明的评分变换或参考尺度偏置时，按对应定义代入。不同物理量、分量或时刻不拼接、不取平均。本例的 `total NRMSE` 定义为这些 `e` 的最大值 `E=max(e)`，全部请求时刻均参与，包括初始帧；全部观测位置均参与，包括边界及零值。

每例连续得分：`E <= 0.05` 得 1 分；`0.05 < E < 0.10` 得 `(0.10-E)/0.05` 分；`E >= 0.10` 得 0 分。题目 reward 为全部正式 case 得分的算术平均值，不按字段数量或空间点数量给 case 加权。

空间位置采用等点权重 `w_i=1`；这是对请求观测位置的误差评价，不推断网格体积或积分权重。单个整体观测也使用该规则。

除 DATA 明确声明的评分变换外，候选和参考均按规定表示直接比较，不平移、去均值、拟合比例或对齐场。

`scale_floor` 是与本输出同单位的正数下限，防止零参考或很小的参考导致除零或尺度失控。本题明确采用：

| quantity | scale_floor | 单位 |
|---|---|---|
| `velocity` | 0.001 | `m/s` |
| `pressure` | 0.1 | `Pa` |
| `density` | 0.0001 | `kg/m3` |
| `dynamic_viscosity` | 1e-06 | `Pa.s` |
| `shear_rate` | 0.01 | `1/s` |
| `traction` | 0.1 | `Pa` |
| `force` | 0.001 | `N` |
| `volume_flow` | 1e-06 | `m3/s` |
| `mass_flow` | 1e-06 | `kg/s` |

IDs、时间轴、shape、dtype 和有限值要求仍须严格满足；整数及布尔输出精确比较。程序失败、超时、超资源、缺失或非法输出得 0 分；输入、参考或评价基础设施错误不算考生失分。守恒、低残差和正常退出不替代目标观测准确性。
