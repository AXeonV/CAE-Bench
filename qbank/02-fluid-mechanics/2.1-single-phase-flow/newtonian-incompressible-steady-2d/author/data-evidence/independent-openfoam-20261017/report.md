# 19 例独立交叉验证结论

实际执行 OpenFOAM Foundation incompressibleFluid：19 例 × 16/24/32 三档网格，共 57 次最终计算。19/19 例全部网格收敛，57 个网格均通过 checkMesh。19/19 例通过本次交叉验证判据，现有实际 grade_case 消费链 19/19 得 1。

全部 1653 个观测点、9918 个请求标量分量均比较；最细网格的跨求解器最大绝对差分别为：速度 0.000298484167 m/s、压力 0.000261968772 Pa、剪切率 0.00136002695 1/s。全批最大题面容差占比为 0.218312，位于 001 的 velocity。

最终两档 24→32 网格的最大差异为题面容差的 0.147350 倍。经验验收要求：全部实际分量跨求解器差异不超过题面容差，最后两档网格差异小于对应容差的 25%，且全部最终计算收敛。完整的 16→24、24→32 差异及每档与原参考的差异均保存，未丢弃较粗档结果。
