# 2.1.3 3D 常黏度牛顿流体不可压缩流动稳态分析

生产可复用求解器，完成输入所描述的3维空间单相层流分析。

密度和动力黏度均为正常数。流体为不可压缩牛顿流体，不考虑材料随剪切变化。

求给定驱动下不随物理时间变化的流动。输入无物理初值；不得把某个任意瞬态末帧直接定义为本题答案。

几何、材料参数、边界及体加速度由每个算例提供。三维流量与载荷为实际空间积分量。输出请求的速度、压力及其他适用观测。

接口定义见[本题 DATA.md](DATA.md)，通用存储规则见[CONTRACT.md](../../../../docs/CONTRACT.md)。这三份文件构成本题完整要求。

## 任务

实现一个可复用求解器，读取算例给出的流体域、材料、机械条件及观测要求，计算相应流动。几何、材料参数、条件分布与观测位置均可能变化。一次提交冻结后用于该题的全部算例。

允许自行选择语言、软件、内部网格、离散、线性／非线性求解和收敛策略。可以使用解析或降阶方法，只要覆盖下述范围并达到相同精度。不得改变输入所定义的物理对象、材料响应、边界、初值、压力基准或观测时刻。提交接口不限制核心计算必须用 Python。

## 物理范围

单相连续介质、层流、固定流体域，无反应、相变或待求的温度场。温度由输入给定并保持均匀恒定；不计算热量传递或温升。体加速度可随位置变化、时间恒定，未给出时为零。

本题求完整三维流动；流量与载荷使用实际空间积分。

域按单元公共边／面连通，可以有内孔和多个障碍物。边界可以静止或给定切向壁面运动；壁面运动不改变域的几何。支持条件及其组合见[本题 DATA.md](DATA.md)。不存在隐含的重力、参考系旋转、壁面粗糙度或入口扰动。

求不随物理时间变化的流动。输入无物理初态，迭代初猜由程序选择；算例保证请求观测可确定，不要求选择未知的多稳态分支。

## 输入支持范围

- 网格为 Gmsh MSH 4.1 ASCII、一阶单元。流体单元为四面体／六面体／棱柱／金字塔，边界为三角形或平面四边形。允许混合单元，域边界以给定网格的分片直线／平面为准。
- 每例至多 50,000 个流体单元、100,000 个节点、101 个不同的输出时刻；全部输出数组合计至多 5,000,000 个 float64 标量分量。
- 一个流体域、一个空间均匀的材料；材料参数取值范围与严格正值／非负值约束见数据说明。输入和所求状态均在材料有效范围内，几何及条件满足层流分析的适用性。
- 正式算例采用非退化网格，并须经独立基准程序验证：在相同运行资源内达到本题精度。不会仅凭参数合法就将极端时间跨度、尺度比或病态网格纳入测试；考生无须覆盖所有有限正数参数的任意病态组合。
- 不要求支持屈服、黏弹性、触变、多相、湍流、轴对称、网格运动或流固耦合。

## 提交与运行

入口为 `solve.py`，每例独立启动：

```sh
python solve.py --input /path/to/problem.json --output /path/to/result.h5
```

文件路径以参数为准，输入内的相对路径相对于 `problem.json` 所在目录解析。程序成功时以 0 退出，并将完整结果写至 `--output`；日志可写标准输出／错误，不作为答案。辅助代码和运行依赖须在评测前准备完成，逐例运行无需网络。

每例墙钟时限 **600 秒**（含启动、读取、计算和写出），**4 个 CPU、4 GiB 内存、无 GPU**。运行环境为 Linux AMD64，提供 Python 3、NumPy、SciPy、h5py、Gmsh、jsonschema，以及 g++、OpenMP、Open MPI、HDF5 开发库；可以自行准备兼容的其他依赖。所有输入共享这些上限，不要求程序依赖特定软件。

按 `outputs` 中的声明计算全部输出；不要求输出内部迭代场、残差、求解过程或建模报告。结果文件中的 IDs、时间轴及数组结构必须精确符合输入。

## 评价

每例得 0 或 1 分，逐题成绩为通过例数除以该题总例数。结构合法、正常退出且全部输出通过数值检查才得 1 分；超时、超内存、非零退出或缺失／非法输出得 0 分。输入或参考材料错误不计作考生失分。

对每个输出时刻、位置和标量分量，要求

`|计算值 − 参考值| ≤ atol + 0.01 × |参考值|`。

所有值均须通过，不剔除边界、初始时刻、零值或个别分量。`atol` 按输出 `quantity` 取下表，单位与该输出一致；相对容差均为 0.01。IDs 和时间轴不参与近似比较。

| quantity | atol | 单位 |
|---|---|---|
| velocity | 0.001 | m/s |
| pressure | 0.1 | Pa |
| density | 0.0001 | kg/m3 |
| dynamic_viscosity | 0.000001 | Pa.s |
| shear_rate | 0.01 | 1/s |
| traction | 0.1 | Pa |
| force | 0.001 | N |
| volume_flow | 0.000001 | m3/s |
| mass_flow | 0.000001 | kg/s |

压力按声明的表示和基准直接比较，不在判分时平移、去均值或重新对齐。积分与平均按本题 DATA.md 比较，不以网格节点的算术平均替代。只检查算例实际请求的输出，各输出同等构成本例通过条件。
