# 2.11.4 非等温广义牛顿流体瞬态分析

生产可复用求解器，处理3维瞬态问题族。求三维不可压缩Carreau液体流动与温度，包含温黏反馈和黏性耗散。该题无记忆，区别于本节构象及触变能力，也区别于2.1的等温流变。

几何、材料、边界分布、物理初态、请求时刻均由每个算例明确给定；求解算法、内部网格与软件自由，解析或降阶方法满足整个契约也有效。不得由题号或来源推断未声明参数，不改变材料、闭合或边界定义。

完整要求见[共同要求](../COMMON.md)、[本题DATA](DATA.md)、[公共DATA](../DATA.md)及[模型协议](../../../../docs/FLUID-REDUCED.md)。本题采用其中`fluid-reduced-thermal-generalized-newtonian-v1`，不默认扩张到同节其他模型。

入口：`python solve.py --input problem.json --output result.h5`。按outputs计算全部请求观测，输出真实IDs及给定时间轴。资源与评价设计目标见共同要求，真实算例与参考尚未制作，不表示数值精度已验证。
