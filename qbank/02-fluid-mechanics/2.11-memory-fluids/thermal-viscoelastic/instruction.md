# 2.11.5 非等温黏弹性流体瞬态分析

生产可复用求解器，处理2维瞬态问题族。从速度、温度及构象初态演化二维不可压缩热Oldroyd-B液体。黏度与松弛时间共享公开温度移位因子，聚合物弹性能与溶剂／松弛耗散分开记账；不含相变或化学反应。

几何、材料、边界分布、物理初态、请求时刻均由每个算例明确给定；求解算法、内部网格与软件自由，解析或降阶方法满足整个契约也有效。不得由题号或来源推断未声明参数，不改变材料、闭合或边界定义。

完整要求见[共同要求](../COMMON.md)、[本题DATA](DATA.md)、[公共DATA](../DATA.md)及[模型协议](../../../../docs/FLUID-REDUCED.md)。本题采用其中`fluid-reduced-thermal-viscoelastic-v1`，不默认扩张到同节其他模型。
