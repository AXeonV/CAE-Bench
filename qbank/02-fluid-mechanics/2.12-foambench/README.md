# 2.12 FOAMBench 兼容题集

本节保留全部 110 道 Basic 与 16 道 Advanced 的独立题目身份，使用本题库题面和通用数据协议。各题明确物理、材料及模型责任，软件与数值实现自由。

本节是具体问题的兼容专题，不代替 2.1—2.11 的 general problem 核心能力题。源题只有数值设置不同、物理上重复的情形仍保留对应关系，不能按题数推断独立能力覆盖。

当前仅交付题面与 DATA 文档，无实际输入、样例、参考或评测配置，尚未绑定模型校验器。数值精度与资源限制没有校准，不表示可以发布评测。各题公开阅读材料为本题 instruction.md、DATA.md 和 [CONTRACT.md](../../../docs/CONTRACT.md)。来源固定版本、映射和改编依据见 [维护记录](author/README.md)。
