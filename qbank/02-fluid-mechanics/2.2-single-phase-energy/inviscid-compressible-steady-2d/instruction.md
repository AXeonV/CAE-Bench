# 2.2.5 2D 无黏可压缩流动稳态分析

实现一个可复用求解器，处理2维xy平面固定封闭域的单相流动。热完全理想气体，忽略黏性和导热。

求给定驱动下稳定的时间不变状态；不使用物理初值，不能任取瞬态末帧作为稳态。 本题限定平滑等熵稳态；每例保证请求观测的解唯一，不要求选择未知涡量或环流分支，不得任选静止解。

几何、材料参数、适用初态、体加速度及观测由输入明确给出。全部壁面为固定域上的不可穿透滑移绝热壁；不施加壁面运动、壁温或热流。本题以流动为主要目标；热反馈属于任务，不包含固体传热或反应。全部请求输出为：`velocity`, `pressure`, `temperature`, `density`。

完整任务由[共同要求](../COMMON.md)、[本题数据说明](DATA.md)和[公共数据说明](../DATA.md)组成；公共说明引用可随解题包交付的规范。入口为 `python solve.py --input problem.json --output result.h5`。每例900秒、4 CPU、8 GiB、无GPU；所有输出通过共同要求中的结构及数值规则，本例得1分。资源及容差尚待真实数据校准。
