# 2.2.7 3D 无黏可压缩流动稳态分析

实现一个可复用求解器，处理3维完整空间固定封闭域的单相流动。热完全理想气体，忽略黏性和导热。

求给定驱动下稳定的时间不变状态；不使用物理初值，不能任取瞬态末帧作为稳态。 本题限定固定封闭滑移域中由公开数据唯一确定的平滑等熵静水平衡，速度为零；含非零环流或依赖未知初态选择的稳态不在本版范围。

几何、材料参数、体加速度及观测由输入明确给出。全部壁面为固定域上的不可穿透滑移绝热壁；不施加壁面运动、壁温或热流。本题以流动为主要目标；热反馈属于任务，不包含固体传热或反应。全部请求输出为：`velocity`, `pressure`, `temperature`, `density`。

本题阅读依赖为本文、[本题数据说明](DATA.md)和[通用数据协议](../../../../docs/CONTRACT.md)。生产一个冻结后可处理本题多个未见算例的求解器；几何与参数可变。

## 支持范围与方法责任

一个连通单相固定封闭流体域，允许内孔与多个固体障碍物；全部边界不可穿透。无开口、周期面、粗糙壁、旋转坐标系、反应、相变、辐射、固体传热或几何变形。

本题无湍流闭合。允许自行选择语言、软件、解析或降阶方法、内部网格、离散与迭代，只要满足整个公开契约。

不得改变给定材料响应、边界、质量库存、压力规范、观测位置或时刻。不存在隐含重力或旋转。输入的适定性和材料有效范围由算例保证；输出时刻不约束内部时间步。稳态须求适用的时间不变分支，不能用任意瞬态末帧代替。

## 输入规模与运行资源

每例至多 60,000 个流体单元、120,000 个节点、201 个请求输出时刻，输出合计至多 12,000,000 个 float64 分量。尺度比、网格质量和物理时间跨度限定在同预算可处理的范围，不承诺任意病态参数组合。

入口固定为 `python solve.py --input /path/to/problem.json --output /path/to/result.h5`。文件相对路径以 problem.json 所在目录为基准；成功退出码为 0，答案为完整 HDF5，日志不作为答案。可在启动前准备依赖，逐例运行无网络。

每例墙钟 900 秒、4 CPU、8 GiB 内存、无 GPU，Linux AMD64；提供 Python 3、NumPy、SciPy、h5py、Gmsh、jsonschema、g++、OpenMP、Open MPI 及 HDF5 开发库。允许兼容的其他离线依赖。

## 评价规则

每例正常完成、结构合法且所有输出标量满足 `abs(value-reference) <= atol + rtol*abs(reference)` 得 1 分，否则 0 分；本题分数为通过例数/总例数。所有请求时刻、单元及分量逐值检查，不豁免边界、初始时刻或零值；IDs 和时间轴须精确一致。压力直接按规定表示比较，不平移或去均值。

| quantity | atol（本题 DATA.md 所列单位） | rtol |
|---|---|---|
| velocity | 0.002 | 0.02 |
| pressure | 0.5 | 0.02 |
| temperature | 0.05 | 0.005 |
| density | 0.0002 | 0.02 |

输入或参考错误不计考生失分。成功退出、守恒或低残差均不替代目标量准确性。
