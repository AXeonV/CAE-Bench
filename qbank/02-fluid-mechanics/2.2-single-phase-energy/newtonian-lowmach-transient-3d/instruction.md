# 2.2.4 3D 牛顿流体低速流动与传热瞬态分析

实现一个可复用求解器，处理3维完整空间固定封闭域的单相流动。热膨胀牛顿液体，Boussinesq密度反馈；黏度和导热率按温度幂律变化。

从全部给定物理初态演化，在每个请求物理时刻输出；内部时间步及迭代自选。

几何、材料参数、壁面运动、适用的热条件、体加速度及观测由输入明确给出。本题以流动为主要目标；热反馈属于任务，不包含固体传热或反应。全部请求输出为：`velocity`, `pressure`, `temperature`。

本题阅读依赖为本文、[本题数据说明](DATA.md)和[通用数据协议](../../../../docs/CONTRACT.md)。生产一个冻结后可处理本题多个未见算例的求解器；几何与参数可变。

## 支持范围与方法责任

一个连通单相固定封闭流体域，允许内孔与多个固体障碍物；全部边界不可穿透。无开口、周期面、粗糙壁、旋转坐标系、反应、相变、辐射、固体传热或几何变形。

本题无湍流闭合。允许自行选择语言、软件、解析或降阶方法、内部网格、离散和迭代，只要满足整个公开契约；不得改变给定材料响应、条件或观测定义。

不得改变给定材料响应、边界、初态、质量库存、压力规范、观测位置或时刻。不存在隐含重力或旋转。输入的适定性和材料有效范围由算例保证；输出时刻不约束内部时间步。

每例至多 60,000 个流体单元、120,000 个节点、201 个请求输出时刻，输出合计至多 12,000,000 个 float64 分量。尺度比、网格质量和物理时间跨度限定在同预算可处理的范围，不承诺任意病态参数组合。

## 评价规则

对每个请求输出物理量、每个标量分量和每个请求时刻，分别沿空间位置计算加权归一化均方根误差：

`e = sqrt(sum_i(w_i*(a_i-r_i)^2)/sum_i(w_i)) / max(sqrt(sum_i(w_i*r_i^2)/sum_i(w_i)), scale_floor)`。

`a_i` 为提交值，`r_i` 为参考值；采用下述已声明的评分变换或参考尺度偏置时，按对应定义代入。不同物理量、分量或时刻不拼接、不取平均。本例的 `total NRMSE` 定义为这些 `e` 的最大值 `E=max(e)`，全部请求时刻均参与，包括初始帧；全部观测位置均参与，包括边界及零值。

每例连续得分：`E <= 0.05` 得 1 分；`0.05 < E < 0.10` 得 `(0.10-E)/0.05` 分；`E >= 0.10` 得 0 分。题目 reward 为全部正式 case 得分的算术平均值，不按字段数量或空间点数量给 case 加权。

空间位置采用等点权重 `w_i=1`；这是对请求观测位置的误差评价，不推断网格体积或积分权重。单个整体观测也使用该规则。

除 DATA 明确声明的评分变换外，候选和参考均按规定表示直接比较，不平移、去均值、拟合比例或对齐场。

`scale_floor` 是与本输出同单位的正数下限，防止零参考或很小的参考导致除零或尺度失控。本题明确采用：

| quantity | scale_floor | 单位 |
|---|---|---|
| `velocity` | 0.002 | `m/s` |
| `pressure` | 0.5 | `Pa` |
| `temperature` | 0.05 | `K` |

IDs、时间轴、shape、dtype 和有限值要求仍须严格满足；整数及布尔输出精确比较。程序失败、超时、超资源、缺失或非法输出得 0 分；输入、参考或评价基础设施错误不算考生失分。守恒、低残差和正常退出不替代目标观测准确性。
