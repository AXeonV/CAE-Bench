# 2.3.1 2D 不可压缩湍流定常平均分析

实现一个可复用求解器，处理2维xy平面固定封闭域的单相流动。恒密度牛顿流体，等温，不求能量。

求给定驱动下稳定的时间不变状态；不使用物理初值，不能任取瞬态末帧作为稳态。 方法责任为稳态RANS，输出是平均场；具体闭合和光滑壁近壁处理由考生决定。

几何、材料参数、壁面运动、体加速度及观测由输入明确给出。本题以流动为主要目标；温度固定，不要求预测温升。全部请求输出为：`velocity`, `pressure`。

完整任务由[共同要求](../COMMON.md)、[本题数据说明](DATA.md)和[公共数据说明](../DATA.md)组成；公共说明引用可随解题包交付的规范。入口为 `python solve.py --input problem.json --output result.h5`。每例1800秒、4 CPU、8 GiB、无GPU；所有输出通过共同要求中的结构及数值规则，本例得1分。资源及容差尚待真实数据校准。
