# 2.3.4 3D 不可压缩湍流尺度解析统计分析

实现一个可复用求解器，处理3维完整空间固定封闭域的单相流动。恒密度牛顿流体，等温，不求能量。

从给定完整瞬时初态发展三维湍流，在指定离散统计网格上求均值、方差与适用协方差；输出时刻是统计终点标记。 必须使用DNS或适当LES的尺度解析统计，不以RANS模型变量替代。

几何、材料参数、壁面运动、体加速度及观测由输入明确给出。本题以流动为主要目标；温度固定，不要求预测温升。全部请求输出为：`velocity`, `pressure`, `velocity_covariance`。

本题阅读依赖为本文、[本题数据说明](DATA.md)和[通用数据协议](../../../../docs/CONTRACT.md)。生产一个冻结后可处理本题多个未见算例的求解器；几何与参数可变。

## 支持范围与方法责任

一个连通单相固定封闭流体域，允许内孔与多个固体障碍物；全部边界不可穿透。无开口、周期面、粗糙壁、旋转坐标系、反应、相变、辐射、固体传热或几何变形。

允许自行选择语言、软件、内部网格、离散和迭代；允许有依据的简化或解析方法，但须满足本题方法责任及公开输入范围。必须进行三维尺度解析，允许 DNS 或有物理依据的 LES，不接受把 RANS 闭合方差直接当解析统计。模型误差、尺度解析不足和统计不确定度均计入目标观测误差，不能改变观测定义。

不得改变给定材料响应、边界、初态、质量库存、压力规范、观测位置或时刻。不存在隐含重力或旋转。输入的适定性和材料有效范围由算例保证；输出时刻不约束内部时间步。

## 输入规模与运行资源

每例至多 120,000 个流体单元、240,000 个节点、201 个请求输出时刻，输出合计至多 12,000,000 个 float64 分量。统计内部样本数由本题 DATA.md 限制，不要求全部存盘。尺度比、网格质量和物理时间跨度限定在同预算可处理的范围，不承诺任意病态参数组合。

入口固定为 `python solve.py --input /path/to/problem.json --output /path/to/result.h5`。文件相对路径以 problem.json 所在目录为基准；成功退出码为 0，答案为完整 HDF5，日志不作为答案。可在启动前准备依赖，逐例运行无网络。

每例墙钟 1800 秒、4 CPU、8 GiB 内存、无 GPU，Linux AMD64；提供 Python 3、NumPy、SciPy、h5py、Gmsh、jsonschema、g++、OpenMP、Open MPI 及 HDF5 开发库。允许兼容的其他离线依赖。

## 评价规则

每例正常完成、结构合法且所有输出标量满足 `abs(value-reference) <= atol + rtol*abs(reference)` 得 1 分，否则 0 分；本题分数为通过例数/总例数。所有请求时刻、单元及分量逐值检查，不豁免边界、初始时刻或零值；IDs 和时间轴须精确一致。压力直接按规定表示比较，不平移或去均值。

| quantity | atol（本题 DATA.md 所列单位） | rtol |
|---|---|---|
| velocity | 0.01 | 0.05 |
| pressure | 2 | 0.05 |
| velocity_covariance | 0.01 | 0.1 |

输入或参考错误不计考生失分。成功退出、守恒或低残差均不替代目标量准确性。
