# 2.5.5 二维毛细与润湿瞬态流动

实现一个可复用求解器，预测恒定表面张力、壁面给定接触角和物理滑移长度共同作用下的双流体运动。

本题的规范性材料为 [共同要求](../COMMON.md)、[本题数据说明](DATA.md)、[公共数据说明](../DATA.md) 和 [多相物理/接口规范](../../../../docs/FLUID-MULTIPHASE.md)。请求时刻、相态和材料参数由算例给出，不要求固定几何或单个工况。

## 能力与建模责任

本题空间维度固定为2，分析类型为瞬态；物理方法通过显式 `fluid-multiphase-wetting-v1` 声明。必须覆盖公开协议支持的材料参数变化、固定一般域、初始相分布/状态、体加速度与允许的边界组合。

接触线可移动，接触角穿过a相；无滞后、无动态角经验律。与无张力双流体题的差异是毛细牵引与润湿边界。

内部离散、相场/界面表示、线性代数和时间推进由考生自选；必须实现本题固定物理响应，不可用其他闭合解释相同输入。解析/降阶方法若覆盖整个公开契约同样有效，不要求某一软件。

## 目标观测及评价

液体分布、接触线影响下的速度和毛细压力；不要求返回未定义的界面面积重建。 必须返回本题DATA列出的全部场，按请求实体、时间和物理平均比较；不得返回模型专有变量代替共同观测。

提交入口、设计资源、逐值比较及误差目标按COMMON。数值/物理参考和预算尚待数据阶段校准；此阶段不发布评测，不宣称已有真实流动准确性证据。
