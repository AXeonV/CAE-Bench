# 2.5.4 三维不混溶双流体界面瞬态流动

实现一个可复用求解器，在完整三维空间解析不可压缩牛顿双流体，无相变、无表面张力。

本题由本文件、[本题数据说明](DATA.md) 和 [通用契约](../../../../docs/CONTRACT.md) 完整定义。请求时刻、相态和材料参数由算例给出，不要求固定几何或单个工况。

## 能力与建模责任

本题空间维度固定为3，分析类型为瞬态；物理方法通过显式 `fluid-multiphase-immiscible-v1` 声明。必须覆盖公开协议支持的材料参数变化、固定一般域、初始相分布/状态、体加速度与允许的边界组合。

必须支持三维界面变形和一般域，不能将所有输入化为二维截面。

软件、语言、内部网格、离散、相场/界面表示、线性代数和时间步由考生自选；不得依据文件名、来源或 task 名推断未声明物理；必须实现本题固定物理响应，不可用其他闭合解释相同输入。解析/降阶方法若覆盖整个公开契约同样有效，不要求某一软件。

## 固定物理响应

全部为瞬态、层流、固定 Euler 域，边界不移动；无反应、无湍流、无界面活性剂、无辐射。等温；所有相密度均为正常数。必须处理完整三维空间，不能将所有输入化为二维截面。

α 为 a 相体积分数，β=1−α；g 为输入 acceleration，D(u) 为对称速度梯度，D_t 为物质导数，I 为单位张量。rho_i、mu_i 分别对应 DATA 中各相密度、动力黏度。所有压力为绝对静压。

a、b 均为不可压缩牛顿物理流体，各自满足质量和牛顿动量守恒；界面物质输运，速度连续且无相变。应力为 stress_i=−p_i I+2 mu_i D(u_i)。无表面张力，界面牵引连续。

## 评分规则

对每个请求输出物理量、每个标量分量和每个请求时刻，分别沿空间位置计算加权归一化均方根误差：

`e = sqrt(sum_i(w_i*(a_i-r_i)^2)/sum_i(w_i)) / max(sqrt(sum_i(w_i*r_i^2)/sum_i(w_i)), scale_floor)`。

`a_i` 为提交值，`r_i` 为参考值；采用下述已声明的评分变换或参考尺度偏置时，按对应定义代入。不同物理量、分量或时刻分别计算空间 NRMSE，不拼接原始数值。本例的 `total NRMSE` 定义为全部这些 `e` 的等权均方根 `E=sqrt(sum(e_j^2)/M)`，其中 `M` 为 NRMSE 组数，全部请求时刻均参与，包括初始帧；全部观测位置均参与，包括边界及零值。

每例连续得分：`E <= 0.05` 得 1 分；`0.05 < E < 0.10` 得 `(0.10-E)/0.05` 分；`E >= 0.10` 得 0 分。题目 reward 为全部正式 case 得分的算术平均值，不按字段数量或空间点数量给 case 加权。

空间位置采用等点权重 `w_i=1`；这是对请求观测位置的误差评价，不推断网格体积或积分权重。单个整体观测也使用该规则。

压力的参考尺度使用 `r_i-pressure_reference` 计算 RMS，`pressure_reference` 取输入公开参数；误差分子仍是原始绝对静压的 `a_i-r_i`，不对候选平移或去均值。其他量按其原值计算。

`scale_floor` 是与本输出同单位的正数下限，防止零参考或很小的参考导致除零或尺度失控。本题明确采用：

| quantity | scale_floor | 单位 |
|---|---|---|
| `alpha` | 0.005 | `1` |
| `pressure` | 1 | `Pa` |
| `velocity` | 0.001 | `m/s` |

IDs、时间轴、shape、dtype 和有限值要求仍须严格满足；整数及布尔输出精确比较。程序失败、超时、超资源、缺失或非法输出得 0 分；输入、参考或评价基础设施错误不算考生失分。守恒、低残差和正常退出不替代目标观测准确性。
