# 2.7 热质交换及相变多相流动：共同要求

本文件、[公共数据说明](DATA.md) 及逐题 instruction.md/DATA.md 共同定义任务；物理与接口的规范性定义见 [多相配置](../../../docs/FLUID-MULTIPHASE.md) 和 [通用契约](../../../docs/CONTRACT.md)。

实现一个可复用求解器，读入不同一般几何、材料、初态、驱动和观测时刻，覆盖对应题目的公开能力范围。不得依据文件名、来源或task名字推断未声明物理。可自行选择软件、语言、离散、内部网格和时间步，也可使用满足整个公开范围的解析/降阶方法。不得改变固定的物理闭合、边界、材料响应、压力基准和采样含义。

所有题目瞬态、层流、固定Euler域。三维必须处理三维空间；二维为xy平面单位厚度，不是轴对称。具体材料范围、相标识、低速/等温假设及不覆盖过程由公共协议和逐题声明限定。网格为Gmsh MSH4.1 ASCII一阶单元，实体ID是身份，不能按读取行号配对。

入口为solve.py，每例独立运行，成功时以0退出并写完整HDF5：

```sh
python solve.py --input /absolute/path/problem.json --output /absolute/path/result.h5
```

输入相对路径均相对problem.json目录。数值输出只写请求文件，日志不作为答案。提交冻结后全部算例共用同一程序；逐例运行无网络。设计运行环境为Linux AMD64，Python3、NumPy、SciPy、h5py、Gmsh、jsonschema、g++和HDF5开发库；可预备兼容依赖。

本节首版设计预算为每例1800秒、8CPU、8GiB、无GPU；pressure及派生相变率在起始时刻必须具有制作方已证明有限且唯一的右迹；无此证据，公共输出轴必须严格晚于time_start开始，不能选择任意离散压力/差分率作为起始观测。输入至多30000体单元、101输出时刻、全部输出合计20000000个float64分量。该预算和下述容差是尚待真实算例校准的设计目标，尚未形成正式评测。数据制作方须提供同一预算内的独立基准、网格/时间误差和模型适用性证据，不以参数合法收纳任意病态长时或极端尺度问题。

每例暂定0/1分；结构有效、正常退出且每个请求时刻/实体/分量都满足 `abs(value-reference) <= atol + 0.03*abs(reference)` 才通过。此公式适用于除pressure外的量；pressure仍输出绝对静压，比较时两边都减输入的同一pressure_reference，仅相对项采用参考扰动：`abs(p_calc-p_ref) <= 1 Pa + 0.03*abs(p_ref-pressure_reference)`。这不是另选零点或平移对齐答案，固定参考仍参与物理边界；不得以约1e5 Pa背景压力放宽压差误差。不省略任何已请求的起始时刻或零值，不剔除界面单元。逐题成绩为通过例数/有效例数。缺失/非法输出和超资源失败；输入或参考错误应撤回修复，不能计入考生失分。比较用相同实体上的物理体积平均，不以内部数值平滑变量替代公开观测。

| quantity | atol（对应输出单位） |
|---|---|
| alpha | 0.005 |
| velocity、flux_a、flux_b | 0.001 m/s |
| pressure | 1 Pa |
| temperature、temperature_a、temperature_b | 0.1 K |
| concentration_a、concentration_b | 0.00001 kg/m3 |
| phase_change_rate | 0.001 kg/(m3.s) |

只评价逐题允许的输出。相体积、常相密度下的相质量和已请求的总相变率可由单元平均场线性积分复算；分散模型的相通量输出也允许线性复算总动量。共速变密度动量、每相溶质量、热量/焓涉及相含率与速度/浓度/温度的乘积，各自单元均值不能精确恢复乘积均值；从当前输出估计这些量只能作为带重建误差的近似，不用于严格守恒判分。守恒、低残差或正常运行不能替代目标观测准确性。参考与容差必须区分数值误差、模型适用性和测量不确定度，不以复现某来源软件为有效性的充分依据。
