# 3.2.2 一维梁弯曲分析

实现本题范围内可复用求解器，冻结后处理多个未见算例。能力范围：1D Euler–Bernoulli弯曲，变截面分段常数，静力。具体几何、参数、载荷、支撑与观测由算例给定。任务目标是deflection、slope、bending_moment对应的物理量，含义以本题DATA就地定义。

一根沿全局x轴严格递增的直梁，线性Euler–Bernoulli弯曲；横向w是抽象横向挠度而非x位移。连续方程(EIw″)″=q。跨单元w、w′及无集中力偶处内力连续。端力按虚功定义，右端F=−(EIw″)′、M=EIw″，左端符号相反。不求轴向伸长、扭转或剪切变形；恰有一个端点clamp，另一个端点可end_load。

考生负责由物理描述建立相容的连续问题、选择模型允许范围内的适当表示和求解方法、离散与误差控制；给定的材料响应、降维假设和历史不能改写。允许任意语言、软件、内部网格、解析或降阶方法，只要覆盖公开问题族；不要求复现参考软件和参考离散。输入网格定义精确参考几何及采样支持，不是强制有限元离散。不同方法输出须满足相同观测。

阅读[本题DATA](DATA.md)和[通用数据协议](../../../../docs/CONTRACT.md)即可确定全部输入输出。模型仅为`solid-elastic-beam-v1`；只接受本题定义的模型与组合。

## 规模与运行

每例至多5000个顶维单元、15000个网格节点，每个轴至多201帧，全部输入和输出场分别至多3000000个float64分量。首版不承诺任意病态网格。数据制作方须用独立基准证明同预算可达到设计精度；当前规模、预算及容差尚待正式数据校准。

入口：`python solve.py --input /path/problem.json --output /path/result.h5`。每例Linux AMD64、900秒墙钟、4CPU、8192MB内存、0GPU；启动与全部读写计时，逐例无网络。依赖提前准备，可用Python3、NumPy、SciPy、h5py、Gmsh、jsonschema、C++/OpenMP/OpenMPI/HDF5；不强制使用Python计算。程序以0退出，输出为完整HDF5，路径以命令行参数为准；无独立输出字节限额，shape规模仍受限。生成求解器时间为3600秒，构建环境最多1800秒。

## 评分

每例正常退出、结构合法且全部请求quantity通过得1分，否则0分；本题成绩为通过有效例数／有效例数。输入、配置和参考错误属于基础设施问题，不计考生失败；没有正式有效例时不产生成绩。

每个float64输出在全部时刻、实体与分量上逐值满足 `|结果−参考| ≤ atol(quantity)+0.01|参考|`。不去均值、平移、重排、拟合偏置、豁免少数超限点或按整体RMSE替代。全部字段同时通过，阈值等号接受。IDs／时间、shape、dtype及有限值严格遵守CONTRACT。
