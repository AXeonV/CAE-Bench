# 3.8.2 预设界面内聚开裂

实现本题范围内可复用求解器，冻结后处理多个未见算例。能力范围：2D平面应变，两个小应变体，零厚度纯I型可卸载内聚界面，固定拓扑。具体几何、参数、载荷、支撑、历史与观测由算例给定。任务目标是displacement、stress、opening、cohesive_traction对应的物理量，含义以本题DATA就地定义。

两个二维平面应变线弹性体，单位厚度；直线预设界面两侧几何重合、节点tag不同，无跨界单元。n从minus体指向plus体；δ=(uplus−uminus)·n≥0，切向位移跳跃为0（严格粘结），无压缩接触分支。δ0=T0/Kn，δf=2Gc/T0>δ0；κ=max历史δ，κ≤δ0时d=0，δ0<κ<δf时d=δf(κ−δ0)/[κ(δf−δ0)]，κ≥δf时d=1；T=(1−d)Knδ。minus体界面法向牵引+Tn、plus体−Tn；切向反力由零切向跳跃约束确定，反力在两体上大小相等方向相反，不强制为零；T只表示法向内聚牵引。卸载按已损伤割线回原点。起始u=κ=0，无牵引；载荷位移控制，保证唯一连续稳定、无回闭／压缩／跳跃分支。界面完全断开后切向仍严格约束，只评价给定纯I型问题族。

考生负责由物理描述建立相容的连续问题、选择模型允许范围内的适当表示和求解方法、离散与误差控制；给定的材料响应、降维假设和历史不能改写。允许任意语言、软件、内部网格、解析或降阶方法，只要覆盖公开问题族；不要求复现参考软件和参考离散。输入网格定义精确参考几何及采样支持，不是强制有限元离散。不同方法输出须满足相同观测；没有其他隐藏模型变量。

阅读[本题DATA](DATA.md)和[通用数据协议](../../../../docs/CONTRACT.md)即可确定全部输入输出。模型仅为`solid-cohesive-interface-v1`；其他模型、任意跨物理组合及材料温度反馈不在本题范围。

## 规模与运行

每例至多5000个顶维单元、15000个网格节点（无网格题至多15000个独立点），每个轴至多201帧，全部输入和输出场分别至多3000000个float64分量。模态至多12阶；首版不承诺任意病态网格、任意逼近不可压缩极限或任意长历史。数据制作方须用独立基准证明同预算可达到设计精度；当前规模、预算及容差尚待正式数据校准。

入口：`python solve.py --input /path/problem.json --output /path/result.h5`。每例Linux AMD64、1500秒墙钟、4CPU、8192MB内存、0GPU；启动与全部读写计时，逐例无网络。依赖提前准备，可用Python3、NumPy、SciPy、h5py、Gmsh、jsonschema、C++/OpenMP/OpenMPI/HDF5；不强制使用Python计算。程序以0退出，输出为完整HDF5，路径以命令行参数为准；无独立输出字节限额，shape规模仍受限。生成求解器时间为3600秒，构建环境最多1800秒。

## 评分

每例正常退出、结构合法且全部请求quantity通过得1分，否则0分；本题成绩为通过有效例数／有效例数。输入、配置和参考错误属于基础设施问题，不计考生失败；没有正式有效例时不产生成绩。

每个float64输出在全部时刻、实体与分量上逐值满足 `|结果−参考| ≤ atol(quantity)+0.01|参考|`。不去均值、平移、重排、拟合偏置、豁免少数超限点或按整体RMSE替代。全部字段同时通过，阈值等号接受；谱量也是逐分量比较且保留重数。IDs／时间、shape、dtype及有限值严格遵守CONTRACT。
