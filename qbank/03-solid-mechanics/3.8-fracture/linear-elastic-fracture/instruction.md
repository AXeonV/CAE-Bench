# 3.8.1 预制裂纹线弹性场与能量

实现本题范围内可复用求解器，冻结后处理多个未见算例。能力范围：2D平面应变，固定贯穿裂纹，裂面无载，位移与弹性能，不采样裂尖点应力。具体几何、参数、载荷、支撑与观测由算例给定。任务目标是displacement、stress、energy对应的物理量，含义以本题DATA就地定义。

二维各向同性平面应变，单位z长度，固定贯穿裂纹；裂纹由同坐标不同tag的裂面节点及不跨裂缝的三角网格显式给出，连通未断区仍共享节点。两侧无载裂面显式traction=0，裂面互不粘结、不发生接触，裂尖无人工钝化。线弹性小应变divσ+b=0。应力输出为裂尖邻域也有定义的单元积分平均，位移可含裂尖节点；不请求裂尖点应力、裂纹扩展路径或由离散能量差猜J积分。energy=∫ε:C:ε/2 dA。算例保证裂面张开、无相互穿透。

考生负责由物理描述建立相容的连续问题、选择模型允许范围内的适当表示和求解方法、离散与误差控制；给定的材料响应、降维假设和历史不能改写。允许任意语言、软件、内部网格、解析或降阶方法，只要覆盖公开问题族；不要求复现参考软件和参考离散。输入网格定义精确参考几何及采样支持，不是强制有限元离散。不同方法输出须满足相同观测。

阅读[本题DATA](DATA.md)和[通用数据协议](../../../../docs/CONTRACT.md)即可确定全部输入输出。模型仅为`solid-linear-elastic-fracture-v1`；只接受本题定义的模型与组合。

## 规模与运行

每例至多5000个顶维单元、15000个网格节点，每个轴至多201帧，全部输入和输出场分别至多3000000个float64分量。首版不承诺任意病态网格；Poisson比范围按DATA给定。数据制作方须用独立基准证明同预算可达到设计精度；当前规模、预算及容差尚待正式数据校准。

入口：`python solve.py --input /path/problem.json --output /path/result.h5`。每例Linux AMD64、900秒墙钟、4CPU、8192MB内存、0GPU；启动与全部读写计时，逐例无网络。依赖提前准备，可用Python3、NumPy、SciPy、h5py、Gmsh、jsonschema、C++/OpenMP/OpenMPI/HDF5；不强制使用Python计算。程序以0退出，输出为完整HDF5，路径以命令行参数为准；无独立输出字节限额，shape规模仍受限。生成求解器时间为3600秒，构建环境最多1800秒。

## 评分

每例正常退出、结构合法且全部请求quantity通过得1分，否则0分；本题成绩为通过有效例数／有效例数。输入、配置和参考错误属于基础设施问题，不计考生失败；没有正式有效例时不产生成绩。
