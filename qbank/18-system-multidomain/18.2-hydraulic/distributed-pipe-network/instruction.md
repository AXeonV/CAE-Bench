# 18.2.2 分布管路与容腔波动网络

实现覆盖整个公开问题族的可复用求解器，冻结后处理多个未见算例。

每有向管支路a→b有连续坐标x∈[0,l_e]，截面积A、密度rho、体积模量K、线性阻力r均在本管均匀。
管内表压P与沿+x的体积流率Q满足(A/K) P_t+Q_x=0，(rho/A) Q_t+P_x+r Q=0。
P_e(0,t)=p_a(t)，P_e(l_e,t)=p_b(t)。节点容腔C_i p_dot=s_i−G_i p_i−sum_{tail=i}Q_e(0,t)+sum_{head=i}Q_e(l_e,t)。
每管两端Q均按该管+x为正，首端流入节点项为+Q(l)，绝不能将首端输出改成外法向通量。节点具有正顺应性，所有管初态P=Q=0，所有节点初态p=0；加载从0开始且s(0)=0。各节点无外加压力约束。必须保留沿管传播与反射，不以单个集总阻力替代连续PDE。

固定参考管道、无壁运动。正式数据保证|P|/K≤0.01、|Q|/(A sqrt(K/rho))≤0.01；初边角点按因果弱解，观测为连续端口迹。内部空间网格和时间步自由，不由拓扑或请求时刻规定。

模型和元件关系固定，考生负责按身份组装、求解、内部时间步及误差控制；分布管路的内部空间离散也由考生决定。语言与软件自由，解析／降阶方法覆盖全部公开契约同样有效，不要求某种参考算法。连通拓扑、并联支路、有向编号、元件参数、初态及外源时程由算例改变。输入输出只依赖[本题DATA](DATA.md)和[通用CONTRACT](../../../../docs/CONTRACT.md)。

## 运行与资源

入口`python solve.py --input /path/problem.json --output /path/result.h5`。每例Linux AMD64、600秒墙钟（含启动和I/O）、2CPU、4096MB、0GPU、无网络；正常0退出并完整写HDF5，无独立输出字节上限。生成求解器3600秒、构建1800秒。提前提供Python3、NumPy、SciPy、h5py、Gmsh、jsonschema及C++/OpenMP/OpenMPI/HDF5，不强制Python或Modelica。

规模：nodes 2..128、edges 1..256，load 2..256节点，response 1..256节点，static 1帧；输入场／输出场各至多2000000数值分量。资源与容差是待校准设计目标，正式数据必须独立核验精度、模型适用性与预算可达性，不能由结构合法参数推得全范围已验证。
