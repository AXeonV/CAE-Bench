# 18.3.1 等温气动容腔与毛细阻流网络

实现覆盖整个公开问题族的可复用求解器，冻结后处理多个未见算例。

固定容腔理想气体，所有节点由充分恒温换热维持同一给定绝对温度Tg，气体比气体常数Rg。每节点绝对压力p>0满足[V_i/(Rg Tg)] p_dot=s_i−(B mdot)_i。
每条有向长毛细管a→b的质量流率mdot=H_e(p_a²−p_b²)，H>0为已给定等温层流导通系数，沿a→b为正。B为尾端+1、首端−1关联矩阵。不另用喷口临界流／绝热关系或以表压代入平方关系。管内储存与动量惯性忽略；初始绝对压力p0给定。

正式数据核验全程p>0、理想气体／等温层流毛细管假设和预算内可达精度；不将元件导通关系解释为任意压比喷口模型。

模型和元件关系固定，考生负责按身份组装、求解、内部时间步及误差控制；语言与软件自由，解析／降阶方法覆盖全部公开契约同样有效，不要求某种参考算法。连通拓扑、并联支路、有向编号、元件参数、初态及外源时程由算例改变。输入输出只依赖[本题DATA](DATA.md)和[通用CONTRACT](../../../../docs/CONTRACT.md)。

## 运行与资源

入口`python solve.py --input /path/problem.json --output /path/result.h5`。每例Linux AMD64、240秒墙钟（含启动和I/O）、2CPU、4096MB、0GPU、无网络；正常0退出并完整写HDF5，无独立输出字节上限。生成求解器3600秒、构建1800秒。提前提供Python3、NumPy、SciPy、h5py、Gmsh、jsonschema及C++/OpenMP/OpenMPI/HDF5，不强制Python或Modelica。

规模：nodes 2..128、edges 1..256，load 2..256时间采样点，response 1..256时间采样点，static 1帧；输入场／输出场各至多2000000数值分量。资源与容差是待校准设计目标，正式数据必须独立核验精度、模型适用性与预算可达性，不能由结构合法参数推得全范围已验证。
