# 18.4.1 非线性传导辐射热网络

实现覆盖整个公开问题族的可复用求解器，冻结后处理多个未见算例。

节点为等温储热体，绝对温度T_i、正热容C_i；C_i T_dot=S_i−(B q)_i+h_i(Ta_i−T_i)+sigmaSB Aenv_i(Ta_i^4−T_i^4)。
支路a→b传热率q=g_e(T_a−T_b)+sigmaSB Arad_e(T_a^4−T_b^4)，正向a→b。B为尾端+1、首端−1关联矩阵。sigmaSB固定5.670374419e−8 W/(m2.K4)。
Arad和Aenv是包含发射率、面积及交换因子的非负有效辐射面积，由输入直接给定，不再从几何推导或重复乘发射率。h是对节点独立外界温度Ta的传导／对流热导，不是单位面积换热系数。所有初始绝对温度T0给定。

实际数据保证全程正温度及集总均温／常热容适用。外界温度是给定热浴，不另计入节点图或未知状态。

模型和元件关系固定，考生负责按身份组装、求解、内部时间步及误差控制；语言与软件自由，解析／降阶方法覆盖全部公开契约同样有效，不要求某种参考算法。连通拓扑、并联支路、有向编号、元件参数、初态及外源时程由算例改变。输入输出只依赖[本题DATA](DATA.md)和[通用CONTRACT](../../../../docs/CONTRACT.md)。

## 运行与资源

入口`python solve.py --input /path/problem.json --output /path/result.h5`。每例Linux AMD64、240秒墙钟（含启动和I/O）、2CPU、4096MB、0GPU、无网络；正常0退出并完整写HDF5，无独立输出字节上限。生成求解器3600秒、构建1800秒。提前提供Python3、NumPy、SciPy、h5py、Gmsh、jsonschema及C++/OpenMP/OpenMPI/HDF5，不强制Python或Modelica。

规模：nodes 2..128、edges 1..256，load 2..256节点，response 1..256节点，static 1帧；输入场／输出场各至多2000000数值分量。资源与容差是待校准设计目标，正式数据必须独立核验精度、模型适用性与预算可达性，不能由结构合法参数推得全范围已验证。
