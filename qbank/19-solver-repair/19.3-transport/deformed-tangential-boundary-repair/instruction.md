# 变形边界切向约束修复

给定固定版本 ASPECT，修复其材料速度边界实现，使独立网格运动改变边界形状后，切向材料速度仍满足当前物理边界的零法向条件，并保持静态曲面及规定速度边界行为。你交付可复用的库修复，处理 [DATA](DATA.md) 定义的全部工况。

本题为常密度、常黏度、零重力、定温不可压缩线性 Stokes 问题。每个给定时刻求解当前域中的速度和压力；时间用于推进规定网格运动及更新边界，不包含材料惯性。支持二维／三维盒及二维静态圆环，使用 block AMG。GMG、自由表面动力学、自适应拓扑和其他几何不在本题范围。

材料速度 `u` 与网格速度 `w` 不同。本题切向条件为 `u·n=0`，其中 `n` 属于当前几何；切向应力为零。它不是材料相对网格的不可穿透条件。压力采用当前上边界的面积平均为零的规范；圆环“上边界”指外圆。

提交目录只含 `core.cc`，替换固定源码的 `source/simulator/core.cc`。保留文件内公开API、指定物理、真实 ASPECT 求解过程及其他已有边界行为；不得修改可信输入输出转换器、另写求解入口、绕过库实现计算答案，或将材料速度强制设成网格速度。完整源码及许可在离线环境 `/opt/aspect`，构建目录为 `/opt/aspect-build`；运行器为 `public/run_case.py`。公开文件可帮助读取与运行输入，不会修正物理结果。

开发时可在环境内修改指定文件后运行：

```sh
cmake --build /opt/aspect-build --parallel 1
python public/run_case.py --input samples/01/input/problem.json --output /tmp/result.h5
```

源码替换件不超过1MiB。环境提供4个CPU与8GiB内存；可信判题分别重建原件及候选，候选编译预算900秒。每例实际求解预算60秒，结果文件须满足 [CONTRACT](../../../../docs/CONTRACT.md)。开发产物不作为提交；判题会强制删除受替换文件影响的对象与程序并重新构建。

按每例全部固定空间采样点、全部要求时刻的材料速度及压力比较；两项全部通过才记该例通过，所有计分例等权平均。每个分量使用 `|提交−参考|≤atol+rtol×|参考|`，全部采用rtol=1e-5。平行盒或圆环的速度atol=1e-5 m/s、压力atol=1e-6 Pa；deformed-tangential-wedge-v1的速度atol=1e-4 m/s、压力atol=2e-3 Pa。公开样例可用本题评分工具核对。方法限制单独核查，数值通过不等于允许绕过指定库。
