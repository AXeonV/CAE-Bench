# 19.4.1 梯度电极的锂库存观测修复

在给定的 PyBaMM 源码基线中，修复跨尺度浓度平均的实现，使梯度电极的活性材料平均浓度与锂库存正确。输入给出两个电极的瞬时有限体积状态。你需要提交可复用的库内修复，保持公开 API 和常数分布等已有行为。

## 问题与要求

每个电极的厚度坐标 x∈[0,1]、球形粒子的归一化半径 r∈[0,1]分别按等宽单元离散。数据给出每个厚度单元 j 的活性材料体积分数 ε_j，以及该单元中每个径向单元 i 的固相浓度 c_ij。各数值代表网格上的分片常数状态。它们是独立瞬时输入，不保证构成守恒时间轨迹。

径向平均浓度使用球壳体积权重：c̄_j=Σ_i (r_{i+1}³−r_i³)c_ij。电极活性材料的平均浓度为 c_vol=Σ_j Δx_j ε_j c̄_j / Σ_j Δx_j ε_j。平均化学计量比为 c_vol/c_max；电极锂库存为 n=A L Σ_j Δx_j ε_j c̄_j，其中 A 为集流面积、L 为该电极厚度。两电极总库存是各自库存之和。全部输入输出及量纲见 [DATA](DATA.md)，通用格式见 包内 CONTRACT.md。

可信驱动以粒子主域、电极辅助域的真实浓度变量构建表达式，通过 `r_average` 和 `particle.TotalConcentration.get_coupled_variables`，再进行参数处理与有限体积离散求值。应让指定库在该入口正确返回径向平均浓度、体积平均浓度、化学计量比及库存。不能修改驱动、数据转换器、网格或指定调用来纠正输出；不能另写程序替代库内计算。

## 材料与提交

公开包内的 `public/pybamm-source.tar.gz` 是固定源码原件，保留其许可证。`public/driver.py` 为可信库调用，`public/run_case.py` 为协议转换器，`public/CMakeLists.txt` 定义构建目标。运行环境已安装对应 PyBaMM 和依赖。可通过下面的入口读取输入、执行和写出结果：

```sh
python public/run_case.py --input samples/01/input/problem.json --output result.h5
```

只提交一个 `averages.py` 文件，替换 `packages/pybamm/src/pybamm/expression_tree/averages.py`；保持现有类、函数及公开接口。每个文件不得超过 1 MiB，提交目录不得包含其他文件或符号链接。可信端从固定原件恢复并执行 `repair_sources` 语法构建，删除并重建真实导入的缓存，再由固定驱动运行。无需提交入口脚本或第三方依赖。

要求覆盖两电极、非均匀体积分数与非均匀粒子浓度，并保持常数体积分数、均匀浓度和零浓度的行为。本题考查上述乘积平均和库存观测；不要求修复其他平均运算或完成电池时间积分。

## 评分与资源

逐 case 对全部声明输出比较；每个输出、每个分量均满足 |y−y_ref|≤atol+rtol|y_ref| 才通过该 case。各 case 等权，构建或运行失败的 case 不通过。rtol=1e-8；浓度输出atol=1e-7 mol/m³，化学计量比atol=1e-10，库存atol=1e-12 mol。零值也按该绝对容差比较。

考生总时限1800秒、4核CPU、8GiB内存；可信源码构建限时60秒，每个case运行限时30秒。禁止联网安装或依赖提交目录外自带程序。输入读取、格式检查和数值评分由可信工具完成，不补充库内物理。
