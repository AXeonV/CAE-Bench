# 出题与协议设计的经验清单

本清单供出题 Agent 和审阅者使用，不属于考生材料。它补充 [出题工作流](AUTHORING.md)，记录本轮题库设计中用户纠正的问题、[2.1 审阅](reviews/section-2.1-statements.md)及[第二章简化审阅](reviews/chapter-02-simplification.md)发现的缺陷，以及已实现协议中的可复用做法。下列 CFD 例子用于解释风险，不是其他领域必须照搬的物理约定。

## 已纠正的设计与题面问题

| 问题或错误表现 | 为什么会出错 | 已采用的修复 | 后续如何检查 |
|---|---|---|---|
| 把顶盖驱动腔流等具体几何问题称为问题族 | 用某个几何和工况代替一般求解能力 | 按物理、材料、维度和分析目标划分题目，几何下沉到算例 | 改变几何后是否仍属同一能力；若是，不因几何名称另立问题族 |
| 用 PDEBench 等来源给一般题目命名，或让来源是否有数据决定目录 | 题目能力与外部数据集耦合，无法独立演进 | 题名表达问题；来源与改编记录进入 cases／references | 更换或自制算例后，题目定义是否仍成立 |
| 默认以明确的方程、本构、闭合模型组织全部 CAE 题 | 提前替考生做完本来要考查的建模选择 | CAE 题以物理描述和方法责任界定；仅固定任务确实需要固定的信息 | 分别列出输入固定的材料响应与考生可选模型；湍流不因来源配置而隐含指定某种闭合 |
| 将给定 PDE 与 CAE 分成两套顶层题库 | 描述方式差异被当成领域分类 | 统一按 CAE 章、节、子节组织，各题声明建模责任 | 不因有无显式方程复制一套领域目录 |
| 出题 skill 假定已有明确章／节规划，遇到模糊方向只能指出不足 | 将完成目标所需的规划工作留给用户，自动化链条不完整 | 将逐级规划补全纳入同一 skill：缺章规划先规划章，再细化目标节，随后完成出题 | 分别检查“2.3 只有方向”和“3.1 上级章尚未规划”两种路径；不额外实施兄弟节，不默认每层等待批准 |
| 用“压力出口＋无回流”作为完整边界说明 | 未确定黏性作用；合理考生可能实现不同连续问题 | 2.1 选择外部储槽压力产生的总牵引，区分外压和内部静压，同步协议 | 同名条件能否有两个不同且合理的物理解读；尤其避免同时叠加不等价约束 |
| 流率 shape 表格只列实体场，公共规则又允许节点场 | 两处支持集合冲突；积分归一化的对象不明确 | 明确节点重建后先取边界实体平均，再归一化 | 每个专用参数是否与公共场表示相容；节点集合、重建和平均顺序是否确定 |
| 规定等温马赫数上限但不定义声速 | 考生可能采用绝热声速，得到不同适用范围 | 明确该题采用等温响应声速 | 无量纲数、参考量及降维量的定义是否能从输入唯一确定 |
| 稳态与瞬态采样共用说明，却未直接排除稳态多帧 | 可把稳态理解成某个瞬态帧，或误读边界采样 | 明确稳态输入常量单帧、输出标记；区分物理初态与迭代初猜 | 分别核查初态、边界采样、请求时刻、内部时间步和统计区间 |
| 固定计算预算但未说明数值难度边界 | 合法参数可形成任意病态、极端长时间或退化网格问题 | 要求正式算例有相同预算内达到精度的独立基准证据，排除任意病态组合 | 数据建设时验证并记录可解性；不能仅凭参数正值宣称全范围可测 |

这些修复中，有的属于题库组织，有的属于边界语义和输入表示。不要通过改名字掩盖物理缺失，也不要用“方法自由”让考生替出题方猜测条件。

## 第二章简化后落实的设计

- **三文件自足**：考生只需本题 instruction.md、DATA.md 与通用 CONTRACT.md。共享定义减少了作者重复，却把查找、筛选和消解冲突转嫁给考生；维护端可复用，交付端必须逐题展开适用内容。静态脚本只能查链接，独立审阅还须识别纯文本中遗漏的外部定义。
- **按职责交接**：出题先确定物理目标、方法责任、资源和评分；caeoj-design-data 根据题面设计 DATA，基础设施不足才拓展。不能以“还没发现协议缺口”为由跳过 DATA 设计，也不能为每道题先造新协议。
- **反馈而非暗补**：无黏封闭滑移稳态的非零环流无法凭原输入选择，必须回到题面讨论可确定范围或新增物理条件。DATA 不能悄悄固定模型、补任意状态或把一般流动缩成静水来让接口看似闭合；影响目标的修订须明确提出。
- **复制不等于自包含**：展开时层流混入湍流闭合、瞬时量混入 Favre／Reynolds 平均、稳态混入变化场，会改变答案。逐题检查模型、维度、时间、参数、边界和观测，不整份复制维护规范。
- **离散观测也需定义**：尖锐界面恰位于单元公共面时，表面质量率要有分配规则；熔凝黏度及相线折点导数、浅水固定床也须明确。不能用“物理解相容”掩盖实际存在的观测歧义，也不应在已有唯一迹限制足够时机械增添新条件。
- **维护资料不并列拥有题意**：领域参考已移到 qbank/maintenance/protocols，不随考生材料打包。它能说明实现依据，不能在 DATA 之外增加要求。当前候选文件才是审阅对象，旧散列不能覆盖改写后的版本。

## 协议实现中值得复用的做法

以下是当前实现采用的工程办法，不表示每项都是此前发生过的故障。

| 风险 | 当前做法与依据 | 后续复用时的检查 |
|---|---|---|
| 分析类型、材料和条件分散在题号／文件名／两套字段里 | CFD 显式 analysis、materials、profile；禁止重复 physics 声明，见 qbank/maintenance/protocols/CFD-2.1.md | 每题物理事实在本题 DATA 就地定义；题号不携带隐式条件；维护复用不增加考生阅读层 |
| 新功能意外改变旧题的解析与诊断 | 新配置显式启用，未启用保持旧行为；通用与专用错误分层 | 比较旧合法输入及旧非法输入；错误类别、路径和退出行为也属于兼容性 |
| Schema 合法被误当作物理定义完整 | Schema 管类型，跨字段检查管声明相容，实际物理解由独立验证建立 | 分别报告结构、语义声明、数值与物理验证；不要由校验器自动补值或修复物理 |
| 用相同数组长度或行号配对不同实体 | 节点按实际 tag 集合匹配，周期面按几何双射配对，法向取自流体域 | 用非连续 tag、不同排序和边界节点反向等变体检查身份关联 |
| 整体力／流量被塞入假探针 | aggregate 显式引用区域和 sum／mean；区分积分与加权平均 | 检查单位、区域、法向、符号与二维厚度，不能伪造点坐标来凑数组 shape |
| 采样值被默认视为任意连续函数 | 显式空间重建、时间插值和外推规则；SDK 不偷偷改变语义 | 用中间时刻、区间外、非均匀样本与节点到实体转换验证 |
| 为新检查给所有旧大网格额外加载连接关系 | 几何连接数据按需加载，见 validation.read_mesh 的 geometry 参数 | 扩展是否改变旧任务的内存、启动时间及全量载入行为 |
| 错输入触发 KeyError 而非诊断 | CFD 测试覆盖缺 sampling、错 location 等畸形引用 | 除合法样例外检查缺字段、错误层级、错误引用和非法组合；不只捕获单个异常就算修复 |
| 源码能运行但公开包漏带依赖 | 发布测试检查必要运行模块／考生文件并排除维护资料，在独立进程确认从解压包导入 | 检查实际模块路径，隔离 editable checkout／PYTHONPATH 的掩盖作用 |
| 测试工具覆盖已有算例，或以忽略规则掩盖缺失 | 示例生成器拒绝非空目的地；临时产物放 runs | 保留来源与审计资料；.gitignore 只排除应忽略的生成产物，不隐藏该追踪的修改 |

实现与测试依据： [CFD 规范](../maintenance/protocols/CFD-2.1.md)、[校验器](../../src/caeoj/validation.py)、[CFD 契约测试](../../tests/test_cfd_contract.py)。这些测试包括解析静止场、几何积分和打包隔离，它们不证明一般流动求解正确。

## 每次交付必须区分的证据

| 声明 | 所需证据／边界 |
|---|---|
| 题面完成 | 范围与协议可读、无未解决的答案歧义、独立考生审阅后复核；不等于已有数据 |
| 协议支持 | 声明可表达、实现与规范一致、有合法／非法输入和兼容性验证；不等于物理适定或数值准确 |
| 数据已验证 | 实际输入输出审计、来源及独立参考依据、误差与资源证据；不能用空数据盘点代替 |
| 评测已发布 | 冻结的题面／评分／数据版本一致，实际公开包可独立使用；不能只检查源码目录 |

不把未经校准的容差和资源说成实验结论，不复制其他章节的数值作为普遍默认值。审阅意见逐条闭合并复核最终文件；不采纳的意见说明理由，未决项保留其影响。独立审阅者只用公开材料，不能依靠作者代码、隐藏答案或维护记录把题意“脑补完整”。
