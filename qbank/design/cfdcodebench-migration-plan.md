## 目标与定位

语言、软件及空间／时间离散算法自由，包括解析法、有限差分、有限体积、有限元、谱方法及合适的降阶方法；给定 PDE、物理系数、闭合模型、边界、初值和观测目标仍必须满足。Cess 闭合属于固定模型，不因算法自由变成任意湍流模型。解析法不需要伪造网格收敛或模拟内部时间步。

移植完整保留 24 个来源 ID 与基础工况，包括相同 PDE 的不同工况。`2D_Convection` 与 `2D_Inviscid_Burgers` 不声称是不同通用能力；两个方腔题也不合并其黏度、时间和压力条件。每题可制作有意义的参数变化，必须逐例生成和验证参考，不能将同一份数组复制为多个隐藏例。

兼容对象是冻结的数学任务与物理观测；语言、输出协议、逐字段规则和参考验收改变后，不将新成绩冒称为原论文／原脚本排行榜的直接复现。来源差异及评分差异单列。

## 数据与判题接入

复用 [CONTRACT](../../docs/CONTRACT.md)、[case 级判题](../../docs/GRADING.md)及[扩展职责](CORE-AND-EXTENSIONS.md)。

1. 输入仍为 `problem.json`、引用 HDF5 和按需提供的 Gmsh MSH 4.1 ASCII。所有模型、参数、条件、初态、采样与尺度在本题 DATA 明示；无量纲模型明确长度、时间和场的参考尺度，不靠文件名推断。
2. 输出统一 `result.h5`，float64 数组 `[T,N,*component_shape]`，原值复制 IDs／时间轴，严格声明点值／单元平均／整体观测。提交只需在规定位置与时间输出；内部网格、语言和方法自由，不要求修改源码中的 nx、ny、nt。
3. 瞬态首批保留上游终止时刻；以后新增中间时刻必须公开声明并单独制作参考。输出时间不是内部步长。稳态使用物理稳态轴，不把迭代数当物理时间。
4. 上游二维数组转为显式坐标／IDs 关联的点值。周期端点重复、角点、圆环接缝、数组转置和非均匀谱节点分别审计；不能仅按数组尺寸 zoom。谱结果在公共观测位置进行有误差验证的重建，cell average 则实际积分，不能当作点值。
5. 极坐标圆环转为笛卡尔坐标采样位置，psi、omega 仍按公开定义提交；面积权重含真实 Jacobian。径向球对称问题明确球对称算子和采样意义，积分采用正的壳层体积权重，不给中心点零权重。二维 x-z 来源与协议全局 x-y 的轴映射必须显式声明。
6. 特征值输出以 entities location 表达模态身份，实增长率为 `[1,1,1]` 标量，无伪空间点；若将来要求复特征值，使用 components 显式实部／虚部，不使用 complex dtype。
7. 普通全场／标量评价复用 `direct_outputs` 和 quantity 绑定。需要规范化的压力场或特定观测由共享可信 evaluator 提取，然后复用 `evaluate_observation`。case 仅选择已装配 evaluator 标识与数据参数；不在 HF 放可执行评分代码，也不在核心按来源题 ID 分支。
8. 初版不依赖 `field.sample_points` 的当前二维 P1 三角形限制；直接提交统一观测点上的场即可覆盖一维、圆环、谱方法与标量。只有明确要求候选完整节点场再抽样时才复用该入口，并验证适用网格。

## 逐字段规则

每字段、每请求时刻、每规定分量独立判定，全部 AND；不计算跨字段平均误差。速度可存为 vector，但 u、v/w 逐分量判定。缺字段、轴错、非有限和单位错误不可被数值容差绕过。case 仍为通过 1、失败 0；多 case 总分按题面公开的汇总方式计算。

普通场默认采用现有 NRMSE：

`E(f) = sqrt(sum(w*(pred-ref)^2)/sum(w)) / max(sqrt(sum(w*ref^2)/sum(w)), scale_floor_f)`。

`scale_floor_f` 是公开冻结的物理／数学尺度，不能按候选答案拟合。若报告 NMSE，则为 E²；NMSE=0.01 对应 NRMSE=0.1，不能混淆为 1% 相对 RMS。初步设计目标为每字段 NMSE≤0.01，实际发布前逐题／逐字段校准；上游 0.1 阈值仅保留为来源对照，未授权移植原多字段均值评分。零场、近零特征值使用公开绝对误差规则，不加随意 epsilon。诊断同时保留绝对误差，避免仅有无量纲数字。

压力仅在数学问题本来具有常数自由度时规范化。推荐候选与参考均满足同一公开加权零均值约定；若允许评分时消去常数，仅对固定同一域的加权均值分别处理，不改变梯度、不拟合比例。指定压力边界的 C12 不启用自由平移。Laplace／Poisson 的 p 是势函数，不能仅因变量名为 p 就当压力消去均值。

温度优先定义相对给定公共背景的温升输出；若保留绝对温度，评分尺度须公开按温升定义，避免 Celsius→Kelvin 平移改变相对精度。此类规范化可由共享 evaluator 完成，但不能误用只影响 pointwise 相对容差尺度的 reference_offset 来声称改变 NRMSE。

每 case 的 `reference/grading.json` 保存字段规则、阈值、观测与 reference 资产；题面／DATA 给出完整数学定义。原上游“改源码后再运行”的收敛评分不迁入普通 case：作者负责 reference 的离散验证，考生负责结果。若另测跨分辨率适应性，输入提供不同公共观测网格的独立 case，同一冻结提交运行，不限制其内部离散或要求解析法呈现数值收敛率。普通 case evaluator 只评价该次结果；真正跨运行的关系不得假称已由单 case evaluator 实现。

## Reference 共通验收

- 上游数组仅为原始对照，先实际重跑作者程序，再与可独立验证的数学解或另一实现比较；改变数组格式不构成独立验证。
- 数值参考至少三档空间分辨率，加一次独立时间步缩小，均在同一物理终止时刻和相同观测语义下比较；解析／半解析参考改用截断、积分与高精度误差控制，不强制伪网格试验。
- 定义每字段参考不确定度预算，初始目标不超过考生允许误差幅值的十分之一；按 RMS 幅值预算时平方后再映射到 NMSE，不能把 NMSE 的十分之一误说成 RMS 的十分之一。具体预算随实际误差证据冻结。
- 核查边界、残差、守恒、正性与模型约束；这些仅为补充证据，不能单独认证全场精度。
- 高敏感长时间非定常场若不能在预算内验证，标为未就绪，不静默做时间／空间平移、相位对齐、滤波、删点或放宽阈值。统计观测只能作为另行公开的变体，不替换原终态场后仍声称完全兼容。
- 记录容器镜像、版本、脚本、配置、原始结果、空间／时间误差表、独立依据、重建误差、CPU wall time、聚合内存峰值、容差理由和局限。题面就绪、数据结构就绪、reference 验证和正式评测分别声明。

## 实施顺序与完成标准

1. **冻结与差异审计**：24 个 ID、40 个原输出及其来源摘要，逐题区分可直接数学化、需澄清、需重算；先解决 C12/C17/C19/C24 的具体定义问题，另核对所有时刻／谱节点／压力条件。
2. **协议与 evaluator 最小验证**：普通场/分量、绝对零场、自由压力与固定压力、温升、周期接缝/圆环、entities 标量各做最小 fixture。验证错字段、单位、IDs、时刻、非法 evaluator 和坏参考均进入正确错误类别；坏参考不能算考生错。核查独立公开包装配，不运行 LLM 考生。
3. **优先解析与半解析组**：C01—C04、C08、C10、C11、C13—C17；C17 先解决记号。输出可审查参考误差预算和首批实际 case，不仅制作配置。
4. **非线性／约束组**：C05—C07、C09、C12、C18、C24；定义审计未通过的保持暂缓。
5. **复杂/谱/稳定性组**：C19—C23，分别冻结字段、谱/时间截断、物理约束与统计局限，不因包名或某求解器可运行就宣布可靠。
6. **冻结发布材料**：逐题 instruction、DATA、case grading、作者脚本与来源证据联动审阅；逐例跑真实 reference→转换→协议→公开 grade→私有 verifier 消费链。先 titan 暂存；后续是否上传 HF、分支/PR及正式选样另按用户授权执行。结果场/重证据与轻量索引继续按现有维护分工。

容差和执行资源在真实多方法基准后逐题冻结，不复制上游600/3600秒或FOAMBench限额。题目需对原始离散与异构实现都公平；reference 验证的严格阈值不等于考生通过阈值。多 case 能力范围以实际覆盖为准，不把24个来源单例自动宣称为24个已验证的通用求解器。

独立设计审阅仅覆盖本规划；结果记录在维护审阅文件，不能外推为题面、协议实现、reference 或预算已完成。
