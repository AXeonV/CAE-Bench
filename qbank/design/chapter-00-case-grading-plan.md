# 第零章 case 判题测试题规划

新增 0.2 判题链路测试节，题目 `case-grading-test`，稳定 ID `caeoj-000004`。它是基础设施回传任务，与 0.1 通用格式／数据类型覆盖分开：固定二维三角形节点速度场，提交仍回传完整 x、y 分量及所有时刻。

case 评分可以选择整场逐值比较、输入节点场在指定点的 P1 重建比较（x、y 或 x/y 子集），或若干检查全部通过。题面公开完整目标和所有允许判据，不要求考生读取维护配置；配置只选择检查，不能增加输出。每个检查绝对误差不超过 1e-10 m/s，无相对容差；结构先完整校验，全部选中检查通过得 1 分。参考由输入目标场及确定的三角形重建产生，不涉及 PDE 或物理精度认证。

初始数据：6 个互异测试输入（整场、x、y、xy、x/y 双检查、整场与稀疏组合），2 个与测试不重叠的公开样例（整场和稀疏双检查）。全部使用非连续 node/element tags、多时刻、非对称数值及域内／共享边／边界测点。判题参考和完整提交示例分离；稀疏参考完整覆盖已选观测，绝不冒充 result.h5。

共享代码保持现有接口。题目目录保存题面、DATA、作者生成器／参考程序、执行配置和 HF 选样清单；HF 保存自包含输入、case 配置及参考／观测。新题仅绑定通用核心，不新增领域扩展。不修改既有物理题的要求。

验证涵盖独立设计与考生审阅、逐例数据审计、通过／超阈值／未观察分量／完整性／AND 组合、HF 实际上传与拉取装配、公开包安装和私有 verifier 准备。交付前清理装配与临时载荷，更新 PR20；实际 Linux 容器和 Agent benchmark 不在本次范围。
