# 第五章有限实施清单

全部13题均在本次范围；不止于规划或第一批。

| 编号 | slug | 题名 | 主要能力 |
|---|---|---|---|
| 5.1.1 | `thermal-steady` | 三维稳态导热 | 非均匀材料及混合温度／热流／换热边界 |
| 5.1.2 | `thermal-transient` | 三维瞬态导热 | 热惯性、初态与载荷历史 |
| 5.1.3 | `anisotropic-conduction` | 各向异性瞬态导热 | 全局导热张量与非共轴热流 |
| 5.2.1 | `nonlinear-conductivity` | 温变导热系数稳态传热 | 温度反馈到导热率的非线性 |
| 5.2.2 | `nonlinear-capacity` | 温变热容量瞬态传热 | 储热积分与温度相关热惯性 |
| 5.3.1 | `thermal-contact` | 有限界面热阻传热 | 温度跳跃、双侧热流和独立界面身份 |
| 5.3.2 | `thin-sheet-heat` | 薄层面内传热与面换热 | 实际厚度、面储热、边缘与上下表面换热 |
| 5.4.1 | `prescribed-advection-heat` | 给定速度场热输运 | 能量对流、入流热条件及导热热流 |
| 5.4.2 | `conjugate-prescribed-flow` | 给定流场的流固共轭换热 | 流体携热和固体导热及完美热连接 |
| 5.5.1 | `radiative-boundary` | 导热体表面对流辐射换热 | 四次方表面辐射及与导热联合响应 |
| 5.5.2 | `gray-enclosure` | 灰漫封闭腔体辐射热响应 | 给定视角系数下的多表面反射与热惯性 |
| 5.6.1 | `mushy-enthalpy` | 有限相变温区的焓传热 | 潜热、有限温区相分数与储热 |
| 5.6.2 | `isothermal-stefan` | 等温相变的Stefan焓响应 | 温度平台、多值相态与潜热演化 |

共同边界：非辐射腔体题使用固定参考网格和逐单元热物性；温度为绝对K，导热热流以外法向为正；对流入流与导热出流不同。相变初态是焓而非欠定的熔点温度。共享维护模板逐题展开，不增加章节COMMON或额外考生文档。
