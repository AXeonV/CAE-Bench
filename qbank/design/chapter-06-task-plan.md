# 第六章有限实施清单

全部10题均在本次范围；按6.1—6.2、6.3—6.4、6.5—6.6分批，持续完成。

| 编号 | slug | 题名 | 主要能力 |
|---|---|---|---|
| 6.1.1 | `acoustic-transient` | 线性声学瞬态传播 | 初态、波传播与实时边界历史 |
| 6.1.2 | `acoustic-harmonic` | 非均匀介质单频声响应 | 复相位、介质连接与阻抗边界 |
| 6.2.1 | `surface-radiation` | 给定表面振速的声辐射 | 封闭体外域Neumann驱动与出射波 |
| 6.2.2 | `rigid-scattering` | 刚性体平面波散射 | 入射／散射／总场及外域刚性条件 |
| 6.3.1 | `equivalent-fluid` | 被动等效流体吸声 | 复密度／压缩率与体积耗散 |
| 6.4.1 | `thermoviscous-acoustics` | 理想气体热黏单频响应 | 速度、压力、温度扰动及黏热损失 |
| 6.5.1 | `uniform-flow-acoustics` | 均匀平均流中的声扰动 | 周期域内对流波传播 |
| 6.5.2 | `lighthill-radiation` | 给定Lighthill应力的声辐射 | 紧支撑流源张量到自由场压力的单向传播 |
| 6.6.1 | `resonator-wall` | 局部共振吸声壁的瞬态响应 | 壁面记忆、储能与声场双向反馈 |
| 6.6.2 | `modal-vibroacoustics` | 给定结构模态的单频振声耦合 | 模态惯性刚度与声压载荷反馈 |

所有题只依赖instruction、独立DATA、CONTRACT。共同语义：绝对坐标和实际tag身份；声压是扰动而非总静压；相量exp(+iωt)，出射exp(−ikr)/r；有界域外法向与障碍固体向外法向逐题明确；点与实体平均分开；复量实虚逐分量评分。
