# 第七章 电磁场与电路分析规划

本次由原章级方向补全为7节10题；新增拆分为作者依据题库哲学作出的有限实施选择。基线d7082bd，启动工作树干净、无已有第七章题目及用户未提交修改。本次完成整章规划、题面、自包含DATA、必要共享扩展、评分执行配置及独立考生审阅；不制作正式数据、参考或发布评测。

| 节 | 能力与题目 | 相邻边界 |
|---|---|---|
| 7.1 静电 | 介质电势；带给定总电荷的浮置导体 | 二维平面、单位深度；浮置电极电势未知，不能当普通Dirichlet |
| 7.2 电流传导 | 稳恒传导；介质电荷弛豫 | 后者含位移电流与真实初态，无磁感应或温度反馈 |
| 7.3 静磁 | 给定面外电流的磁场 | 二维Az，线性各向同性材料，不要求非线性铁磁或磁滞 |
| 7.4 磁准静态 | 单频涡流 | 给定面外外加电流，无位移电流，零纵向标势梯度；不冒充通用三维导体连接模型 |
| 7.5 高频全波 | 有耗PEC腔体单频响应 | 三维矢量Maxwell，保留位移电流；无开放辐射、端口或本征模提取 |
| 7.6 集总电路 | 瞬态RLC；单频RLC | 显式有向支路、地、源和初态，无半导体非线性或开关 |
| 7.7 场—路反馈 | 电压驱动线圈与涡流场 | 给定绕组密度与真实轴向长度，线圈电流未知；场与电路双向反馈，不暗加线圈几何提取 |

给定数学模型用来冻结这批有限物理族，考生负责实现、离散、线性代数、积分和误差控制；覆盖整个公开范围的解析或降阶方法同样有效。几何、介质分布、频率、载荷与拓扑由算例变化，不以器件或来源命名题目。电势／磁矢势参考、e^(+iωt)约定、面外单位与功率平均因子逐题明确。
