# 第七章有限实施清单

全部10题本次完成，按7.1—7.2、7.3—7.5、7.6—7.7实施。共用电磁静态／相量规则不构成额外考生阅读依赖。

| 编号 | slug | 题名 | 物理／观测与主要能力 |
|---|---|---|---|
| 7.1.1 | electrostatic | 介质静电场 | 2D实稳态，正介电常数、电荷与电势／位移通量；电势、电场、位移场面积平均 |
| 7.1.2 | floating-electrode | 浮置导体静电场 | 2D实稳态，增加等势但未知电压的带总电荷导体；上述场及浮置电压 |
| 7.2.1 | dc-conduction | 稳恒电流传导 | 2D正电导、体注入与电压／电流边界；电势、电场、电流与焦耳热 |
| 7.2.2 | dielectric-relaxation | 介质电荷弛豫 | 2D实瞬态，正介电／电导，初态和边界历史；电势、电场、传导电流及总电流 |
| 7.3.1 | magnetostatic | 面外电流静磁场 | 2D实Az、正磁阻率与面外电流；Az、B、H |
| 7.4.1 | harmonic-eddy | 面外单频涡流 | 2D复Az、导电和非导电介质；Az、B及感生电流 |
| 7.5.1 | maxwell-cavity | 有耗腔体全波响应 | 3D复E/H、正介电／磁导／电导、PEC边界、外加电流；场与时间平均损耗 |
| 7.6.1 | rlc-transient | 有向RLC电路瞬态 | 实集总网络、源历史、节点初始电压及电感初流；节点电压、支路电压和电流 |
| 7.6.2 | rlc-harmonic | 有向RLC电路单频 | 复集总网络与频率响应，无瞬态初态；上述相量 |
| 7.7.1 | coil-circuit | 线圈与涡流场反馈 | 2D复场加真实轴长、绕组密度与串联RLC电压驱动；Az、B、感生电流、线圈电流和磁链 |

材料和源逐单元常值，节点边界／初态采用唯一P1重建；电路用entities真实离散身份。连续场输出为实际面积／体积平均；电极节点为同一等势值，不用任意探针代替全局未知量。全部时间、复量和平均语义逐题展开。无正式数据、参考与运行校准；所有数据生产保证在DATA显式列出。
