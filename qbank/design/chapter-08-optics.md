# 第八章 光学与光子学分析规划

基线06b289b，启动工作树干净，无已有第八章文件或用户未提交改动。原章级方向现补全为6节8题；拆分是作者依据能力边界作出的有限实施选择。本次交付整章规划、全部题面和自包含DATA、必要共享扩展、评分执行配置及独立考生审阅；正式数据、参考和发布留后。

| 节 | 能力与有限题目 | 边界 |
|---|---|---|
| 8.1 几何光学 | 平行分层介质射线 | 折射、全反射终止、位置／方向／光程；不求波干涉、散射分裂或偏振功率 |
| 8.2 相干与干涉 | 确定相量的相干叠加；给定互相干矩阵的统计光强 | 后者保留非对角相关，不能逐模态强度相加；共同标量偏振，无自发选择相干模型 |
| 8.3 标量衍射 | 有限孔径Fresnel传播；角分布远场衍射 | 前者有限空间点，后者出射方向与远场系数；区别不能只用不同距离的同一采样掩盖 |
| 8.4 偏振 | 被动Jones元件链 | 确定横向复振幅、Stokes及光强，不声称去偏振随机系统 |
| 8.5 层状介质 | 单频斜入射多层膜 | TE／TM，界面及多次反射相干，无吸收、增益、粗糙界面或开放三维散射 |
| 8.6 导波光学 | 分层平板导波模态 | TE／TM开放包层、有效折射率、全空间归一化模态与排序，不当成有限箱体本征问题 |

每题定义可复用问题族，介质、几何、层数、相位、相关性和状态由算例变化。给定有限数学模型及规范是为固定评价目标，考生负责实现、内部离散／求积、求根和误差控制，解析／降阶方法覆盖整个公开范围同样有效。不得要求复制参考算法。

本章以光传播、干涉、偏振与导波为主要目标，不重复第七章有耗PEC腔体矢量响应；射线不混同第十五章统计辐射输运。全矢量光子晶体、非线性光学、随机散射、增益／激光、超短脉冲、一般非平行曲面追迹作为后续独立方向，不声称本次覆盖。

采用现有mesh、points、entities、fields与conditions。角方向和光学元件是真实离散对象，接收点用真实points；孔径三角网格只表示输入积分支撑，不约束内部数值离散。新增共享能力归qbank/extensions/caeoj_ext/optics，核心和发布器无预期缺口。每题只依赖instruction、DATA、CONTRACT；相量符号、复量布局、强度归一化、远场系数及模态相位逐题展开。

暂定精度和预算按不同观测与复杂度选择，正式数据阶段须独立验证模型适用、参考精度和预算可达性。见[逐题清单](chapter-08-task-plan.md)、[进度](reviews/chapter-08-progress.md)。
