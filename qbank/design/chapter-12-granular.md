# 第十二章 颗粒与散体力学分析规划

启动2026-10-16，基线13f6d6b。原总体目录仅有方向，无章内既有决定。本次补齐6节7题，全部实施题面、自包含DATA、必要扩展、评测配置和独立考生审阅；正式数据、参考解及发布留后。

| 节 | 能力范围 | 边界 |
|---|---|---|
| 12.1 颗粒受力运动 | 给定外力及线性阻力的惯性运动 | 无颗粒相互作用；流场不反求，不重复流固耦合 |
| 12.2 耗散碰撞 | 三维多粒径软球法向弹性与耗散 | 无摩擦、黏附和自转动力学 |
| 12.3 摩擦与自转 | 正则化滑动摩擦、力矩及角动量 | 明确无静摩擦历史，不以隐藏接触算法判分 |
| 12.4 黏附 | 有限程可逆黏聚与接触/脱离 | 无烧结、塑性或滞回，材料力律公开 |
| 12.5 散体整体响应 | 周期代表体内接触网络的动力学与宏观应力、配位和堆积率 | 以微观到宏观观测及周期邻接为核心，非按容器几何另立碰撞题 |
| 12.6 粒群分布演化 | 离散体积级聚并；体积守恒破碎 | 均匀群体平衡，不跟踪每颗粒轨迹，不等同空间DEM |

各题按动力学责任和观测区分，粒子数、粒径、质量、初态、外力、相互作用参数及分布由算例变化。前五题固定三维球形颗粒与公开响应；后两题为统计数量密度ODE，bin身份不是空间坐标。考生负责数值实现、时间积分、邻域/事件处理、误差控制，允许任何覆盖全范围的方法。

本次有限范围不声称覆盖非球形、静摩擦记忆、滚动/扭转阻力、塑性断裂、湿颗粒毛细桥、非局部连续散体本构、一般壁面与活动边界、随机颗粒输运；这些保留为后续独立能力，不以几何名字填充题目。与第四章区别在多粒子接触和群体响应而非关节机构；与第十三章区别在固相颗粒运动而非孔隙流动；双向流体反馈归第十七章。
