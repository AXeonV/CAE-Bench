# 第十三章有限逐题清单

全部题目采用固定二维平面域。物性、初边值与载荷均由输入给定；无未声明物理过程。稳态没有物理初态，瞬态的输出时刻不约束内部时间步或迭代次数。

| 编号 | slug | 名称 | 必须新增的能力／观测 |
|---|---|---|---|
| 13.1.1 | darcy-steady | 各向异性饱和稳态渗流 | 张量渗透率、重力、体积源、压力与 Darcy 通量 |
| 13.1.2 | darcy-transient | 饱和介质储集渗流 | 压力储集系数、初压及变化载荷 |
| 13.1.3 | forchheimer-steady | 惯性阻力稳态渗流 | 正定线性阻力与各向同性二次阻力 |
| 13.2.1 | richards-steady | 非饱和稳态渗流 | 压力水头、持水与相对导流曲线 |
| 13.2.2 | richards-transient | 变饱和瞬态渗流 | 含水储量、饱和区储集与初始水头 |
| 13.3.1 | immiscible-two-phase | 不可压缩两相渗流 | 毛细压、相对渗透率、相饱和度及相通量 |
| 13.3.2 | compressible-two-phase | 弱可压缩两相渗流 | 各相压力相关密度与质量存量 |
| 13.4.1 | embedded-fracture | 嵌入裂隙稳态渗流 | 体域压力迹、线压、切向流与净交换 |
| 13.4.2 | dual-continuum | 双连续体瞬态渗流 | 各连续体体积折算容量、流动和交换 |
| 13.5.1 | pore-creeping | 固定孔隙低惯性流动 | 显式孔壁、压力基准与表观平均流速 |
| 13.5.2 | pore-laminar-transient | 固定孔隙层流瞬态流动 | 流动惯性、初速度、变化驱动与体积平均 |
| 13.6.1 | porous-tracer | 饱和多孔介质被动输运 | 孔隙储量、给定 Darcy 通量与弥散 |
| 13.6.2 | porous-sorption-decay | 多孔介质吸附衰减输运 | 平衡固相吸附存量及两相分别衰减 |

资源初案：线性稳态 300 s，非线性稳态／瞬态 900 s，孔隙瞬态 1200 s；4 逻辑 CPU、4096 MB、最多 6000 三角形、8000 节点、101 输出时刻。配置需与逐题题面一致；正式数据的预算与误差可达性未校准。每个输出量给出明确逐值绝对／相对阈值，统一读取 grading.json。

实施批次：规划 → 13.1—13.2 → 13.3—13.4 → 13.5—13.6 → 共享扩展与配置验证 → 三组独立考生审阅及最终复核。所有题目均在本次范围内。
