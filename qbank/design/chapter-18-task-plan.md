# 第十八章有限逐题清单

所有题均瞬态；给定元件关系和固定物理模型，内部算法自由。spatial_dimension=1为网络一维端口／支路坐标标记，不伪造空间采样。全章逐题清单固定如下，不把拓扑或来源作为新题。

| 编号 | task标识 | 材料、范围、方法责任和共同观测 | 明确不覆盖 |
|---|---|---|---|
| 18.1.1 | geared-torsional-network | 连通图、惯性节点与弹性变比支路；组装反力矩，输出角度、角速度、尾端支路力矩 | 变比切换、刚性齿轮约束 |
| 18.1.2 | deadzone-transmission-network | 同类图的对称弹性死区及全程并联黏性；处理刚度折点，输出角度、角速度、尾端力矩 | 冲量、干摩擦、齿轮碰撞恢复 |
| 18.2.1 | nonlinear-hydraulic-network | 容腔顺应性、外泄漏、非线性串联阻力；输出节点表压和有向体积流率 | 惯性波、空化 |
| 18.2.2 | distributed-pipe-network | 每支路1D线性可压缩声学、节点容腔与漏流；输出节点表压、每支路双端流率 | 大扰动、壁运动、湍流 |
| 18.3.1 | isothermal-pneumatic-network | 理想气体定容等温储存、长毛细管平方压力导通；输出绝对压力和有向质量流率 | 临界流、温度演化 |
| 18.4.1 | radiative-thermal-network | 热容与支路传导辐射、对外散热；输出绝对温度和有向热率 | 几何辐射系数提取、对流场 |
| 18.5.1 | nonlinear-diode-rlc-network | 节点对地电容、支路串联RL及反并联Shockley二极管；输出节点电势、支路电流 | 理想开关、任意电源约束DAE |
| 18.6.1 | motor-thermal-feedback-system | 集总电机电流、转速、温敏线圈及散热；联合求电流、角速度、绝对温度 | 铁损、磁饱和、几何热场 |
| 18.6.2 | electrohydraulic-actuator-system | 电机泵、双可变容腔、弹簧阻尼质量；输出电流、转速、位移、速度及双腔表压 | 阀切换、泄漏到外界、碰撞 |
| 18.7.1 | sampled-position-servo | 连续机电位置与数字PI、限幅、条件积分；输出角度、转速、电流、保持电压 | 自主控制设计、PID导数滤波 |
