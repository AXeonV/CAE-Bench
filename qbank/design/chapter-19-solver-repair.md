# 第十九章：求解器诊断与修复

本章要求 Agent 在给定真实求解器版本及接口约束下修改实现，交付可复用的修复。目标既包括物理与数值诊断，也包括现有软件中的正确实现及回归保持。与其他章从零生产求解器的任务区别在于：指定求解器、基线和修改边界本身属于方法要求。不得用绕过指定实现、另写输出程序替代修复。

这是本次任务提出的章级扩展；不重排已有题号，不把某个开源仓库作为物理分类。来源、缺陷版本、补丁及验收证据放在各题 author 和维护记录中。

| 节 | 能力与边界 | 本次范围 |
|---|---|---|
| 19.1 约束与状态求值 | 指定状态下的运动学相容性、动力平衡、约束反力及试探状态；与长期轨迹积分区分 | 2题 |
| 19.2 材料与离散算子 | 本构分支、坐标变换、离散残量及一致性；不包含完整多物理应用的适用性认证 | 2题 |

| 19.4 观测与软件契约 | 场量、积分量、耗散、坐标及状态输出语义；不以输出修正冒充求解改进 | 6题 |

## 19.1.1 双边距离约束系统的加速度与反力求值

- slug：`constrained-assembly-repair`。
- 三维有限质量刚体，质心连接的理想双边距离约束，可连接固定锚点或两个活动体。无接触、摩擦、柔性及时间变化的约束长度。
- 在给定位置及速度相容状态求瞬时线加速度和每个约束对第二个端点物体的全局力向量；包含无约束体、单约束及相互耦合的多体约束网络。质心连接使转动自由度解耦，不考查有限转动参数化。
- 固定事实：质量、质心位置/速度、外力、重力、端点关系和约束长度；状态相容及约束独立由数据建设保证。参考误差必须覆盖约束耦合及尺度变化。
- 考生责任：诊断并修复指定 Chrono 核心装配实现，保持公开 API、指定求解调用和现有位置/速度层功能。不得修改可信输入转换器或用另写求解器输出结果。
- 输入至少含两个有实质区别的情境：运动单质点与固定点的距离约束；具有质量耦合的多活动体约束链/网络。共同接口和实现须覆盖两者，而非仅修正单摆公式。
- 评分对瞬时加速度及全局约束力分别比较，全部通过才记该 case 通过；另覆盖静止、自由体、位置/速度装配回归。来源补丁不充当唯一数值标答。
- 方法验收：只接收指定核心源文件替换件；可信构建从不可变基线增量编译，可信驱动调用 `ChSystem::DoAssembly()`，不执行考生提供的入口或数据转换器。数值评分之外单独记录构建及方法合规状态。
- 位置/速度回归单独采用不相容初猜，检查原入口消除距离及法向速度残差的能力；它们属于软件回归要求，不把初猜误差混入瞬时力学参考。公开题面须分别描述两类输入的保证和验收。
- 与第四章边界：第四章评价所生产多体求解器的运动/动力学能力；本题明确要求修复真实软件中已有入口，不要求完成时间轨迹积分。

首题来源为 Project Chrono #846，采用修复前固定提交。缺陷版、上游修复版及独立约束力学参考须均实际运行；只看到 PR 合并不足以宣称题目就绪。源码与构建环境离线交付，隐藏数据不进入考生容器。增量构建和逐例执行的预算分别校准。
