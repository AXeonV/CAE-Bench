# PDEBench 250000 条轨迹迁移执行规划

## 当前范围

2026-10-18 用户明确收束范围：直接使用 HF 上 PDEBench 已有数据，将其组装为 case。**不重新求解、不生成替代参考、不以额外数值认证作为迁移门槛。** 本节取代此前有关参考补算和高精度资格的迁移要求。已有试验保留为历史证据，不构成继续运行求解器的授权或义务。

从零组织来源数据，不受旧题划分约束。归档初始帧作为输入，后续有效帧作为来源参考；原样保留字段、坐标、时间、参数及已有边界说明。不得把初始值重新解释成分片常数后生成另一问题的参考。来源未说明的语义如实标记未知，不自行补设。case 的含义是复现 PDEBench 归档结果，不宣称连续 PDE 精确解或新增的独立精度认证。

以一条来源轨迹对应一个来源 case 登记，目标覆盖全部 250000 条。每例包含自包含输入、归档参考、字段/时间映射、来源版本/文件/行号及完整性摘要。时间帧不拆成独立 case。同输入或同初态的关联保留在索引中，正式选样时处理，不静默删掉来源记录。损坏或缺失条目记录异常，不能伪造为成功。

## 迁移验收

1. 登记固定来源版本、文件、行号、参数、字段和有效时间，覆盖账不重不漏。
2. 检查数组形状、有效帧、坐标和有限值，隔离无法正常读取的记录；不以守恒、网格收敛或另一求解器对照作为入库条件。
3. 建立原字段到 case 字段的明确映射，检查输入与参考对应同一条来源；数值无损转换，禁止偷偷重采样、改单位、裁剪有效帧或补算。
4. 在 HF 临时盘组装、打包、上传，从固定提交重取并校验摘要及真实读取链。范围读取只报告范围载荷校验，不冒称独立计算整源文件 SHA。
5. 交付来源覆盖、成功/异常清单及可装配池。正式评测子集、评分容差和区分度另行确定；本次不运行考生，不以归档数据自比通过证明数值正确。

旧平流试验使用解析平移重新生成参考，其工具吞吐可作成本代理，产物不能自动当成本次直接迁移的交付。hf_migrate.py 保留为历史路线；当前直接迁移使用 hf_archive_migrate.py 和 launcher 的 archive-pilot 阶段，复用相同 pack/upload/assemble/verify。三族及全部源文件的先导结果由[直接迁移记录](reviews/pdebench-direct-archive-20261018/README.md)维护。先导入口处理有界范围；后续 archive-full 阶段在单个有硬超时的云端作业内推进250批，执行证据见[全量运行记录](reviews/pdebench-full-20261018/README.md)。

## 云端布局与执行

大数组留在 HF；本地只传代码、配置、小型报告及日志。复用现有 pack/upload/select/fetch/assemble/verify 分片池，TAR 保存各 case 资产，64 个哈希分区维护描述；机制见[存储设计](DATA-STORAGE.md)和[操作指南](../maintenance/DATA-SYNC.md)。不恢复一例多远端文件的布局，不隐式覆盖 main 或正式选样。

按连续 1000 行组织约 250 批，单写入者发布；工作集控制在临时盘容量内。三族适配与先导核验见独立记录；扩为千行生产批次时确认工作集、批间恢复与剩余预算，再逐批迁移。每批记录来源范围、输入摘要、上传提交、重取结果与费用；成功批次可恢复复用，失败项单列，远端不同内容停止核对。正式评测随后另选，不混入本次迁移。

## 预算与停止条件

当前预算唯一维护于[实测预算记录](reviews/pdebench-calibration-20261018/BUDGET.md)，最新依据已换为三族直接迁移先导；旧平流加权代理保留在历史测量中。直接迁移不计入求解器重跑或新参考制作费用，小批次外推不当作固定报价。

沿用已有 USD 1 累计 Jobs 上限，所有历史支出和未释放预留均计入，账户余额不扩大授权。先前准备活动的 USD .10 上限也不因范围变更自动增加。存储配额在执行前核对，不购买扩容，不使用 GPU 或模型 API。每批结束重算剩余费用，预计超出剩余额度即停止并交付已完成部分。

用户后续已明确授权启动三族25万条全量，云端作业及监视状态由[全量运行记录](reviews/pdebench-full-20261018/README.md)维护。监视只观察明确登记的Job和小报告，在有意义变化时通知；硬超时和费用停止由执行器承担，定时提示词不自行决定扩支或重试。
