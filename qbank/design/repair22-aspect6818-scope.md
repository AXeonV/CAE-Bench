# 19.3.6 变形边界切向约束修复：独立设计审阅卡

本卡是拟建设范围，不包含作者原型、运行成绩或参考修复实现。

## 目标与来源

来源固定为 [geodynamics/aspect#6818](https://github.com/geodynamics/aspect/issues/6818)，关联解决材料为 [PR#6829](https://github.com/geodynamics/aspect/pull/6829)。不替换来源。基线固定为其合并前提交 `021e8ef55cae159a101e234ff9622e5de0364068`。

考察 Agent 诊断并修复真实 ASPECT 已有求解入口的能力：独立网格运动改变边界形状时，切向材料速度应满足**当前几何**的 `u·n=0`，同时保持静态曲面和规定材料速度边界。不同于从零实现流场求解器；不能用单独答案程序绕过 ASPECT。

网格速度 `w` 与材料速度 `u` 为不同物理量。本题要求的切向材料边界是 `u·n=0`，不是 `(u-w)·n=0`。网格运动不会自动规定材料随网格运动。

## 方法及公开范围

- 常密度、常黏度、零重力、定温、不可压缩线性 Stokes；时间用于改变网格与规定边界，每个状态忽略惯性。
- 使用真实 ASPECT 的 block AMG 求解路径。GMG不在本题范围：上游解决材料明确保留相关GMG问题，不能将其宣称为已解决范围。
- 2D或3D，无自适应细化的盒；另含静态2D整圆环回归。不承诺3D球面、其他几何或任意剧烈网格运动。
- 修改并仅提交真实 `source/simulator/core.cc` 替换件。此文件拥有本题需保持的既有求解生命周期和边界约束入口，限制用于考察库实现修复。保留公开API、指定物理、真实求解调用、可信输入输出驱动及其余库源码，不得另写输出程序替代修复。
- 离线交付固定真实源码、许可、依赖和构建工具；允许关闭与上述解析几何无依赖的可选WorldBuilder。提交大小、编译／求解时限及内存上限须根据实际资源校准后公开，不在设计阶段假定资源已经达标。

## 三个公开工况家族

1. **变形平行边界与多方向材料流。** 2D盒的上下边界具有规定网格速度 `(0,kx)`，侧边网格允许沿边移动；侧边规定材料速度。3D推广为 `(0,0,kx+ly)`，四侧规定材料速度。覆盖正负坡度、不同材料流向、两个横向分量、零变形回归和多个时间步。顶底是当前平行平面，不假定网格内部也是仿射变形。
2. **上边界变形与非均匀驱动。** 2D盒只在上表面规定随x线性变化的网格速度；下边界网格固定并规定抛物线水平材料速度，侧边材料速度切向。用于保留来源中的非均匀剪切流实质，避免只测试均匀流特解。
3. **静态曲面回归。** 2D整圆环网格固定，内壁规定刚体转动，外壁材料速度切向。检验对变形边界的修复是否保持静态曲面语义。

盒子工况应包括当前坡度绝对值跨越1的有效几何，覆盖边界方向明显改变的情境。宽高比、变形幅度及时间步须保证无单元反转；公开参数域应由真实算例和资源核验支持，不能声称支持任意变形。

## 数据语义与评价提案

- 输入公开盒尺寸或圆环半径、维度、材料常数、驱动／网格运动参数、离散细化及完整观测时间轴；每族字段和允许组合由本题DATA自包含定义。
- 采样采用全时域内始终位于域内的固定Eulerian Cartesian点，按CONTRACT的points表示，坐标及严格递增probe_ids显式给定。输出为这些固定位置的材料速度及压力，使用公开时间轴，不含移动采样语义。可信运行器调用真实ASPECT原生PointValues／VectorTools点值API，不自编插值或修正答案。
- 所有要求时刻均评价，不仅评价末步、平均速度或法向残量。固定采样点的选取应保留三族约束错误的检出能力，并检查在整个时间区间内均严格位于域内。
- 计划配置固定最大步长并使所消费原生输出严格落在给定均匀时轴；不在可信驱动中插值、补物理或修正答案。若原生时间推进不能满足这一表示，须在制作阶段反馈设计与DATA，不能隐式改变时轴。
- 压力基准、向量坐标系、全部单位、法向／切向语义及原生输出精度须公开。转换器只执行输入转换、真实库调用及原生输出到HDF5的转换。
- 容差按解析／离散误差与原生序列化精度确定；不得用放宽阈值迁就错误修复。方法合规与数值成绩分别核查。

## 拟独立核验及明确缺口

- 平行变形边界：当前面 `z=q+t(kx+ly)` 的法向方向为 `(-kt,-lt,1)`。均匀材料速度 `(U,V,t(kU+lV))` 的散度与应变率均为零，并切于该面；在匹配边界条件、零重力及压力归一化下可作为独立连续解析依据。还须核验实际几何／边界与这一公式适用条件相符。
- 静态圆环：刚体转动 `u=(-ωy,ωx)` 具有零应变率与散度。曲面几何和有限元误差须单独做细化／误差核查，不将连续公式直接冒充离散程序的无误差输出。
- **非均匀剪切家族的完整流场独立参考资格尚待取得。** 计划用有出处的另一成熟求解器、适用解析依据或其他充分独立途径核对真实ASPECT参考；仅与同一上游补丁一致、守恒、低残量或法向分量正确，不足以独自证明全部速度／压力观测正确。若尚未取得，保留该项未完成，不能悄悄删除该家族或将题目缩成均匀流公式题。
- 缺陷版与参考版应在全部正式case上实际重放；公开包独立安装、真实编译重建、隔离及全部数据审计必须另有证据。设计审阅不替代这些验收。

本轮不包含新增付费模型Benchmark；实际验收计划使用真实库、独立数学／实现核对和Harbor Oracle。
