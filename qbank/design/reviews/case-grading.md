# Case 级判题实施与验证

以 PR19 的 `5acb08d` 为基础，执行协议见[判题说明](../../../docs/GRADING.md)，数据布局见[数据池设计](../DATA-STORAGE.md)。本记录保存实施范围与证据，不另行定义接口。

## 实施范围

- 每例 `reference/grading.json` 是运行时唯一评价入口。229 份原题目配置原值迁入 `author/grading-template.json`，仅供制数使用；不存在题目级回退。
- 提交仍满足完整 outputs 契约。新增通用二维三角形节点场 P1 测点评价，允许分量子集和稀疏参考，首期仅对齐已有输出时刻。既有题目未引入新的观测请求，也未切换稀疏评分。
- 配置、测点、参考进入 HF；可信评价实现位于核心或已安装扩展。HF 不提供可执行代码。完整提交示例与稀疏参考分开绑定。
- pack、fetch、verify、发布器、Harbor 组装与评价 worker 使用同一预检实现。隐藏配置仅进入 verifier；公开包包含样例判题资产。
- 评价证据绑定输入、网格、配置、参考、核心及选中扩展闭包和依赖版本。评价时限独立于求解时限，并计入总预算；基础设施错误不生成考生成绩。

## 验证

2026-10-17 的最终全库回归：426 passed、5 skipped、1,316 subtests passed。跳过项是当前 Windows 平台不能执行的生命周期或链接检查；未把它们记为通过。PDEBench 的离线转换用例另行确认 21 passed、35 subtests passed。

针对性验证覆盖分量绑定、节点 tag 映射、精确时刻、域外与退化单元、缺失／多余参考数组、单位与轴不一致、完整提交检查、可信注册、资产变更检测、数值引擎等价性和基础设施超时。稀疏 fixture 经制池、装配、严格核验、公开发布及隔离公开运行闭包验证。

传热与固体共 34 个模型通过普通安装验证：新虚拟环境安装，移走源码，切换工作目录，再以隔离 Python 执行输入／输出校验、正常判题、非法候选和非法参考。另验证仓库核心 wheel 安装后的 case 判题，补齐 JSON 资源打包；公共资源读取显式使用 UTF-8。8 个 SKILL 均通过格式校验，相关链接有效。

独立审阅后的改进：将输入与完整实现闭包纳入评价证据；补充 example 声明的成员、完整契约和实际通过检查；修正数值策略文档中的旧运行来源描述。自查另修正 Windows JSON 编码、核心 wheel 资源以及公开 CONTRACT 对未打包维护文档的引用。PR 复核后进一步让隔离公开闭包实际执行样例评价，而不只预检配置和提交结构；同时消除作者模板测试对已装配正式数据的依赖。补充回归 23 passed、239 subtests passed。

## 证据边界

本次证明格式、资产覆盖及当前消费链可用，不重新认证参考的数值精度、物理正确性或资源校准。既有样例／测试重叠保留，整套严格正式消费仍拒绝该重叠，须另行审核选样。未运行真实 Linux Harbor 容器、收费 Agent benchmark 或完整 PDEBench 数据下载转换。
