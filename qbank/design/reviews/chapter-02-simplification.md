## 发现与修复

| 问题 | 修复及范围说明 |
|---|---|
| 展开时部分 2.2 层流题误带湍流闭合／Reynolds／Favre 模板 | 删除不适用分支，明确瞬时物理场和普通单元空间平均；不改变原层流模型 |
| 2.1 输入 quantity 未明确、瞬态区间例子像固定值 | 明确输入标签无额外枚举约束、用途由条件引用/data键/单位决定；示例 start/end 不是规定数值，不新增原协议没有的标签限制 |
| 稳态采样混列变化场／迭代初猜与物理初态 | 按题去掉不适用时间分支，constant/[0] 与稳态限制一致 |
| 两个无黏封闭滑移稳态题声称非零分支唯一但没有选择信息 | 按现有无黏方程，非零 u 与 −u 均满足相同稳态条件；原唯一性保证无法选定环流。题面明确本版仅纳入公开条件可唯一确定的等熵静水平衡 u=0。没有新增环流字段或假装已有非零分支支持；若以后需要一般非零无黏稳态，须另行设计物理选择条件 |
| 润湿壁面牵引的 mu、法向及所属相含糊 | 就地定义域外壁面法向、切向投影、各相黏度和完整 Navier 牵引 |
| 尖锐蒸冷界面恰位于单元公共面，质量率积分可能重复或漏计 | 公共面界面测度两侧各半，排除储槽边界上的正面积相变界面 |
| 熔凝“牛顿混合动量”没有唯一黏度约定 | 给出全域使用 viscosity_a 的完整动量与有限 mushy 阻力，不采用未声明的 α 加权或固相黏度 |
| 熔凝相线折点处相变率导数不唯一 | 初始沿用有限唯一右迹；其他请求时刻保证单元平均物质导数有有限唯一经典值，不在左右导数不一致的折点强行请求 |
| 浅水泛化输入采样可能被理解为动床 | 明确 bed 为固定地形、单帧 constant，不包含动床做功；去掉干湿题中其他全湿题分支 |
| 零散不适用 SDK／张量／域条件模板 | 清理无气体、无域初态、稳态及无对应材料时的多余说明，保留可选工具而不要求额外阅读 |

首轮审阅曾考虑的“2.11 输入时间折点导致压力歧义”已由审阅者撤回：题内已有唯一连续迹／导数迹的观测限制，不应为此机械增添新条件。这一项未作无依据的协议修改。
