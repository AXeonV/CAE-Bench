## 独立考生审阅

三位单独subagent只读最终instruction、DATA及docs/CONTRACT；未给作者实现、规划、记录、数据或预设答案。分组：review_transport覆盖15.1与15.2三题，review_diffusion覆盖15.3两题，review_inventory覆盖15.4与15.5三题。共17个不同公开文件，最终实际SHA256与审阅者报告逐项匹配，见[版本清单](chapter-15-review-manifest.json)。修订后完整复核，最后纯文字裁剪只复核变动DATA，其余沿用相同散列版本。

| 实际问题及反例 | 修订与最终复核 |
|---|---|
| 有源输运／扩散scalar_flux误带critical归一化；源加倍可能被错误归一化抹掉 | 有源题明确保持输入激励的绝对幅值，只有临界题使用积分归一化 |
| 空间题混入“有限维中1仅作标记” | 空间题明确1对应平板法向全局x轴；有限维题另行说明 |
| 入射表未明写非负，可能误接受负粒子流 | 左右入射L_g、R_g明确≥0，与实际检查一致 |
| “包括内部控制结点”可能误要求额外输出帧 | 仅输出requests，积分处理其间控制结点，不增加帧 |
| 沉积集总量被统称空间点值 | 按输出表定义，不另加空间／时间平均，层沉积仍为W/m2 |
| 无关网络、层、计数符号、角输运、控制轴、初态和矩阵模板文字 | 按每题实际能力裁剪并回写展开器；重建保持最终审阅散列 |
| 模糊“极端刚性”等被误作已验证参数边界 | 正式数据须有独立预算精度证据；不将结构合法或参数正值当作可达性证明 |

最终限定审阅范围内无未决必修问题；不是无缺陷或物理数值验证保证。审阅还考虑初始非平衡、请求不含0、独立控制结点、重复率、稳定核素、分支汇合／流出、反应循环和零通量等反例。

## 评分及执行配置消费

基线实际实现已核对：caeoj_tools.grading_policy.task_policy读取显式grading.json，caeoj.grading_policy.resolve_policy按quantity+unit绑定每例逻辑名，caeoj.grading执行逐值全部AND；不会假设outputs对象名等于quantity或array key。每题instruction完整公开atol、rtol及等号接受规则，无额外隐藏物理指标、幅度拟合或默认容差来源。

| 题目／观测 | atol／rtol | 逐例墙钟 |
|---|---|---:|
| 光子出射、逐层沉积 | 1e−8／0.005，各自SI单位 | 600秒 |
| 稳态／瞬态角输运的通量和流 | 1e−8／0.005 | 1200秒 |
| 源驱动扩散通量和流 | 1e−8／0.005 | 600秒 |
| 临界归一化通量；k_eff | 1e−8／0.005；1e−7／0.001 | 600秒 |
| 点堆n和C | 1e−8／0.002 | 300秒 |
| 库存；活度；衰变功率 | 1e−6／0.002；1e−8／0.002；1e−12／0.002 | 300秒 |

选择依据是层内有限衰减、连续角输运及有限速传播、扩散边值／谱问题、有限维刚性演化的不同复杂度；均是待校准设计目标。全部2CPU、4096MB、0GPU、生成3600秒、构建1800秒；Linux AMD64且逐例无网络。SciPy由harbor/requirements.txt声明，公开工具本身仅需核心依赖和NumPy。max_output_bytes显式null，不引入隐形128MiB限制，但逻辑分量有上限。

真实prepare_harbor.task_config加载覆盖并验证separate verifier、no-network、资源和动态总预算`max(1200,300+N*(timeout+60))`，临时N=3；正式N未绑定。Harbor judge逐例传递timeout、检查退出／输出、调用grade并按通过例数／总例数汇总，基础设施错误中止而非记考生零分。资源配置被消费不等于Linux容器硬限额已实测。
