# 数据池工具实施与验证（2026-10-17）

## 交付范围

维护 CLI 增加 `data pack/upload/select/fetch/assemble/verify`，入口和操作统一由[数据池操作](../../maintenance/DATA-SYNC.md)维护。实现位于 `caeoj_tools`，HF 依赖仅属维护 extra；核心协议与数值判分未改变。

制池读取生成材料、保留来源证书绑定，合并重复样例并对本题重复文件按内容共享。上传验证全部声明材料与附件，拒绝意外混入的文件；读取远端元数据跳过相同字节，索引保留其他条目，以固定父提交提交并核验。选择绑定明确 ID、角色与描述摘要，正式选择拒绝重复或不完整材料。

装配固定一次远端提交，下载时校验摘要，在写入前预检本地差异；显式更新才覆盖。先暂存再替换，写入失败回滚，回执最后提交。改选时只删除未修改的已管理旧文件，不删除未知文件；校验从 SHA 绑定的原始描述重新推导预期数据，不信任可被编辑的回执文件摘要。

共享数据物化到各输入目录，符合现有自包含路径协议。发布器离线严格校验样例，Harbor 准备严格校验全套材料和重复选样；本地 smoke 使用警告模式。旧 ZIP 在 Windows 上的重复原子替换失败已通过系统文件替换原语处理，未采用先删旧包的回退。

新增 `caeoj-manage-data` skill，并同步数据设计、实际数据审计与 benchmark skill。用户没有要求的物理设计、数值参考制作和模型评测不由数据池工具代行。

## 本地与真实消费验证

- 池工具、公开发布、Harbor、PDEBench 准备及运行时装配回归：72 项测试、284 项子检查通过；后续增补共享依赖物化和制池期间源变更测试后，池工具最终 16 项测试、7 项子检查通过。
- 覆盖相同文件跳过、摘要损坏、未选附件、上传白名单、远端索引合并与显式更新、重复选样、共享依赖与循环、路径/大小写冲突、部分获取、改选清理、用户修改保护、事务失败回滚和回执篡改。
- 用通用离线装配器装配首批三题，未改变原 406 个本地数据文件。其现有选样重叠被保留；稳态题的真实 Harbor 准备按预期因重叠停止，未启动容器或收费 Agent。
- 两道热传导公开材料合包成功，并经已有独立公开运行时预检；包内无池维护代码、条目描述、选样清单或回执，安装依赖无 `huggingface_hub`。
- 此前从真实 DaRUS 获得的平流试跑数据（1 个 case、2 个样例）经通用制池生成 3 个条目，保留来源绑定；没有重新获取全量源数据或完成全轨迹转换。
- 新 skill 通过 skill-creator 的格式验证。相关文档与 skill 内部链接已检查。

## 限制

该工具不证明参考精度或评分资源已校准。现有迁移数据中的样例/测试重叠需要单独审核并重选，不能为让正式准备通过而自动改变题目。PDEBench 全轨迹枚举与转换、制作进度的云端恢复、跨题共享及独立 JSON Schema 文件不在本次交付范围；上传重跑跳过相同文件不等于这些能力已经完成。
