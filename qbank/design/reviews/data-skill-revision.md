# DATA 设计技能修订与前向试用

日期：2026-10-15。实现此前讨论的职责调整，不重写第二章已审阅题面或数据。

## 主要修订

原 caeoj-extend-io 更名为 caeoj-design-data，删除旧入口而非保留两套并列流程。新技能以给定题面为输入、自包含 DATA.md 为主要交付，协议／工具拓展仅在实际缺口存在时进行。

出题技能仍负责逐级规划和 instruction，并协调 DATA 设计与联合修订。审计技能先按三文件核查公开定义，再对照全部实际输入输出。工作流、调用示例及经验清单同步采用新职责。

三文件是本题 instruction.md、DATA.md、CONTRACT.md；维护规范、章节 COMMON／共享 DATA、其他题或源码不能用来补足题意。模板可内部复用，交付逐题展开；维护文档不随考生材料发布。DATA 发现物理欠定时反馈题面，不能悄悄补模型或缩小目标。数据生成、真实数据审计、数值／物理验证及发布保持独立状态。

- 第二章 11节共65题通过更新后静态检查。此前最终审阅的131个考生文件散列保持不变。

## 独立前向试用

独立 subagent validate_data_skill 用给定二维瞬态热传导题面与 CONTRACT 设计一份新 DATA 草稿，不读取现有热题 DATA 或解法。所有产物仅在 /tmp/caeoj-data-skill-evaluation，未改仓库、联网、生成数值数据或启动嵌套审阅。

实际交付 instruction.md、DATA.md、report.md、checks.json。已有结构足够，没有创建领域规范或改基础设施；五个条件片段通过 JSON 解析和通用 condition Schema。试用明确只做到草稿，独立考生审阅及完整输入输出验证未执行，没有将作者自审称为独立审阅。

试用者另核对出题、DATA设计、审计的衔接，发现示例要求不一致：审计此前要求逐算子 JSON，设计侧仅要求已有片段可解析。两处已统一为“每种条件完整结构定义，易误读的嵌套／表示差异用代表性片段说明，结构表能逐键还原时不重复同结构例子”；独立复核通过，完整读取定义要求未削弱。

结论：本轮技能、入口与指导已落实讨论的设计，并通过上述有限前向试用。没有实际执行整章新出题，未生成或发布正式数据；试用不证明未来所有领域均无需协议拓展，也不证明数值／物理正确性。
