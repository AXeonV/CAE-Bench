# 本轮源数据审核记录

本轮采用“匹配官方生成器，审核官方轨迹”的用户选择。审核源码版本及发布文件身份见各题 DESIGN.md 和 catalog.json；源码版本不能证明所有归档文件均由该版本生成。逐例检查结果保存在本地 certificate.json，不随 Agent 输入包分发。

## 已发现并处理的差异

| 方程族 | 发布数据中的问题或差异 | 工具处理 |
|---|---|---|
| 二维反应扩散 | 发布网格是原 512² 网格的 128² 子集；当前生成器随机数接口不能复现归档初值 | 使用历史 MT19937 恢复完整初值，要求所有发布初始值逐值匹配；输入完整细网格，输出明确指定的细网格单元子集 |
| 一维反应扩散 | 部分轨迹远离 logistic 平衡时已停止变化 | 保留官方对照；对同一 PDE 独立计算参考，并分别检查空间与时间加密变化，记录差异及加密历史 |
| Darcy | 小源项发布快照的离散稳态残差较大，不能直接作为稳态答案 | 保留官方快照；独立求解源空间算子的平衡态，记录原始与修正残差；固定网格残差不等于连续误差界 |
| 吸附扩散 | 发布生成器使用外部单元闭合，直接写传统边界会改变问题 | 明确原始单元平均耦合的边界表达及正则化迟滞系数 |
| 可压缩流 | 源黏性通量及由守恒量反算的速度、压力不等同于标准常动态黏度模型和原始变量体积平均 | 题面、参数单位、输入输出观测量均按源实现明确；记录正性、压力下限值与周期质量、能量变化 |
| 不可压缩流 | 当前源码的 grid_size Box 与发布配置的单位 Box 存在版本差异；初始记录尚未投影 | 每个使用的分片用短时标量输运辨别尺度；t=0 保留原记录，正时间契约采用投影后的速度及 χf 强迫 |

## 证据的边界

HTTP 模式仅取必要字节范围；验证响应范围、长度、块摘要和选定载荷摘要，不能声称已验证整份远程大文件的 MD5。完整本地源文件模式才执行整文件 MD5。

数值参考通过结构、初值、坐标、实际时间及族相关一致性检查。除已记录的独立比较或加密检查外，不宣称完成连续解误差认证。官方输出不是精确真解，归档生成器版本、离散误差、部分中心/交错采样误差仍有局限。

2026-10-13 本地运行中，选用的 8 个不可压缩流分片全部通过尺度辨别：单位 Box 的短时标量输运相对残差为 0.001108–0.002146，grid_size Box 为 0.998030–0.998047。两种解释使用相同发布速度、标量及实际时间；此比较只支持空间尺度判断。

生成输入和数值参考不表示已经可以评分。误差阈值、执行资源和评测配置仍需校准；现有 Harbor 输出大小上限也需要审核，才能接入较大的三维结果。本轮不修改旧任务、共享 Schema、SDK 或判题器。

## 可复现记录

- catalog.json 固定发布文件清单；各题 author/data-evidence/reference/selection.json 固定来源、轨迹、公开/隐藏拆分和格式变体。
- author/preparation.json 与 runs/pdebench/reports/latest.json 记录本地实际完成状态、错误和占用，数值载荷和本地状态不进入 Git；问题定义、冻结清单及 JSON 参考证书进入 Git。
- 重新运行入口会验证已有条目及缓存，复用通过校验的内容；题面变更默认拒绝复用冻结清单，作者审核后才能显式刷新契约绑定。
