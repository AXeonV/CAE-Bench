# 其余四题真实来源与消费验收（2026-10-19）

**本批工具验收通过**：四题共 8 条独立 DaRUS 轨迹制作成 8 个计分 case，其中 4 条同时制作引用式 example；全部完成来源比对、契约与公开包校验、独立安装及真实隔离判题。实现版本为 `21521bc`，没有修改转换器、题面、DATA、评分或运行限额。没有调用模型、求解器、HF Jobs 或上传数据。

本次是用户要求的四题小批验收，不是[七题各 20 条试验](../../pdebench-seven-task-trial.md)。每题临时选 2 个 case、1 个公开 example，保留一个未公开 case 验证身份区分；没有覆盖题内正式数量或样例清单。每题公开 case 001 引用为 sample 01，仍计入 2 例分母。

## 发布和判题消费

- 8/8 参考自比较得 1；8/8 明显错误数值控制得 0。4 个 example 的全部输入、参考和完整输出与关联 case 字节一致，公开副本不增加来源身份。
- 四份公开 ZIP 和四份 Harbor 任务实际装配成功，各有 2 个计分 case、1 个 public_cases 身份。公开包未包含隐藏 case、作者绑定或来源回执。
- 合并四题公开运行闭包，离线构建普通 wheel；在现有 Linux AMD64 容器中标准安装到 site-packages，消费过程未挂载源码树、未联网安装依赖。
- 对四题的全部 8 个 case 实际执行生成的 test.sh → judge.py → 非特权程序 → 评价 worker。控制程序只输出结构合法的全零结果，8/8 判为 wrong_answer，均完成判题；不是模型成绩或 PDE 求解。4/4 公开身份保留，未公开例没有 public_sample 标记，分母各为 2。
- 控制程序逐例确认 UID 1000、隐藏 reference 读取被拒绝、无 IPv4 路由、普通安装的运行库路径以及 cgroup 限额。吸附扩散为 2 CPU／2 GiB，其余三题为 4 CPU／4 GiB；Docker 状态相符。实际逐例摘要见 [isolated-summary.json](isolated-summary.json)。本次没有额外校准真实求解程序的时限或数值容差。
- 完整工作区再次 prepare，8 个 case 与 4 个副本全部复用，核验通过，0 次网络请求。
