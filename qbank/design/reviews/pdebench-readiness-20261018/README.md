# PDEBench 迁移准备验收

2026-10-18。本轮仅执行用户授权的 USD .10 内迁移准备；没有启动全量，没有修改 HF main，也没有改变正式选样。**平流的工程迁移链已就绪；另外两族的合同和参考认证仍是全量放行条件。** 完整预算与参考补算情景见 [BUDGET.md](BUDGET.md)，不能把机械入库报价当作 250000 个可用 case 的保证。

## 完成内容与证据

| 准备项 | 实际结果 |
|---|---|
| 统一存储与 CLI | pack/upload/select/fetch/assemble/verify 支持 TAR 批次与 64 分区发现，保持 case/选择身份；跨批合并保留原内容，分区与根原子发布 |
| 整个 worker 丢失恢复 | 第一 Job 在 A 组 4 例发布后故意退出 75，未写完成检查点；第二个全新 Job 从池发现 A，只制作 B 组 4 例，重取 8 例并严格校验、判分，重复装配 changed=0 |
| 实际来源迁移入口 | 从固定 Advection beta=.1 源行 1000～1015 连续读取完整 201 帧，逐例制输入、精确参考、来源证书、独立积分核对和正反例判分；上传后固定提交重取装配、严格核验和 16/16 判分 |
| 冷启动重放 | 同批在另一个新 Job 中再次执行；配方绑定 worker、ZIP 内容、合同和来源范围，重取后 16/16 判分通过，source_records_read=0；未新建重复 case |
| 仅读元数据选样 | 本地限制 backing store 只允许 .json，固定提交选取全部 16 例成功；读取 16 个 JSON，共 45243 字节，TAR/数值载荷读取为 0 |
| 公开包与容器 | 公开 ZIP 30 文件、不含维护模块或隐藏 case；公共核心普通安装；Linux AMD64 容器关闭网络，2 核、2 GiB、无 swap、128 PID；真实 verifier 的 2 个代表例全部接受 |
| 材料隔离 | 实际提交 UID=1000，断言不能读取 root:0700 的 /tests；私有材料以 docker cp 装入，不用只读 bind mount 假冒隔离；1 个公开样例同时计分，另 1 个隐藏例 |
| 身份与断点修复 | 运行 ZIP 按路径与内容 SHA 稳定绑定，不受 ZIP 时间戳影响；拒绝未知状态、状态回退与 selection/transport 绑定变化；更新检查点使用 parent_commit |
| 预算与配额 | 本轮 5 个有界 CPU Job 全部结束（其中 1 个为设计中的故意失败），无活动 Job；共享账本保留活动/未知预留，仅终态采用保守生命周期界结算；实查公开存储配额 7.8 TB，无付费升级 |
| 全量覆盖计划 | coverage-plan.json 列出 25 文件×10 个连续千行范围，共 250 批/250000 行；80 个平流范围可用当前生产入口，170 个其他族范围明确待放行，未执行此全量计划 |

独立审阅先指出默认选择验证、生产依赖身份和检查点覆盖问题，修复后复审通过，见 independent-review.json。预算接口核对另纠正了 SDK 的 endpoint 含义：它是 Hub 服务地址；公开暴露端口使用 expose_urls，不能混为一谈。定向检查为数据池 30 项（29 通过、1 因缺维护 extra 跳过）、云端迁移 12 项通过；没有重跑整套仓库测试。实际云端和容器验收另行记录，不用单元检查代替数值消费。

## 成本和本地流量

jobs.json 是本轮费用数字的记录。新增 5 个准备 Job 的 Running 向上按分钟计为 USD .0025；按整个创建到结束生命周期（含非计费调度）向上取整再各加一分钟，保守计为 **USD .0055**，低于用户 USD .10 上限。连同先前试验，全部已登记 Job 的相同保守口径合计 **USD .0255**。这些均未逐 Job 核对最终账单；界面先前显示的 USD .02 是四舍五入金额，不能假装精确扣款。

原始 HDF5 和云端分片未流经本地。容器检查特例下载了两个已制作 case，共 **3434130 字节**（约 3.43 MB），由 local-transfer.json 记录；另有小型 JSON/日志、代码与本地已有 Docker 镜像，没有拉取新镜像。metadata-selection.json 单列额外选样元数据，不混入数组载荷计数。

## 两个问题族的必要放行准备

这部分不能由工程验证代替；目前不将其 170000 条来源写成可评分 case。

| 问题族 | 已有依据 | 进入全量前必须落实 |
|---|---|---|
| Burgers 120000 行 | 全帧有限；高黏性 Cole–Hopf 诊断与部分收敛对照 | 固定黏性参数是 Nu 还是 epsilon/pi、初态连续/单元常数语义、时间及输出观测；新 DATA/评分合同及独立设计/考生审阅；低黏性和陡梯度层的误差依据；按分层先小批再千例校准可信参考吞吐 |
| CNS 50000 行 | 已提取 50 行有限、正密度正压；固定生成代码诊断 | 按周期随机/透射随机/激波明确分题，落实状态方程、能量、密度相关黏性通量、压力下限与 ghost-cell 边界；不能把示例配置当逐例生成清单；来源精度或独立参考验证、各边界守恒收支及容差，再校准补算费用 |

具体来源语义证据沿用[预检记录](../pdebench-preflight-20261018/README.md)。不能只检查有限值、守恒、正压或文件摘要就认证连续 PDE 参考，也不能沿用平流 1e-6 容差。未通过的条目保持待审/隔离，不为凑齐 250000 降低门槛。
