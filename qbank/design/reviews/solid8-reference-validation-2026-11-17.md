## H1 的能力价值与验证范围

H1 是保留的耦合瞬态留出工况。它要求同时给出位移、速度和单元平均应力；角点速度比整体位移或能量更敏感。可运行、低残差、能量守恒与局部观测准确是不同要求。该例有助于考察 agent 能否忠实保留物理输入，区分读取实现、时间离散、方向空间分辨率及观测积分误差，并在有限预算下选择合适算法和停止条件。

最终参考使用自编三维 GLL P7 有限元、四分之一对称域与正的配点质量近似，通过保留全空间算子的 Chebyshev 矩阵函数计算线性斜坡响应。它不是截断的低阶模态叠加，也不宣称有限多项式计算具有严格零时间误差。分方向空间比较与同网格 p 比较均按相同最终参考的容差分母统计：

| 检查 | 最大 η / 相对量 | 判定 |
|---|---:|---|
| x 方向加密 | 0.0748164 | < 0.2 |
| y 方向前一档 | 0.1298362 | < 0.2 |
| z 方向加密 | 0.1031661 | < 0.2 |
| 同网格 P6 / P7 | 0.1856457 | < 0.2 |
| 多项式截断对比 | 2.36e-8（η） | < 0.2 |
| 固定原四面体观测积分 | 0.000685842（η） | < 0.2 |
| 同算子独立功能量与直接状态能量一致性 | 4.48e-10（相对量） | < 1e-7 |

能量核验与字段差异共同支持本批七个规定输出时刻、原节点及原单元平均观测的精度；不能据此推出所有空间点、任意时刻或任意参数均已验证。最终 H1 参考摘要见该题作者 JSON。此前混合改变网格／阶次但超预算的候选保留为诊断历史，不计作通过证据。

早期路线遇到过实际高阶读取问题；修复后仍有速度差异超预算，不能把全部失败归因于一个原因。旧 P6 的空间速度差异约为 0.570，P2 渐变网格也未通过。时间隔离中，短时程 6.25 / 3.125 μs 比较达到 0.01958，而全时程诊断最大值为 0.09335，未达到当时更严的 0.02 隔离目标；正式输出时刻最大值为 0.04150。这不等于原 grader 失败或最终参考预算 0.2 失败，且旧路线仍缺空间证据。局部高阶振荡、相位积累及网格反射是解释线索，未被实验唯一归因。
