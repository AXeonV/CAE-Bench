官方 Sod6 文件经头部检查为 `[201,1024]` 的单条轨迹，仅规划一个隐藏点；不把时间裁剪或重编号当作额外物理样本。

## 拆分与覆盖

- 每题先选 2 条独立公开轨迹，再从剩余候选选隐藏轨迹；同一源轨迹的时间裁剪、重编号或格式变体不跨公开/隐藏拆分。
- 同一物理配置存在多个隐藏点时，选择不同初始场或材料场，覆盖较平滑和较强局部变化；禁止把仅改变编号的副本当成独立物理覆盖。
- 候选按稳定源身份与索引排序，计算输入特征后分组；公开样例按 SAMPLES.md 的目标选取，隐藏组按分位覆盖选择，平局按源身份和索引打破。组样本不足时明确报告，不自动复用公开轨迹。
- 每组第一点采用连续编号和 ASCII 网格，第二点（若存在）采用固定递增稀疏编号和 binary 网格，其余点交替两种编码。几何和场关联不变；这些只是 I/O 覆盖，不改变数学初值或模型。
- 所有要求的输出位置与分量均参与比较；不能仅检验结构、t=0 或整体守恒来代替正时间数值正确性。

## 输出时刻与参考

保留原空间分辨率，最多选 9 个输出时刻：源有 T 个有效帧时，取 floor(k·(T−1)/8)，k=0,…,8，去重；T<9 时全保留。从实际有效时间数组读取，不能把无对应轨迹帧的额外坐标算成输出。含初始、早期、中期和末期；允许参考在这些相同时间重算，不采用未经审核的时间插值。

常动力黏度连续模型与源更新不等同；独立计算或经过同模型误差审核的参考，明确原始变量平均与守恒量反算的区别。

数值误差阈值、参考收敛指标、CPU/内存及时限在参考审核后确定。本阶段不承诺官方正时间数组可直接当标答。尚未审核的源轨迹只能作为输入候选或对照，不能写入可评测 reference。

case ID 使用本表的三位编号；cases 与 reference 必须一一对应。具体 case 子目录由后续工具在源选择冻结后创建，现在只保留根目录。证书记录源身份、实际数组哈希、空间/时间映射、参考来源、误差证据及工具版本；不复制到公开包。公开样例的私有证书由 author/ 保存。

现有 `.gitkeep` 仅保存空目录，不代表输入/输出或标答。工具成功后才生成 judge-config.json；没有真实样例、完整参考及审核记录时禁止发布或组装 Harbor。
