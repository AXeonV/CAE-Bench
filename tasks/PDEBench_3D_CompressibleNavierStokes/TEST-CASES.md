# 隐藏测试算例规划（作者材料）

**数据准备状态由工具逐例记录，判分配置尚未接入。** 本题计划 2 个公开样例及 6 个隐藏测试点；实际来源与拆分见 author/selection.json，完成状态见本地生成的 author/preparation.json；这些数量不表示评测已校准。本文和 author/ 均不进入 Agent 公开包。

## 测试分组

| 预留 case ID | 配置/选样组 | 隐藏点数 |
|---|---|---:|
| `001`–`002` | 随机场 M=0.1 | 2 |
| `003`–`004` | 随机场 M=1 | 2 |
| `005`–`006` | 湍流 M=1 | 2 |

组名用于作者选样；不加入参赛输入，不要求程序读取来源标签。具体源文件采用 DESIGN.md 固定版本，源样本索引由准备工具检查后冻结在 author/selection.json。

## 拆分与覆盖

- 每题先选 2 条独立公开轨迹，再从剩余候选选隐藏轨迹；同一源轨迹的时间裁剪、重编号或格式变体不跨公开/隐藏拆分。
- 同一物理配置存在多个隐藏点时，选择不同初始场或材料场，覆盖较平滑和较强局部变化；禁止把仅改变编号的副本当成独立物理覆盖。
- 候选按稳定源身份与索引排序，计算输入特征后分组；公开样例按 SAMPLES.md 的目标选取，隐藏组按分位覆盖选择，平局按源身份和索引打破。组样本不足时明确报告，不自动复用公开轨迹。
- 网格统一采用 MSH 4.1 ASCII。每组第一点采用连续编号，第二点（若存在）采用固定递增稀疏编号，其余点交替两种编号。几何和场关联不变；这些只是 I/O 覆盖，不改变数学初值或模型。
- 所有要求的输出位置与分量均参与比较；不能仅检验结构、t=0 或整体守恒来代替正时间数值正确性。

## 输出时刻与参考

保留原空间分辨率，最多选 9 个输出时刻：源有 T 个有效帧时，取 floor(k·(T−1)/8)，k=0,…,8，去重；T<9 时全保留。从实际有效时间数组读取，不能把无对应轨迹帧的额外坐标算成输出。含初始、早期、中期和末期；允许参考在这些相同时间重算，不采用未经审核的时间插值。

高维配置先核实原分辨率并估算总占用；参考须符合连续应力与能量契约，不用低维模型代替。

工具按当前源对齐契约审核轨迹并生成数值参考，保留原始对照和局限；Darcy 的参考采用源离散算子平衡态，一维反应扩散参考采用同一 PDE 的独立加密计算。策略及逐例证据见 DESIGN.md 和私有 certificate.json。数值误差阈值、连续误差审核、CPU/内存及时限仍需校准；参考文件存在不等于题目已可评测。

## 高维评测接入前提

128³ 网格、5 个变量、9 个 float64 时刻的未压缩载荷约为 755 MB。当前试运行 judge-config.json 将结果文件上限设为 2 GiB，判题器已支持按题读取该值；旧任务默认仍为 128 MiB。三维资源和参考误差仍须正式校准，不静默减少输出字段。

## 工具生成的目录与文件

```text
samples/01/input/       # 工具生成：problem.json、mesh.msh、input.h5
samples/01/output/      # 工具生成：result.h5
samples/02/input/
samples/02/output/
cases/<case-ID>/        # 工具生成：problem.json、mesh.msh、input.h5
reference/<case-ID>/    # 工具生成：reference.h5、certificate.json
author/                # 工具生成：selection.json、preparation.json、prepared/、sample-certificates/
```

case ID 使用本表的三位编号；cases 与 reference 必须一一对应。具体 case 子目录由工具在源选择冻结后创建；数值文件不进入 Git，克隆后需运行工具生成。证书记录源身份、实际数组哈希、空间/时间映射、参考来源、误差证据及工具版本；不复制到公开包。公开样例的私有证书由 author/ 保存。

`.gitkeep` 仅为目录占位；问题定义与 JSON 证书纳入 Git，数值数组及网格需由工具补齐。本工具不生成 judge-config.json；真实样例、完整参考、误差阈值和执行资源全部审核完成后，才能发布或组装 Harbor。
