# 二维稳态热传导

给定矩形域、常数导热系数 k、热源 q 和四条边的边界条件，求所有网格节点的温度 T：

\[
-k\left(T_{xx}+T_{yy}\right)=q(x,y).
\]

本题为稳态，无初始条件，不考虑相变或辐射。温度为线性方程中的数值场，允许零值和负值。

## 边界条件

每条边给出下表的一种条件，n 为**向外单位法向**：

| `operator` | 方程 | g 的单位 |
|---|---|---|
| `dirichlet` | T=g | K |
| `normal_derivative` | ∂T/∂n=g | K/m |
| `normal_flux` | −k∂T/∂n=g | W/m² |
| `robin` | αT+β∂T/∂n=g | W/m² |

四边全为法向导数／热流时，输入另给域平均温度。输入保证边界条件相容且解唯一。

## 输入范围

输入使用 Gmsh 网格、NPZ 数组及 JSON 元数据，遵守[通用数据协议](../../docs/CONTRACT.md)。源项为至多二次多项式，边界右端为至多四次多项式；输入给出 NumPy 升幂系数。字段读取和函数定义见[输入说明](DATA.md)，该说明是题目的一部分。

| 项目 | 范围 |
|---|---|
| 矩形 | x0,y0∈[−5,5] m；Lx,Ly∈[0.5,3] m |
| 导热系数 | 0.05≤k≤20 W/(m·K) |
| 网格 | MSH 4.1 ASCII 或 binary；一阶三角形及边界线段；节点数 3～20,000，三角形数 1～40,000 |
| 编号 | 正的 int64 tag，可不连续 |
| 系数 | float64；各源项／边界系数绝对值≤10,000（对应字段单位） |
| Robin 参数 | 0.1≤α≤20 W/(m²·K)，0.01≤β≤100 W/(m·K) |
| 平均温度 | [−20,20] K |
| 时间轴 | `times=float64([0.0])` |

网格、矩形参数和边界分组保证一致，输入通过结构校验。

## 输出与判分

程序接口：`python solve.py --input problem.json --output result.npz`。

输出 NPZ 包含原样复制的 `node_ids`、`times`，及 float64 `temperature`，shape `[1,节点数,1]`，按节点 IDs 行序，单位 K。

每测试点所有节点满足 `|T−Tref|≤0.01 K` 得 1 分，否则 0 分。32 个测试点满分 32，单点时间上限 30 秒。标答由解析解在节点坐标处直接计算。
