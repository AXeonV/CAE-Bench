# 二维稳态有粘不可压缩流

给定矩形域、密度 ρ、动力粘度 μ、体加速度 a 和边界条件，求稳态速度 **u=(u,v)** 和压力 p：

`ρ(u·∇)u = −∇p + μΔu + ρa`，`∇·u=0`。

本题为稳态，密度和粘度为常数，无初始条件。

## 边界条件

| `operator` | 条件 |
|---|---|
| `dirichlet` | 壁面速度 u=g |
| `periodic` | 配对边的速度、压力及对应导数相等 |
| `mean` | 域内面积平均压力为零 |

输入为一对相对边周期、另一对边给定恒定切向速度的通道；或三边静止、任意一边沿正或负切向匀速运动的正方形方腔。方腔运动边两个角点为零速度，开区间保持恒定壁速。

## 输入范围

输入使用 Gmsh 网格、HDF5 数组和 JSON 元数据，遵守[通用数据协议](../../docs/CONTRACT.md)。字段与条件的程序语义见 [DATA.md](DATA.md)，该说明是题目的一部分。

| 项目 | 范围 |
|---|---|
| 矩形 | x0,y0∈[−2,2] m；0.5≤Lx,Ly≤2 m，长短边比≤4 |
| 材料 | 0.5≤ρ≤2 kg/m³；0.005≤μ/ρ≤0.05 m²/s |
| 速度与驱动 | 壁面速度绝对值≤1 m/s；恒定体加速度分量绝对值≤0.2 m/s² |
| 雷诺数 | 通道按净间距、速度尺度定义，Re≤100；方腔按运动壁速幅值和边长定义，Re=100 |
| 网格 | Gmsh MSH 4.1 ASCII；等距笛卡尔点阵划分的一阶三角形；25～4,225 节点，32～8,192 三角形 |
| 时间轴 | 单元素 float64 `[0.0]`，表示稳态采样 |

节点编号可能不连续；周期节点对应关系由网格 `$Periodic` 段给出。角点值不沿运动边插值。题目不规定求解算法或收敛迭代次数。

## 输出与判分

接口：`python solve.py --input problem.json --output result.h5`。

按清单 `outputs` 写出指定字段及其原始编号、时间轴。通道要求网格节点速度 `[1,N,2]` 与压力 `[1,N,1]`；方腔要求独立采样点处的 `u_centerline`、`v_centerline`，各为 `[1,17,1]`，分别表示全局 x、y 速度分量，不要求其他分量或压力。全部数值为 float64。

每点所有要求的速度值绝对误差≤**0.02 m/s**，要求的压力值绝对误差≤**0.02 Pa**，得 1 分，否则 0 分。32 点满分 32；单点限时 **5 秒**，内存 **1,024 MiB**。限时包含提交进程启动、输入读取、计算和输出写入。
